### 重新挂等待

box 端的 watcher（`watch_p3.sh`，见上表）不用重启，它一直在跑；`WATCH_TRIGGER` 消费完删掉后它会继续轮询。执行员这边挂一个阻塞等待，
每 3 分钟查一次那个文件，ssh 失败就重试，不做短周期监控、不发中间消息：

```bash
while true; do
  out=$(ssh -o ConnectTimeout=10 -o BatchMode=yes autodl \
    "cat /root/autodl-tmp/ujs/runs/nq4/p3/WATCH_TRIGGER 2>/dev/null")
  [ -n "$out" ] && { echo "TRIGGER: $out"; break; }
  sleep 180
done
```

用 Bash 工具的 `run_in_background: true` 跑这一整段（不要拆开），这样只在真正触发时才收到一次通知，不用自己轮询。
