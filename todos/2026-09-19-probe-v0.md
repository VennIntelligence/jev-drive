# Probe v0：nuScenes mini 上打通 feature → probe pipeline

状态: draft
主题: ../research/qwen-latent-driving.md

## 目标

不回答科研问题，只把 pipeline 端到端跑通：
nuScenes mini → ego future label → Qwen3-VL-4B 多层 feature → linear probe → 指标表。
跑完以后，换 trainval 只需要改数据路径。

## Setup

- 数据: nuScenes mini，只用 CAM_FRONT。已在 box 上 `$DATA_DIR/datasets/nuscenes`。
- 模型: Qwen3-VL-4B-Instruct，BF16，frozen。已在 HF cache 里。先不做量化，也不装 flash-attn。
- 环境: 在 `$DATA_DIR` 下用 `uv` 建 venv（Python 3.11）。先不装 vLLM / SGLang。
- 算力预算: 单卡 4090 D，总共不超过半天。
- 输出路径: feature 放 `$DATA_DIR/processed/`，run 放 `$DATA_DIR/runs/`，都不进 git。

## 步骤

- [ ] 建 env，写 `scripts/` 里的 env 脚本，确认 Qwen BF16 能加载，记下显存占用。
- [ ] `inspect_nuscenes`：列出每个 keyframe 的时间戳、ego pose、CAM_FRONT 路径。
- [ ] `build_labels`：用 ego pose 算未来 2s 的 Δyaw → left / straight / right（±5°）；
      同时存过去 2s 的 ego 速度、加速度、yaw rate（给 ego-state baseline 用）。
      打印类别分布。
- [ ] `extract_features`：单帧输入，hook 出 vision encoder 输出和 LLM 若干层
      （比如 4 层等距）的 hidden states，先用 vision token mean-pool，存成 npz/parquet。
- [ ] `linear_probe`：按 **scene** 划分 train/val（用官方 mini_train/mini_val），每层训一个 logistic regression。
- [ ] 同一套划分跑两个 baseline：majority、ego-state only。
- [ ] 出一张表：每层 × {acc, macro-F1, NLL, Brier}，加上两个 baseline。

## 成功标准

- 上面那张表完整生成，整条链路一条命令能重跑。
- 数字本身不作为结论（val 只有 2 个 scene，样本不到 100）。
- 顺便回答两个工程问题：单帧抽 feature 多快、显存多少；多层 hidden states 怎么存最省事。
