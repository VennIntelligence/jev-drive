# WL-2 表示改动干跑：在 WL-1 数据上先看 ego 横向通道和空间 token 动不动 C1c

前置: [WL-2 预登记](2026-09-29-wl2-prereg.md)（口径全部照它）、[WL-1](2026-09-28-wm-loop.md)、[空间 token 抽取](2026-09-29-wl-spatial-tokens.md)

**性质，每张表都要带这句**：这是**描述性干跑，不是判格**。WL-1 的 130 个评测分叉点在设计 WL-2 时已经被看过（C1c 的被占子集、cg 标签、H 口径都是看着它们定的），所以这里的任何数字都不算 WL-2 的结果，不进 decisions.md，也不改第 54 / 61 条。
用途只有一个：WL-2 的数据要几天才生成完，先用手头的 WL-1 数据看这两个表示改动（ego 通道、空间 token）有没有把横向问题往好的方向推，好决定 WL-2 的 `T` 臂要不要排在前面。

## 臂（全部 3 seed，WL-1 原配方）

WL-1 的配方一字不改：`W.CFG`（8 000 步、按 inner-val 取点）、10% base 路线作 inner-val、seed = 初始化 + inner-val 抽取、probe 同 WL-1、critic 同 WL-1（2 层 MLP，256，3 000 步，3 个 seed 的概率取平均）。

| 臂 | 训练数据 | 输入 / 结构 | 用途 |
|:--|:--|:--|:--|
| `W1main`、`W1worig`、`W1holdout` | WL-1 已训好，原样 | 无 s | 参照；critic 用 cg 标签重拟（预测器不重训） |
| `B` | WL-1 `main` 的宇宙 | 主改动：z + 5 维 ego 状态 s，结构同 WL-1，损失三块等权（openpilot / V-JEPA / s） | ego 通道 |
| `Bh` | `B` 去掉未来碰到 `shift_R` / `op_slow` 的窗口 | 同 `B` | C2(b) |
| `Bi` | 只用 wl_gen 索引行（去掉 W 日志帧） | 同 `B` | `T` 的同数据对照（W 日志帧没有 token） |
| `T` | 同 `Bi` 的行 | 空间 token 副臂，见下 | token |

ego 通道 s = [e_y, e_ψ, v, a, ω]：e_y、e_ψ = ego 位姿相对 route 折线（每个 run 的 `route.json`，约 1 m 间距的稠密全局路线；CARLA route 中心线，特权来源，同 WL-2 决定 4）的有符号横向偏移（左正，m）与航向差（rad）；v、a、ω 用 universe 里已有的 v、a_prev、w_prev。每个 5 Hz 步一个，标准化沿用 z 的逐列标准化。
probe（`occ`、`ped`、`d_front`、`v`）、C-learn、Q 都读含 s 的向量（推演时读 [ẑ, ŝ]），Q 读 [z_t, s_t, 动作序列]。

**空间 token 臂的偏离预登记（先写在这里）**：
1. 每个 token 从 1 024 维用一个共享 PCA 压到 128 维（在 3 万个随机行 × 24 个 token 上拟合，保留方差比例写进结果）。理由：显存上限 15 GB（box 上 GPU 4 已满、GPU 5 与 Cosmos 共用）；1 024 维的 24 个 token 让 probe 的 ridge 与 critic 输入都到 2.5 万维，装不下。压完 24 × 128 + openpilot 512 + s 5 = 3 589 维，与 `B` 的向量同宽，probe / critic / 读数代码原样复用。
2. 预测器 = token Transformer：每步 26 个 token（openpilot 1、空间 24、s 1），历史 8 步 + 未来 10 步的查询共 468 个 token，6 层、d = 512，同 W；每个 token 按类型 / 位置加可学习标识，输出头按类型分（openpilot 512、空间共享 128、s 5）。batch 128（不是 256，序列长 26 倍，激活装不下），逐层激活检查点，其余同 WL-1。
3. 训练数据只有 wl_gen 索引行（没有 W 日志帧的 token），所以公平对照是 `Bi`，不是 `B`。
4. C4 不做 `T`：考卷帧是 W 日志帧，没有 token。

## 读数（全部按 WL-2 预登记的定义，评测集 = WL-1 的 130 个评测分叉点，7 个候选）

unsafe 标签：**cg** = 碰撞或本车道最小间距 < 2 m（主）；**reg** = WL-1 登记标签（cg 或 TTC < 1.0 s，次要，并列）。critic（C-learn、Q）各按两个标签拟合，其余同 WL-1。

1. **C1c**（被占子集横移可分性）：S = 所有 (评测分叉点, 侧 ∈ {L, R})，满足 `op` 分支在分叉 + 2 s 的真实 `occ` = 1、`op` 与该 shift 分支都有标签、分叉点不在退出成对读数名单里。真值 = shift 分支 +2 s 的 `occ`（1 = 仍被占）；分数 = 该臂推演第 10 步的 `occ` probe 值；AUC = 区分「仍被占」与「已离开」，按 seed 各算再取均值。
   CI = 按 base 路线整组 bootstrap（2 000 次）；`B` − `W1worig` 的 AUC 差用同一次路线重抽的 CI。最小样本：两类各 ≥ 20 对、来自 ≥ 8 条 base 路线；不够就写「样本不足」，同时给 WL-1 差分口径（推演 `occ` 概率 shift < `op` 与真实「已离开」一致的比例）作回退。
   并列：WL-1 原口径（全部分叉点的一致率）；`B` 的 ŝ 横向偏移对真实 e_y 在 2 s 的误差（中位绝对误差，与「永远预测当前 e_y」对照）。
2. **C1 刹车方向**：`brake_hard` 对 `hold` 推演 2 s 后 `d_front` 更远的比例（线 85%）与 Δd 误差中位数（线 3 m），seed 均值。
3. **C2**（cg，并列 reg）：C-learn 对真实 unsafe 的 AUC（线 0.85）、同分叉点内 unsafe 对 safe 分支的成对排序（线 0.80）、C-learn − Q 的 AUC 差 CI；`Bh` / `W1holdout` 的 2(b)（`shift_R` / `op_slow` 分支上 C-learn − Q 的 AUC 差 CI）。只有 7 个候选。
4. **C3a**（cg，并列 reg）：x⁺ 评测分叉点上 H = (U_op − U_sel) / (U_op − U_or)，选择规则不变（p < 0.2 里进度最大，都 ≥ 0.2 选 p 最小），CI 按路线 bootstrap；同时报「可解」分叉点数与 U_op、U_sel、U_or。
5. **C4 连续考生**（`W1main` 与 `B`，cg）：考卷同 WL-1 C4（20 条评测 base 路线、seed 0 / 1 / 2、`p5_exam.exam` 原样），考生 = 对该帧推演 `hold` 候选后 C-learn 的 p̂，3 个 seed 的 p̂ 取平均，输出 = −p̂；判格线（只作参照，不判）：行人翻转率 CI 下界 > 样本外 null 误翻 + 10 pp；cut-in 用同一 null 线。并列每个 seed 单独的翻转。
