## 冻结 v1 holdout 比较

冻结协议提交 `2d69c17` 之后，才开始 6 路线 × 3 seed × H/J 的 **36/36** 个有效 case；所有 case 的官方状态均为 `Completed`，I1–I3、控制组合和执行量检查均通过。只在 `27529/2/H` 有一次 CARLA server `rc139` 的基础设施失败，尚无驾驶结果或逐帧记录；按原规则重试一次，canonical `done.json` 选择成功的 attempt 2，官方 DS 100。A/B 沿用 W2 正式结果。候选与分析规则均未在 holdout 期间改动。

**先与最强参考 A 比较：H−A 和 J−A 都是 +0.00 DS，路线整组 bootstrap 95% CI 均为 [0.00, 0.00]。** A、H、J 的 18/18 个 case 全部是 100 DS、100% RC，18/18 完成且 18/18 达到 SR。因此，本次没有测到 H 或 J 相对 A 的增益；两候选在这个保留集上恰好复制了 A 的满分结果。H/J 使用 A 的油门和制动，优于 B 的大部分差距不能算作新控制律的独立收益。
