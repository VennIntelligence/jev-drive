# Planner v0：在 nuScenes 上彩排 Stage-A 轨迹词表规划器

状态: running
主题: ../research/frozen-vlm-planner.md

## 目标

把我们准备发表的 Stage-A 系统——**trajectory vocabulary planner**（先用训练集轨迹聚出一套固定的候选轨迹
"词表"，在线时只让一个很薄的 head 给每条候选打分、选一条输出）——整条代码、指标和表格先在 nuScenes 上
跑通一遍，然后原样指向 Waymo E2E。

这里得到的数字**不是结论**：nuScenes 只有前视单帧、3 s horizon，而且 open-loop ADE 早就被证明由 ego state
主导。这一版要回答的是工程和方法学问题：词表多大够用、frozen feature 该取哪一层、classification 比
regression 差多少、视觉到底比 ego-only 和物理外推强多少、head 本身有多快。

## Setup

- 数据: nuScenes v1.0-trainval，CAM_FRONT keyframe（2 Hz），官方 train/val scene 划分。
- Feature: 已经缓存好的 frozen feature，`$DATA_DIR/processed/nuscenes/v1.0-trainval/features/`
  下的 `qwen_w800`（Qwen3-VL-4B-Instruct，输入宽 800 px，36 层 × {last, mean} 两种 pooling，2560 维）、
  `qwen`（原分辨率）和 `dinov2`（ViT-B/14，cls 和 patch_mean）。这一版不重新抽 feature。
- 模型: 只训 head，backbone 完全冻结。
- 算力预算: 单卡 RTX PRO 6000，整条链路 < 1 h。

## 步骤

- [x] 轨迹目标：3 s / 2 Hz / 6 个 waypoint，horizon 和 rate 是参数
- [x] 词表：train split 上 k-means，K ∈ {64, 256, 1024, 4096, 8192}，报 oracle minADE/minFDE
- [x] Head：classification（hard / soft target）、ridge regression、MLP，以及 ego-only 和物理 baseline
- [x] Feature 对比：DINOv2、Qwen ViT、Qwen LLM 各层 × 两种 pooling
- [x] 指标：ADE/FDE（含中间时刻）、minADE_k、scene-level bootstrap CI
- [x] Latency：head 自身 batch-1 延迟，以及截断到某一层的抽取速度

## 成功标准

跑之前写死：

1. 整条链路一条命令跑完，输出 results.csv / results.md / 图，且换成 `--horizon 5 --rate 4` 就是 Waymo 的口径。
2. K sweep 能把 **coverage error**（词表本身覆盖不了，oracle minADE）和 **ranking error**（scorer 选错）分开。
3. 视觉 feature 至少要比 majority anchor 和 mean trajectory 强很多；能不能超过 ego-only 不预设结论，
   但必须诚实报告差距。

![planner layer curve](../research/figs/planner-layer-curve.png)

图 1：ADE（average displacement error，预测轨迹与真值在各时刻的平均距离，越低越好）随 Qwen 解码层变化，
左为词表分类 head（K = 1024），右为 waypoint 回归。视觉 feature 全都在 3.3–4.3 m，而只用 ego 运动状态的
灰色虚线在 0.8 m 左右，差了一个数量级。和 probe 的结论一致：短时轨迹主要由当前运动状态决定。
另外中间层的优势在这里很弱（回归 head 上 L13–L22 略好），不像转向 probe 那样有明显的倒 U 形。
**左图的 legend 压住了曲线，出图代码需要改 legend 位置。**

![planner K sweep](../research/figs/planner-k-sweep.png)

图 2：K sweep 把两种误差分开。oracle（词表里最接近真值的那条，粉线）随 K 从 0.37 m 一路降到 0.11 m，
说明**词表本身不是瓶颈**；而 top-1 分类结果（蓝线）稳定在 3.9–4.1 m，几乎不随 K 变化，
说明瓶颈全在 **ranking**，也就是 scorer 选不对。top-10 的 minADE（橙线）约 1.0–1.4 m，
仍然比 ego-state ridge（0.8 m）差。
