# 横向后续：先分清采样、rejoin和车辆响应

**推荐下一项单变化：先验证并消除 lateral aim 的折线插值相位误差，保持.5s前视、纵向、rejoin与转向限制不变。** 若根代理的固定圆弧扫描不能证明足够的相位误差，该候选不进入CARLA；目前不同时加入yaw-rate反馈或更改rejoin。理由是插值可以在真值运动和恒定圆弧下独立证伪，不需要先拟合车辆动力学或增加一层反馈。

## 1. 车辆确有随工况变化的yaw响应差，但不能当成一个固定增益

`r_bicycle = -v*tan(applied_steer*max_angle*curve(3.6*v))/wheelbase`；`r_truth_left = -angular_velocity_z*pi/180`。

同帧IMU左正yaw rate与真值角速度的差RMS约.0010–.0015rad/s（上述26966/24240样本）。因此当前gyro有能力观测这个差异，但“测得差异”不等于“已识别understeer模型”：没有实测当前左右轮转角/轮胎滑移，最大转角×曲线的单轨模型也有近似；道路、瞬态、横向速度和控制输入采样均可能影响比值。急弯响应不足比缓弯明显，却没有支持全域同一个补偿增益。

**暂不选yaw反馈的理由：** `desired yaw = v*kappa_aim`若本身带有5Hz重规划和折线相位纹波，直接按其与IMU差加转向会把该纹波当成车辆不足，再增加动作。上一候选已因steer-rate和横向加速度失败；在未分离参考噪声/动力学前，以更强反馈“追回”高曲率指令的风险明显。未来可用现有speed/gyro实现有带宽限制的yaw跟踪，但需先固定干净的目标、延迟/符号契约，且只能作为下一项独立实验。

## 2. rejoin使“缩短前视增强纠偏”的通常直觉失效

`RouteAdapter._rejoin_path` 每次新轨迹都使起点等于当前估计ego，并令起点切向等于当前ego heading。原路线位置偏移用 `w(u)=1−10u³+15u⁴−6u⁵` 衰减，切向差用 `T(s)=L*(u−6u³+8u⁴−3u⁵)` 衰减，`u=s/L`。8m/s条件下最短join一般8m。每5Hz重新建立这条连接，相当于持续把近处参考往当前车辆位置和朝向拉回。

在直参考、小横向/航向误差的局部线性化下，Pursuit的有效纠偏曲率系数约为：

- 横向误差：`2*(1−w(d/L))/d²`；L=8m、d=4m时.06250/m²，d=3m时.06116/m²。
- 航向误差：`2*(1−T(d)/d)/d`；同条件从.34375/m变为.32080/m。

这不是对CARLA结果的拟合，而是当前构造公式的解析检查：在这个join下，4→3m并没有增加横向纠偏，航向纠偏甚至稍弱。它解释了为什么短前视可能带来更多命令变化，却只少量降低实际路径误差。当前候选的单一变化不能被解释为通常“不改变参考路径时”的1/d²增益放大。

不过，直接删除每次ego连接或缓存世界路径也有边界风险：20×.25s输入默认把当前origin补入轨迹，首点距离参与速度估计。缓存路线再从投影处取未来点可能重新出现v1的origin→first-point速度跳变；只保留旧切线也可能失去真实起点切向连续。持久join终点/路径生命周期是可研究方向，但需要明确初始化、偏离、重置、终点、实际路径弧长计时，工程面明显大于仅修改lateral插值。

## 3. 折线aim是较窄、可直接检验的候选

当前 `_geometry` 用折线投影，aim再以 `np.interp` 沿同一20点弧长表取x/y。8m/s的预测点间距约2m；近7m半径急弯并不是高密度采样。前视3/4m会落在不同的段内位置，随着20Hz运动重投影和5Hz重规划，段内相位发生变化。即使圆弧和运动没有噪声，折线内插点也不在真实圆上；其`2*y/(x²+y²)`可产生不属于真实曲率的变化。

根代理的独立扫描应先回答：固定圆弧/恒速/精确运动，仅改变采样相位，原算法的曲率和steer纹波有多大？目标均值偏差与纹波要分开，不能靠降低有效转向幅值把纹波压小。分别覆盖左右、R≈7/20m、6/8m/s、前视3/4m、0/.05/.10/.15s接收年龄；规划时域保持真实20点/5s。这是机制验证，不是另一次CARLA参数搜索。

如扫描确认明显相位纹波，候选只改变**lateral aim局部插值**为形状受限的C1曲线；保持`_speed_at`、原弧长/时间表、目标station、lookahead=.5、rejoin和所有限幅不变。需要明确局部插值的坐标基和参数，不声称仅因C1就动态可行。禁止外推、禁止越过可用终点；少点/重复点/近零段/不合理反向或过冲时回退原折线。由于某些坐标系下逐轴shape-preserving并不旋转等变，应在局部切向/法向或其他等变构造中检查该性质，不能直接把世界x/y分别限斜率当几何保证。

这是一项插值定义变化，不是同时加yaw反馈、重写route geometry或加强steer_rate。如果需要修改投影和重参数化弧长才能让它有效，则扩大了本轮“仅aim”承诺，应重新登记而非悄悄合入。

## 可证伪的进入条件和验收建议

1. **机制进入条件：** 理想圆弧全相位扫描中，候选曲率纹波峰峰值至少降低50%；平均曲率偏差不比旧算法更大，左右镜像和坐标刚体变换等价。恒直线/停车/终点应保持既有行为；所有有效点有限、不外推。若原纹波很小或改动只改变均值，则该机制不足以解释当前失败，不进入CARLA。
2. **对已有日志的受控重放：** 同一motion/轨迹序列，默认算法先逐值重现实际输出；再只换aim插值作shadow。记录replan与非replan两类raw/emitted变化率、转角幅度和纵向输出。`_speed_at`输出与原始纵向输入应逐值相同；闭环真实轨迹会改变，shadow改善不能当闭环收益。
3. **六例闭环仍固定24240/26966/17563×baseline/candidate**，baseline恢复.5系数。保留turns-v1全部原G2和固定窗口速度/动作/舒适性门槛；26966窗口RMS下降≥15%且P95/post10m不升；各窗steer-rate P95增加≤20%、横向加速度P95增加≤10%。完整all帧、低速、失败、停车与恢复censor均保留，不按均值取优或调整限幅。
4. **否证结果照收：** 若只减少命令纹波却不降低外侧残差，说明主要路径/动力学因素尚未解决，不能宣布横向问题解决。若CTE改善但动作代价再次超门槛，也不升级默认；随后才单独设计yaw动态补偿或持久join实验。

当前唯一推荐是上述插值机制验证/候选，而非同时实施多个补偿。其完成判据必须在根代理看到圆弧扫描结果、进入真实闭环之前固定；本笔记没有把待验证效果写成已有收益。
