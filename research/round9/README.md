一次主会话与用户的长讨论加上同时派出的一组诊断（大多只用 CPU、不训练）。本页收拢讨论中的判断、每个诊断的结论数字和后续决定，
供用户带去和另一个智能体继续讨论。数字都来自所引的结果文件或 decisions.md 行；「推」= 由记录的数算出。
草稿计划：[experiments/round9/plans/2026-10-22-round9-draft.md](../../experiments/round9/plans/2026-10-22-round9-draft.md)。

## 0. 结论先行

- PAI 上真正大的几步都是**换结构、给一个统一的约束 / 教师、用自己开到的状态**；按缺陷逐个补数据和 loss 的改动（第 2–8 轮）加起来约为零，R6DAG 之后到平台。
- 「修一个坏一个」是结构性的：闭环会走到的状态上**没有一个前后一致的目标策略**，各个 trick 是互相矛盾的局部教师，共用一个小 adapter 和一份 batch 预算；评估又在同一个 281 上选、seed 噪声≈臂效果。
- 失分表：R6DAG 两 seed 平均丢 57.2 分，**61 % 不归路线**（停车点冲过 19.5、追尾 / 慢 9.3、碰撞 6.0），横向 22.5。
- 路线支路：前视窗口按速度拉长**在 serve 上做不到**（AlpaSim 路线最多 80 m）；锚定记忆、窗口 0 分，航向指令约 1 分 / seed；高速失分的主因是**路线给在人旁边那条车道**（4–5 分 / seed）→ 不重训底座，改走 DAgger 迭代 (a) 航向指令 + (b) 教师车道规则（在跑）。
- S 课：洗池（S-MIX）把每批可学激活行从 3.8 提到 17.7，但**模型没多学到东西**（目标行 hinge 差 −0.2 %）；S 池全是 nuPlan 市区 ≤ 15.3 m/s，只能碰到 57 分里的约 19 分 → S 的瓶颈是**覆盖**与**可学性上限**，不是精选；唯一说得通的是 PAI 自车状态上的 S 行（CPU 闸在跑）。
- 在线自适应循环（边训边推演、按跑分调参）：组合层面文献里没找到同款，但各部件都有成熟先例（IMPALA / DAgger / PLR / PBT / 模仿锚）；噪声估计说 100 场景练习切片、均分排序 + 新坏否决、多轮平均才可行；基础设施约 22–31 智能体小时可搭，推演是瓶颈。先等 PAI 状态 S 行的证据再投入。
- 内部信号：没有人在驾驶 / 动作模型上沿训练 checkpoint 跟踪「线索可读 / 被因果使用 / 分技能闭环变化」三者并对齐时序——这是可写的空位；任何内部信号先在约 25 个存档 checkpoint 上用闭环分数验证才能进循环。
- 候选打分 + TOAD 式测试时选择：外挂组件、验证快，**放到最后几天**。

## 2. 高一层的问题：为什么修一个坏一个

- 每个 trick 是一个只管一片状态空间的局部教师（起步、停车、转弯、漂移、跟车），彼此矛盾：navtrain 人起步 4 s 走 8.3 m、PAI 人 4.2 m（d416）；DAgger 教师保留学生速度、第 2 次又取 min(学生, 人)；ACC 重新解释 plan 速度（d406）；起步与静止等待在同一低速轴上（d352/363）。
- 它们抢同一个小 adapter、同一份 batch；收益不可加（d244）。
- 评估：一直在同一个 281 上选，seed 噪声≈0.03≈臂效果（R6DAG-s1 的 0.818 是幸运 seed）；榜差≈本地差 × 0.6（d426）。

## 3. 用户的直觉：scale / randomization / 暴力多采样

- **randomization**：本项目读数都不支持——REC 扰动恢复行不降出路（d437），Harmonizer 孪生补不上开 / 关差（d443），时间拉伸行伤起步（d414）。
- **scale**：文献里的增益多来自便宜仿真器上的 RL / 自博弈（GigaFlow、CaRL）或 10–100 倍数据；我们冻结编码器 + 小 adapter、NuRec 读一次小时级，扩得起的只有「自己开到的状态 × 场景」，DAG2 显示教师不变时多迭代无用（d438）。
- **多采样**：有直接证据——281 上逐场景取我们 21 份读数里最好的到 0.879（现 0.80，d436）；模型自己的 16 个 TTS 候选里挑贴路线的救回 43 个零分、但撞坏 8 个（d417/421）→ 候选有，**选择器**是瓶颈。对应 Hydra-MDP / TOAD（valeoai，arXiv 2606.07170：测试时 CEM 在 planner 自带打分器上优化，不重训，navhard EPDMS 54.6 → 56.3）。用户决定放到最后几天。

## 5. 路线支路

**现状**：记忆 = 后轴坐标 −6 … +72 m、每 2 m、40 点（d282），范围从没扫过。「记住过去」的原因：AlpaSim 路线消息约从车前 40 m 才覆盖（d287），近处靠旧消息按位姿带过来。

**已知 bug 在现役模型里的状态**：时空错位（d342，`--rm-anchor` 写好未训）——没修；小弧线读成变道（d432）——大体不成立；变道 / 转弯指令混用（PAI 非转弯行 23 % 带 LEFT/RIGHT，navtrain 3 %）——只在 R7J 捆绑上过。

**用户提议**：前视窗口按速度自适应，点数固定、间距随速度伸缩。

**路线 CPU 检查**（[route_check](../../experiments/round9/results/route_check/README.md)）：
- 高速事件（22–38 m/s）每一个都是 AlpaSim 路线落在人所在车道的**相邻车道**（3.1–3.8 m）；车跟路线换道，R6DAG / R7J 在 38.5 m/s 冲过路线车道中心 1.1–1.5 m（NTV0 < 0.5 m），越过 4 m 走廊。
- 20 m/s 以上 4 s plan 几乎全部超出 72 m 路线（中位超出 47–50 m），但路线在本车道时高速 plan 并不偏离路线（72 m 处偏 > 1 m 仅 2–5 %，中速 10–11 %）。
- 依赖：0–20 m 段几乎无作用，40–72 m 段占约 60 % 响应；整条路线平移 1 m 只让 4 s 点动 0.07–0.08 m。
- 可收回（每 seed）：航向指令约 1（≤ 3）、速度窗口 0、锚定 0（≤ 1）；**相邻车道路线 4–5**，三种输入改法都管不到；DAgger 教师用同一车道规则，会在这些状态上教错车道（未在行上核实）。

**新基座评估**（智能体核实后搁置）：AlpaSim `ROUTE_LOOKAHEAD_DISTANCE_M = 80`（PAI / nuPlan 同），40–160 m 窗口 serve 上不存在，高速最多 72 → 78 m，实际变成「低速更短更密」，可能砍掉模型在读的 40–72 m 段；整链训练约 3 卡时 + 读 10–15 卡时，预期约 1 分 / seed，281 噪声分不出。窗口代码留在开关后、默认关。

**决定（用户）**：(a) 航向指令 + (b) DAgger 教师车道规则（路线车道是平行相邻车道、前方无转弯 / 岔口时，横向标签跟人实际走的车道），合成一次 DAgger 迭代，其余照 R6DAG 原配方，2 seed；采用线：两 seed（关 + 开）/ 2 ≥ R6DAG 3 seed 均值、高速漂移零分降、其他零分 ≤ +2。计划 [2026-10-22-dag-lane.md](../../experiments/round9/plans/2026-10-22-dag-lane.md)，结果 experiments/round9/results/dag_lane/（在跑）。

## 6. 车身 S 课（论文方向）

**剂量历史**（[s-rows-and-paper.md](../s-rows-and-paper.md) 第 3 节）：倒 U，压力 1.9–2.9× 最好，5.8× / 8.6× 变差（d311 / 347 / 348）；JTN 起固定 32 行 / 批、2.4–2.9×，未在 R5LC / R6DAG 上重扫。但剂量与「垃圾行」从没分开：63.5 % 的 hinge 量在学不动的行上，每批可学激活行约 3.9。**时间安排（爬升 / 周期 / 自适应）从没试过。**

**S-MIX 离线价值**（[smix_value](../../experiments/round7/results/smix_value/README.md)，CPU 约 70 核时）：
- 可学激活行 3.8 → 17.7 / 批（4.7×），可学行上的 hinge 份额 32.9 % → 100 %。
- 但从 NTV0 起，目标行 hinge 量 R6DAG-s0 降 5.5 %、R7J 降 5.7–6.0 %，差 −0.2 % [−1.2, +0.6]；被降权的行上 R7J 反而差 +3.0 %。
- S 池最高 15.3 m/s，57 分里只有约 19 分是 S 能碰的：转弯切内侧速度覆盖但转弯行少（可学 1.9–4.8 %）；直路出路约 5；碰撞约 5；高速漂移 0；停车 / 追尾 / 慢 / 该转未转 30.6 分无对应 hinge。
- 判词：单独 S-MIX 臂 −3…+3 分，不值 GPU；「S-MIX + 刷新池 + PAI 状态 S 行（road_pai）」+0…+5（中心约 +2），反证是 PAI S 行两次持平（d367 / 402）、road_pai hinge 曾增出路（d420）。
- 读法：S 的瓶颈是**覆盖**（PAI 的高速与转弯状态不在池里）和**可学性上限**（给 4.7 倍可学行也只多满足几个百分点）——后者本身是「知道约束却学不进去」的论文现象。

**PAI 状态 S 行 CPU 闸**（在跑，[pai_s_gate](../../experiments/round9/results/pai_s_gate/)）：G1 栅格有效性、G2 他车框、G3 当前策略下的激活 / 可学、G4 覆盖（可学激活抽取 ≥ 30 % 在 13 m/s 以上）、G5 hinge 梯度是否只教减速 / 切角；过闸则并进 (a)+(b) 之后的下一次 DAgger 联合臂。

## 7. 在线自适应循环（用户 10-22 的核心想法）

**用户的定义**：不是把「S 拉力 / 模仿拉力」稳在一个事后测出的目标比例（会随模型和池失效），而是**边训练边推演新样本、更新权重、看跑分**，让参数自己被跑分推着走；一边巩固旧技能、一边学新技能，尽量把知识塞进 planner（表征层多数线索已可读，问题在策略）。

**框架**：推演者（GPU 池 fan-out）用最新快照在训练场景上按提交 serve 开 → 新 S 行 + DAgger 标签 + 逐场景结局 → 缓冲区按当前激活 × 可学性 × 新鲜度定权 → 场景按当前失败 / 部分分且可学优先（PLR）→ P 个学习者各带混合参数 θ（S 压力、DAgger 份额、PAI 人类份额）→ 控制器（PBT）在固定练习切片上读确定性的关 Harmonizer 配对分，末位复制首位再扰动 → 281 整轮不碰，最后读一次。

**文献**（[round9-online-loop-lit.md](../round9-online-loop-lit.md)）：
- 不是全新：IMPALA / Ape-X 推演者-学习者 + DAgger 聚合 + PLR / SFL + PBT + 模仿锚（DAPG / BC-SAC / RAD）+ 回放式持续学习。没找到的是「S 行（无标签、作用在当前 plan 上的后果 hinge）+ 按重建日志闭环配对分调剂量的 PBT + 新坏否决」的组合；审稿人多半把 PBT 看成调参，方法贡献在 S。
- 驾驶近邻：OPTED（2609.20756，AlpaSim、冻结骨干、在线蒸馏特权教师；不混原数据 nuPlan ADE 0.74 → 1.22）、RoaD（第二轮碰撞 0.024 → 0.042）、RAD（4 轮 RL 夹 1 轮模仿）。常规 e2e 不做的原因：推演贵（OPTED 524 s 推演换 6 s 梯度）、离日志渲染变差、奖励难、第一轮后不稳。
- 有利观察：S 损失在当前 plan 上重算、DAgger 标签只依赖状态 → 旧行只是状态分布过时、标签不过时，off-policy 修正（V-trace 等）用不上，旧行可放心留。
- 五个坑与对策：适应度噪声（PB2：4 成员 PBT 输随机搜索 → 配对 CI 选择、2 轮 EMA、exploit 间隔 ≥ 2 轮、不扰 lr、第二留出切片）；遗忘与模仿漂移（InstructGPT：KL × 100 修不好、混预训练数据才行 → 每批保留 navtrain + PAI 人类行、模仿梯度 ≥ 0.6、种群里留 R6DAG 原配方对照）；钻 hinge 空子（缩短 / 减速 → S 压力 ≤ 5×、三类零分分开记、盯 plan 长度与末速比）；PLR 塌到学不会的场景（按 s̄(1−s̄)、单场景 ≤ 5 %）；「新坏」多是抖动（281 上每 seed 新坏约 10、修好约 44 → 相对对照、只算近 3 快照 ≥ 2 次解过的场景）。
- 默认值：θ 起点 S 2.4×（1.2–5）、DAgger 8 行（4–24）；配对 CI 不含 0 且增益 ≥ 0.02 才复制；新鲜度半衰期 4 轮、最新一轮 ≤ 50 % S 抽取；推演兼作适应度；85–90 % 分块完成即进下一轮。

**适应度噪声**（[fitness_noise](../../experiments/round9/results/fitness_noise/README.md)，22 份已存 281 关读数）：
- 排对概率（K = 60 / 100 / 200 场景）：真差 0.02–0.035 为 0.76 / 0.82 / 0.90，0.035–0.06 为 0.86 / 0.92 / 0.97；同配方兄弟学习者真差 0.03 约 40 场景即 80 %，不相关配方约 82。
- 281 上「seed 噪声 0.03」约一半是场景抽样，checkpoint 本身 sd 约 0.010。
- 新坏惩罚进适应度会更吵（K = 100、λ = 1 时 sd 0.034 → 0.059）→ 均分排序、新坏作否决。
- 切片 = 70 % 过去读数里不一致的场景（只从之前轮次挑）+ 30 % 均匀（每轮重抽）；3 轮平均：60 场景单轮 0.86 → 固定切片平均 0.94 → 重抽 0.97。
- 选超参在 0.02 差上即使场景无限也最多 0.92 排对 → θ 要连续几轮赢；best-of-4 高估约 +0.025；练习场景不进 PLR 与 DAgger 缓冲区。

**基础设施审计**（[infra_audit](../../experiments/round9/results/infra_audit/README.md)）：
- 现在一轮 DAgger 3 h 39 min：推演 718 场景 2.7 卡时（每卡每小时约 230 场景、GPU 利用率 49–60 %，渲染器上限）、推演后串行处理约 47 min（合并重写 35 GB、72 GB 内存）、训练 34–41 min、读 281 每 35 场景块 23 min。nuPlan DAgger 线逐块处理 + 追加，推演到训练完 68 min。
- 训练器能定期存快照、从快照加载权重；不存优化器 / RNG；不能中途改行权重或读增长的池 → 每轮起新训练 job 接着训。
- 设计：一轮约 25–30 min、3 个学习者，推演 r 轮时训 r+1 轮；约 430 次推演 / 轮；卡占用 85–90 %。必需部分约 22–31 智能体小时。
- 与池规则冲突：常驻循环学习者不行（改为每轮一个 job、`--after` 串）；控制器须是队列 job；「每卡一个学习者」与「不手选卡」冲突——**待用户定**。

**当前态度**：先等 PAI 状态 S 行的证据；最小 pilot = P = 3、θ 两维（S 压力、DAgger 份额）、2–3 轮不做 exploit，量时间分布与学习者差是否超过噪声底，超不过就退回固定安排的几个臂。

## 8. 内部信号：从模型体内判断「学到了没有、学得好不好、忘了没有」

用户的想法：结合闭环分数与模型内部（特征、权重、激活变换、探针），感知新学到的东西及其好坏；LLM 上多、RL / 驾驶动作模型上少，是潜在创新点。完整笔记（合并中）：research/round9-internal-signals-lit.md。三路子调查要点：

- **RL 内部诊断**：没有单一健康指标（有效秩、休眠神经元、权重范数）能跨配置预测分数（Gulcehre 2022：超参一扫，秩与表现的关系消失；Lyle 2023/2024：可塑性丧失多因）——只当报警器。遗忘最直接的信号是**更新与旧技能样本梯度的内积**（GEM / MER），小 adapter 多一次反传即得。churn（相邻快照在固定状态集上的动作分歧）几乎免费。我们无 TD 自举，秩塌缩问题较轻，主要盯权重范数 / 有效学习率。
- **从 LLM 搬来的**：最稳的无标签预测是**分歧**（两 seed / 相邻 checkpoint 在同批状态上的输出差，Jiang 2022、Baek 2022）；遗忘按技能用固定探针集与逐样本损失量，并分开「头没对齐」与「表征丢了」（Davari 2022、Jin & Ren 2024）；行来源归因的先例是机器人的 CUPID / DataMIL，最便宜是 TracIn（存档 checkpoint 上的梯度点积）；警告：多数数据配比方法打不过分层抽样（Aioli），有迁移证据的是代理回归（RegMix、DoGE）——PBT 日志也许更适合拟合回归；CKA 可被操纵、SAE 特征跨 seed 只约 30 % 稳定。
- **驾驶 / 机器人可解释性**：50 篇里**没有一篇**在驾驶或动作模型上沿训练 checkpoint 跟踪内部状态并对上分技能闭环变化。已有：单帧解释（saliency、反事实输入）、固定 checkpoint 的运行时失败预警（SelfOracle、ThirdEye、SAFE）、VLA 上的机制干预、只看输出的 checkpoint 排序（CI-MSE 27 checkpoint Spearman −0.87）。最近邻：Jeon 2606.31106（探针误差关联 plan，单 checkpoint）、Molinari 2509.24559（OpenVLA 两个 checkpoint 的探针涌现）、Zhang 2605.28527（冻结 pi0.5 价值探针选动作，26.7 % → 44.3 %）。警告：OpenVLA 探针读状态 > 0.90 但与成功无关；108 个离线指标没有一个预测出 RSSM 闭环崩溃。
- **可写的创新点**：对每个线索（前车在动、停止线、红灯、路线）沿 checkpoint 与训练数据来源同时跟踪 (1) 特征里可读、(2) 策略因果使用（消融 / 反事实）、(3) 对应技能的闭环分，检验内部变化领先还是滞后于闭环变化。冻结编码器 + 只训 adapter 是最干净的设置——线索一直可读，变的只是 adapter 用不用。接上已有的「知道 vs 做到」（d362 / 373 / 383，[knowing-vs-doing.md](../knowing-vs-doing.md)）。
- **验证先于使用**：约 25 个存档 checkpoint（NTV0、RSG、JTN、R2C/R2J、R3MV、R5LC、R6FIX、R6DAG ×3、R8K ×3、R7J、DAG2 …）都有 281 逐场景分与失分类别——先离线检验哪些内部信号能预测按类的闭环变化，过了才进循环当快反馈。
