# 「知道」与「会做」：驾驶智能和驾驶能力分开（论文主线候选，2026-10-19，工作笔记）

## 1. 主张

**「知道」和「会做」是两套系统，各有各的学习规则。** 神经科学里有双分离：

- H.M. 不能形成新的陈述记忆，每天都不记得练过镜像描画，描画却一天比一天好（会做在长，知道没有）。
- 小脑受损的病人清楚目标在哪、该做什么，戴上棱镜后投掷却适应不过来（知道还在，会做学不了）。
- Ryle 的 knowing that / knowing how 是同一区分的哲学说法。

所以「驾驶智能」和「驾驶能力」分开不只是直觉，可以作为论文主张立住：

- **驾驶智能**：看懂世界、预测别人、知道该做什么。能靠观看学，换车、换城市基本带得走。
- **驾驶能力**：在自己的车身、动力学和延迟下，在对的时刻把意图实现到容差以内。只能从自己动作的、可归因的后果里学，绑定在这个身体上。

## 2. 能力取决于「可归因的试次数」，不是驾龄

车道里转向人人会，停车很多人一直不会。差别不在动作难不难：

| | 车道里转向 | 倒车入库、侧方停车 |
|:--|:--|:--|
| 参照在哪 | 在世界里，车道线就在眼前 | 在自己身上：车角、车尾扫过哪里都看不见 |
| 误差能否归因 | 零点几秒后看到偏了，知道是哪一下 | 几秒后才发现歪，说不清方向打早了还是打晚了 |
| 能否当场修 | 能，小幅修正 | 往往不能，只能前后挪着重来 |
| 有效练习次数 | 每秒一次，一小时上万次 | 一天一两次，多在同一车位 |

运动学习研究里较确定的五条：

1. **必须自己动**：Held & Hein 1963 小猫转盘（看到同样画面，只有自己走的那只学会视觉引导动作）；Iriki 的猴子：耙子要主动用才并进身体图式。
2. **先预测，再比对**：小脑前向模型在动作发出前预测身体会到哪，学习信号是预测与实际之差。
3. **预测把延迟后果变成当下可归因的误差**：打方向时就预测到三秒后车尾碰柱，这个误差当下就归到这一把方向上。
4. **在能力边缘、变化着练**：Ericsson：练到「够用」、自动化以后多年不进步；Schmidt 图式理论：变化练习学到可泛化的映射，恒定练习只学到那里管用的习惯。
5. **从靠反馈修正到提前做对**：Kawato 反馈误差学习，修正本身是训练提前量的信号；熟练的标志是需要修的越来越少。

任务按参照分两类：**参照在世界**（跟车道、跟车：好眼睛 + 模仿就能做好）；**参照在自己**（起弯点、到点停车、起步时机、入位：只能靠练）。

## 3. 和我们的读数对上

我们的模型是坐吊篮的那只小猫：冻结的 Cinque 眼睛是智能，模仿人类日志相当于看别人开车。失败的地方和人类新手重合：直路车道保持没问题，
路口转弯、到点停车、起步时机不行。

| 读数 | 在这个框架里 | 性质 |
|:--|:--|:--|
| S 的 agent / road hinge 是唯一各考场一致有用的训练项（第 286 条：RSG 对 YS2G −15.5 零分） | 在出 plan 那一刻用 4 s 车身扫掠判断会不会撞、会不会出路，只在越界时罚：替模型做了前向预测，把几秒后的后果变成当下可归因的误差（第 2、3 条） | 读数强；对应关系是解释 |
| 自身状态上的几何目标都伤避让（第 286 条 RBSG2、第 297 / 303 / 321 / 323 条），规则专家 DAgger 闭环 held 零分 +38（第 321 条） | 教练抢方向盘：给了「正确路线」，没告诉是哪一下错了 | 读数强；机制是解释 |

## 4. 要直说的边界

- **路口有一部分是智能问题**：冻结眼睛在路口看不准近处可行驶走廊（第 283 条，R-A 0.99 m 对 0.5），人没有这个问题。路口失败要拆成智能与能力两部分讲。
- **「加眼睛、训编码器都没涨分」不能这么写**：路口眼睛那条线在第 1 步就停了，没训过臂（第 283 条），只能说「没测过」。第 341 条只说明保留线没丢横向通路。
- 「反应是差分」（上一轮提法）管的是「什么时候该动」，是智能到行动的接口，可以当一个零件；能力的本体是「动了以后身体能不能做到」，即自我预测加练习结构，才够格当主干。
- 「数据越多越强」要改成：该数的是**可归因的试次**，不是行数或小时数。
