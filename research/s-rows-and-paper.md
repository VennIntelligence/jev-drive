# S 行：现在的分布、做过和没做过的、能写成什么论文（2026-10-21 工作笔记）

用户 10-21 的问题：S 行是不是系统里最大的杠杆？里面现在是什么分布？加量 / 减量、过采样零分 / 部分分、不再喂满分行、
缩小人类模仿行把预算给 S，这些试过没有？除此之外，手上还有什么能写成 CVPR 论文？
本页先给测量（第 1–2 节），再给历史（第 3–4 节）、文献（第 5 节）、提议（第 6 节）和论文候选（第 7 节）。
数字都来自盒上已存文件或 decisions.md 的行，第 1–2 节的新测量全是 CPU、0 卡时，脚本 [s-rows/audit.py](s-rows/audit.py)，
输出在盒上 `$DATA_DIR/runs/s_rows_audit/`（`audit.json`、逐行 `rows_audit.parquet`、来源场景结局 `outcome/per_scene.csv`）。

**先读这几个词**
- **S 行**：我们自己的模型在 AlpaSim 闭环里开到的状态（离日志可能已偏），行上不给模仿目标，只在训练时对**当前模型的 plan** 算后果 hinge（只在越线时才罚的损失）：
  本车 4 s 扫掠足迹对他车框（agent）、对道路车道栅格（road），10-17 起加对向车道点项（lat_onc）、同向他车道软项（lat_soft）、旁车侧缓冲（lat_side）。
  梯度只改 plan 形状（shape-only）。**激活** = 该项在这一行的当前 plan 上 > 0；不激活的行对 plan 没有 hinge 梯度。
- **压力**：每批 S 行数 × ho_w（S 项的行权重，现在 3）÷ 该批模仿行数，按 d311 的定义折成 RSG 配方的倍数（RSG = 1×）。S 项按「行求和 ÷ 模仿行数」进损失，
  所以压力就是 S 项对模仿项的相对拉力。
- **抽取**：训练每步按 `--on-wfile` 的行权重从池里抽行；**live 行** = 权重 > 0 的行（S 池按 log 留出 15 %，`--on-hold-pct 15`，留出行权重 0）。
- **来源场景结局**：产生这一行的那次 rollout（滚池用的旧策略、18 决策、train 场景）在该场景的得分：0 = 零分，(0, 1) = 部分分，1 = 满分。**不是**当前模型的结局。

## 0. 结论先行

- **当前配方（R6DAG）每批 136 行里 S 只有 32 行（23.5 %），而且只有约 23 % 的 S 抽取对 plan 有梯度**；再扣掉「人的恢复路径也违反」或「t0 就在栅格外」的行，
  真正可学的激活行只占 S 抽取的 12.3 %，约每批 3.9 行。S 池 100 % 是 nuPlan 市区行（> 13 m/s 的只有 0.9 %），由 4 个 10-12/13 的旧策略滚出，从没用当前谱系刷新，
  也没有一行 PAI 自身状态的 S 行。
- **用户的直觉「满分行是陪跑的」测出来是对的**：来源满分场景的行占 S 抽取 56.5 %，只带 15.2 % 的 hinge 量；来源零分场景的行只占 11.0 % 的抽取，却带 57.8 %。
  hinge 量极度集中：前 1 % 的行带 54 %，前 10 % 带 96 %。但「零分行」里也混着大量学不动的行：1.4 % 的行（t0 已出栅格）带走 road 项 66 % 的量，
  这些行在 RB0 → NTV0 的整个 L18 训练里只有 0.2 % 被满足。
- **S 的剂量已经扫过，分布从来没调过**：剂量（每批 13 / 26 / 32 / 51 / 64 行，压力 1–8.6×）、轮次（第 2 轮、聚合）、新起点、PAI S 行（只带 agent 项）都试过，
  全长读数上 2.4–2.9× 附近最好，再加就伤；但按激活 / 按结局 / 按可学性重采、去掉不激活行、带重要性修正的按类配平、在当前配方里缩 navtrain 换 S、
  带道路栅格的 PAI S 行，**一次都没做过**。
- **S 是不是最大杠杆**：第一次加进去时是 nuPlan 上最大的单次训练增益（YS-L18 对底座 +0.053、对同续训 +0.145；RSG 零分 59 → 34），但 10-13 之后 PAI 上的增益来自
  模仿构成（NTV0 去 trainval 行）、serve（ACC + GAP）和 DAgger（R6DAG），S 的剂量 / 来源改动全是平或负。所以准确的说法是：**S 是一个只调过剂量、没调过分布的杠杆**；
  现有读数不足以说它比别的杠杆大。第 6 节给三个便宜的实验来回答。
- **论文**：最强的候选是把 S 行写成方法（label-free 的自身后果练习，「知道 vs 会做」作分析半边），文献子代理没找到完全相同的做法；
  最大缺口是跨榜：AlpaSim nuPlan 的训练场景就是 navtest 的 log，带这些 S 行的 checkpoint 永远不能报 navtest / navhard（recipes.md）。第二候选是本地 PCS 尺子（方法学）。

**从来没测过的**

4. 按情境 / 按后果项配平（前车、转弯、自由路、站着；agent 对 road）并做重要性修正（group DRO 式）。

8. 当前配方里的剂量扫描（JTN 起压力一直 2.4–2.9×，没在 R5LC / R6DAG 上重扫）。

## 4. 机制上能说的和不能说的

- 能说：S 项与模仿正交、在池上几乎不被学完；梯度只落在 12 % 的抽取上；量集中在零分 / 前车 / 晚决策 / 偏离日志的行；满分来源的行几乎不贡献。
- 不能说：「多给激活行就更好」。剂量历史是倒 U：压力 1.9–2.9× 附近最好，5.8× 与 8.6× 变差（d311、d348），而按触发行聚焦（d386）伤了 PAI。
  聚焦等于在激活行上加压力，所以要么做重要性修正（期望梯度不变、只降方差），要么同时把 ho_w 降到同压力，否则分不开「分布」与「剂量」。
- 不能说：「零分行最该过采」。零分行的量 2/3 是学不动的行，RHO-LOSS 的警告正好对上；部分分行的可学量密度最高。
- 结局是滚池旧策略的结局，不是当前模型的；当前模型在这些状态上会怎样，只有激活率是直接量。

## 6. 直觉与提议

直觉：S 行像「练习」。现在的练习单是 4 个旧学生在 nuPlan 市区练出来的，每次练习 77 % 的题目已经会了，剩下的一半是题目本身有错（栅格 / margin），
真正「会错、能改」的题只占八分之一，而且没有一道是 PAI 高速路上的题。剂量已经扫过（再多就伤），所以下一步该调的是**练哪些题**，不是练多少。
按 research-method 的规则：先离线指标，再一条联合臂，早停闸写死；不做析因。
