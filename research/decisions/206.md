定义：innovation = 日志（或 plan）4 s 位置相对「最近 1.5 s 历史的恒曲率恒加速度外推」在其 Frenet 系下的横向偏移与弧长差；gain = plan innovation 对日志 innovation 的 OLS 斜率；top-decile = 日志 |innovation| 最高 10% token 上的斜率。navtest 12 027 token，按 136 个 log 的 cluster bootstrap。

1. **登记判定**（D = WA-JEPA − SH30 的 top-decile gain，S = 对 WA-JEPA 的 −2.16 分差落在该轴最高三档的份额）：横向 D +0.026 [+0.016, +0.038]、S 56.8% [44.3, 72.5]，判**部分**；纵向 D +0.068 [+0.053, +0.084]、S 38.7% [27.8, 52.3]，判**证伪**；联合分位 S 52.4%。P1（差 ≥ 0.10）两个轴都不成立。
2. **横向的「部分」来自分差所在的位置，不来自响应不足**：同一弧长处比较路径，SH30 0.976 / top 0.986，WA-JEPA 0.982 / 0.987，差 +0.002 [−0.003, +0.005]；2 s 处 SH30 的横向 gain 反而高（0.948 对 0.932）。时间对齐下的 0.03 是 plan 沿同一路径走得短。与第 178 条（无全局欠转）一致。
3. **纵向有一个小的真实缺口，但分差不在 innovation 大的地方**：去掉机械项的偏 gain 0.796 对 0.887（差 +0.091 [+0.078, +0.104]）；只看 v0 ≥ 2 m/s 的 token，top-decile 差 +0.119 [+0.091, +0.143] 过了 0.10、S 43.2%，判定格变成「部分」；匀速直线外推下差只有 +0.026、S 24.0%。纵向判定格依赖定义，可信度比横向低一档。
4. **阶梯**（横向 / 纵向 gain）：均值轨迹 0.37 / 1.71（纯机械项，偏 gain 为 0）；不看画面的回归（ego 历史 + 指令，navtrain 拟合）0.842 / 0.778；shipped Cinque 0.656 / 1.005（截距 −3.6 m）；P2 0.948 / 0.864；RMH10 0.945 / 0.863；SH30 0.941 / 0.869（两 seed 0.941、0.940 / 0.871、0.867）；OT30 0.940 / 0.868；AP2 0.937 / 0.858；泄漏日志路径且学会读的 GEP s1 0.964 / 0.920，没学会的 s0 0.924 / 0.834；WA-JEPA 0.971 / 0.935。按这个定义，日志 innovation 的方差有 78–85% 可以不看画面预测：它大部分是运动学延续，不是场景。
5. **分数挂钩**（一个 innovation 方法的上界）：横向最高三档 1.23 EPDMS，纵向 0.84，联合 1.14。NC 失败（第 196 条）最高三档份额横向 27% [18, 36]、纵向 41% [30, 53]，均匀是 30%，57% 落在横向最低五档；DAC 失败横向 61%（切内角与转不过去各 64%），WA-JEPA 自己的 DAC 失败也有 54% 在那里。
6. **P3 被否，方向相反**：转角桶对比（> 45° 相对 < 5°）单独 −7.29 [−9.19, −5.20]，加入 innovation 后 −7.86 [−10.22, −5.42]；横向 innovation 对比（最高档相对最低五档）单独 −4.36 [−6.35, −2.15]，加入转角桶后 −0.66 [−2.80, +1.75]。out-of-fold R²：innovation 对转角桶的增量 −0.0003 [−0.0029, +0.0020]，转角桶对 innovation 的增量 +0.0099 [+0.0032, +0.0162]。两者 Spearman 0.76；分开的地方由转角决定（< 5° 而横向最高 quintile 的 232 个 token 分差 −0.11）。
7. **虚构的变化**：日志延续的 870 个 token（两轴最低三档、v0 ≥ 2 m/s）上，SH30 的横向 |plan innovation| 均值 0.145 m，WA-JEPA 0.063 m（差 +0.082 [+0.068, +0.099]），P2 / RMH10 0.077 / 0.078；≥ 0.5 m 的占 4.0%（WA-JEPA 0.8%），≥ 1 m 的 0.7%。台阶出现在 λ 10 与 λ 30 / 0.5 m 的臂之间（事后对比，未登记）。纵向与 WA-JEPA 持平。第 202 条的 1–2 m 横移在 navtest 开环里不出现。
8. **图像消融**（此前没有条目回答；第 173 条是 WOD 上的选择器，第 183 条是 WA-JEPA）：SH30 两个 seed、navtest 全量，前视 token 换成另一个 log 里运动学最接近的 token（匹配距离中位 0.05 sd），ego / 历史 / 指令原样；不换时逐位复现存档 plan。横向 gain 0.941 → 0.576 [0.540, 0.610]，R² 0.95 → 0.37，top-decile 保留率 0.68 [0.65, 0.72]；纵向 0.869 → 0.693，保留率 0.78 [0.75, 0.82]。按登记读法两轴都在 0.5–0.8 之间，「视觉对变化几乎没有贡献」不成立；换图后的横向 gain 远低于不看画面的回归（0.84），说明画面与运动学冲突时 plan 跟画面走。
9. **navhard stage 1**（450 token，G 帧，只给 gain）：时间对齐下横向 0.784 对 0.940，但 G 帧 plan 普遍短 2.6 m；等弧长下 SH30 1.025 [0.987, 1.066] 对 WA-JEPA 0.961，不低。WOD val 与 HUGSIM 跳过（没有可拆的分差；闭环 plan 没有对应的日志未来）。

**对方向的含义**：navtest 上对 WA-JEPA 的差距不是「不会从画面决定变化」，plan 对日志变化的比例响应与 WA-JEPA 只差 0.03 / 0.07，差距仍是转弯 token 上的精度（第 153、170、178 条的结论不变）。以「提高 innovation gain」为目标的方法在横向没有空间；纵向在行进 token 上有约 0.1 的 gain 缺口，但它不对应分差的集中处，NC 失败也不在高 innovation 档。新得到的两个可用读数：强 hinge 臂在直行 token 上多出约 0.07 m 的横向虚构变化（与 AlpaSim 横移同号的开环量，量级小一个数量级）；SH30 的 plan 在换图后明显改变，论文里「换掉当前相机」的对照臂（plan.md 第 6 节第 6 点）有了第一组数，但还没有分数。
**状态**：**成立**（中）。限定：开环、日志状态；gain 是斜率，量比例响应不量精度；纵向判定格随外推定义翻转；日志 innovation 本身大部分可由运动学预测，更干净的标尺（扣掉不看画面的预测后的残差）没有登记也没有算；换图同时注入了另一个场景的内容，保留率不是方差分解；消融后的 plan 没有打分；hinge 与虚构变化的关系是事后对比；WA-JEPA 单 checkpoint，SH30 两 seed，有分差的榜只有 navtest；pool 作业申报 8 GB、实测峰值 14.4 GiB。
**会推翻或推进本条的证据**：以不看画面的预测残差为标尺重算后 SH30 与 WA-JEPA 的 gain 差超过 0.10；闭环（AlpaSim / HUGSIM）状态上的同一读数显示响应不足；消融后 plan 的 EPDMS；λ 10 与 λ 30 配对臂在 AlpaSim 直行段横移上的差。
