# 294. SLOW-NOVELTY（不训练、不用 GPU，只读已存 held 460 读数）：去掉或控制速度历史棘轮之后，剩下的变慢**不随状态新奇度变化**。按登记规则判为「纯输入回路」，新奇度只是小项：新奇块只多解释 0.11 % 的方差（登记线 5 %），只有偏离日志路径一项的 CI 过 0（−0.041 SD，约每 0.57 m 偏离对应 plan 短 5 cm）；航向误差方向相反；路口内车速比路口外更接近日志。用户的假设（「进入没见过的状态才慢，学了人的谨慎却没学人的解除条件」）作为残余变慢的主因，在这批读数上不成立。

- 日期 2026-10-14（box CPU，12 worker，GPU 池外）。预登记 `experiments/route_follow/plans/2026-10-14-slow-novelty-prereg.md`（6df8f422，在任何统计量之前提交）。
  脚本 `experiments/route_follow/scripts/rf_slownov.py`（+ `.sh`），结果 `experiments/route_follow/results/slow_novelty/README.md`（`slownov.md` / `slownov.json`），
  图 `experiments/route_follow/figs/slow_novelty_bins.png`、`slow_novelty_onset.png`；逐决策数据在 box `runs/route_follow/slownov/data/decisions.parquet`。
- 数据：RSG-L18-s0 在 held 460、18 个决策上的三份读数：RSG（棘轮在）、RSG+hold（速度历史保持，第 286 条）、RSG+holdlead（复现）。
  单位是一个决策，沿用 rf_deficit 的保留规则；保留的决策数和中位数与 rf_deficit 的表逐项相同（7217 / 7214 / 7205，−0.258 / −0.068 / −0.069 m），说明用的是同一把尺。
- 结果 Y1 = plan 2 s 欠量（plan 2 s 弧长 − 2 × 实测车速），Y2 = 车速 / 同一弧长位置的日志车速。
  新奇度三项：偏离日志轨迹的距离 lat（中位 0.12 m、p90 0.90 m）、相对日志切向的航向误差 head（中位 0.7°、p90 4.7°）、rf_follow 路口段 junc（4.7 % 的决策）。
  基础块：日志在同一位置自己的 2 s 欠量和车速、距上次停车的时间、决策序号，以及棘轮变量：喂入车速、喂入车速趋势（当前减 1.5 s 历史均速），hold 读数另加 held。
  方法是标准化 OLS，报新奇块相对基础块的 ΔR²；CI 用日志聚类 bootstrap（39 个 log，2000 次）。
- 主模型（RSG+hold，Y1，基础块含棘轮变量）：基础 R² 0.784，**ΔR² +0.0011 [+0.0002, +0.0038]**；lat −0.041 [−0.082, −0.008]，head +0.016 [−0.016, +0.052]，junc −0.004 [−0.024, +0.014]。
  各变体的 ΔR² 都低于 5 %：不加棘轮控制（按任务书原式）0.006（这时 head **+0.065**，CI 过 0，方向与假设相反）；场景固定效应 0.001；Y2 0.001；holdlead 复现 0.0016；
  RSG 带棘轮 0.0017；RSG 不加控制 0.009；RSG 的 Y2 0.024（这时 lat **+0.130**，偏得越远反而越不慢）；
  事后变体（把日志欠量当固定偏移，结果改为超额欠量）1.0 % / 2.8 %，junc −0.064 / −0.069，CI 过 0。
- 棘轮的输入端特征很强：喂入车速趋势的标准化系数 +0.71 到 +0.86，加上它 R² 从 0.53 升到 0.78–0.82，plan 把喂入的加减速延续下去。
  hold 读数里也是这样，因为 hold 只覆盖 33 % 的决策，54 % 因为转弯命令被释放。
- 起点（RSG）：超额欠量阈值取 10 % 分位 −1.68 m，163 / 450 个 rollout 达到（起点决策中位数 6），131 个起点前至少有 2 个决策（32 个 log）。
  起点处 lat 比同一 rollout 之前的决策大 +0.34 m [+0.24, +0.44]，比同一决策序号上从不变慢的 rollout 大 +0.21 m [+0.07, +0.33]，按登记规则算「lat 支持起点」。
  但对齐图显示：超额欠量从起点前约 4 个决策（2 s）开始逐步下滑，lat 跟着同步上升（0.17 → 0.42 m），并不领先；2 Hz 分不出先后，「新状态导致刹车」和「变慢漂移的车离开日志路径」都说得通。
  下滑开始时喂入车速趋势还是正的（车在加速），起点前约 2 个决策才转负：第一下变短不是减速的速度历史引起的，棘轮在 plan 开始变短之后接管。
- 假设没料到的：（1）相对变慢出现在普通路段，不在新状态里（RSG 的 Y2 中位数：路口外 0.92，路口内 0.98；hold 把路口外拉到 0.98）；
  （2）航向误差大时 plan 更长（转弯出口、纠偏都在加速段）；
  （3）路口效应藏在人自己的加速里：路口段人的 2 s 欠量 +1.14 m，plan 只有 +0.48 m，出弯时 plan 加速比人晚，与第 293 条一致，不是在新状态里踩刹车。
- 量不到：特征空间新奇度（冻结 Cinque token 到 navtrain 训练状态的 kNN 距离）。读数里没存 token 也没存画面（images.jsonl 只记字节数），只能用几何代理。
  做特征版需要：driver 加一个按决策导出 pooled token 的开关（约 1 h 改代码加 smoke）；重读 RSG 和 RSG+hold（12 个分块 × 约 8 min ≈ 1.6 卡时；开关关闭时 plan 逐位复现，决策能一一对上）；
  再在 CPU 上对训练行的 token 缓存做 PCA 64 加 kNN（几分钟）。
- 证据：弱（一个 checkpoint、一个 seed；held 460 已在 RSG-L18 的训练侧；回归是相关，不是因果）。
- 用途：残余变慢的修法仍在速度从哪里来（第 286 / 292 条的速度锚、第 290 条分支行带速度目标），不在「见没见过」；状态新奇度不作为 P4 示范行的优先条件。
  若还要追 Cinque 特征版，按上面的成本做，不在本条范围。
