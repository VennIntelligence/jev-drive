# 102. 指令走天空箭头（测试时只用导航指令和到路口距离，不画在路面、不用地图）：zero-shot 无效；微调能训进去（吸收 nav 0.29 / CARLA 0.39，车道保持不变），但路口无覆盖漂移 0.13–0.27 m 过不了 0.10 m 护栏，且部分学成了「天空有品红就转」（**待定**，navtrain 385 / CARLA 测试 225 样本，单 seed，开环）
2026-10-04。按用户对第 99 条的意见改向（禁用遮挡类覆盖物与白色路面标线，测试时不许用地图几何，首选天空浮动箭头）。预登记 [experiments/op_img_cmd/plans/2026-10-04-img-cmd-ft2-prereg.md](../../experiments/op_img_cmd/plans/2026-10-04-img-cmd-ft2-prereg.md)（三个按时间追加的附录），结果 [experiments/op_img_cmd/results/ft-q3.md](../../experiments/op_img_cmd/results/ft-q3.md)，审阅图 `figs/sky_sheet.png`。由另一位执行者完成；本条由 main 按其报告写，没有复算。

1. **共同改动**：蒸馏池扩到约 6 600 帧（nav / WOD / CARLA）；CARLA 179 个路口按路线分训练 101 / dev 18 / 测试 60；目标取残差形式（原计划 + 指令支路与原模型所选支路的中心线差），速度剖面保留原模型的。
2. **天空箭头**（品红，固定在地平线以上，大小随导航距离）：zero-shot 吸收 0.00（只让计划缩短 0.6–1.2 m）。微调 SA：吸收 nav 0.29 [0.23, 0.34]、CARLA 0.39 [0.37, 0.42]，correct 0.71 / 0.78（不加覆盖 0.50 / 0.45），车道保持不变；路口无覆盖漂移 nav 0.13、CARLA 0.27 m。SB 在 nav 上过 0.10 m 线（0.09），但吸收只剩 0.13 / 0.23。
3. **对照不干净**：CARLA 上不带信息的品红圆盘让 SA 的 4 s 横向移动 3.0 m（原模型 0.28 m），指向不存在出口的箭头 7.5 m（原 0.29 m）。学到的一部分是颜色信号，不是指令。
4. **天空箭头 + 感知放置的绿线**（模型自己车道线中线 + 固定半径圆弧，单独一臂）：correct 0.82 / 0.84、吸收 0.33 / 0.39，漂移更大（CARLA 0.37 m）。zero-shot 吸收 ≤ 0.05。
5. **护栏为什么过不了**：普通帧漂移只有 0.04–0.08 m，超标集中在路口；原模型自己在路口就敏感：一个不带信息、不挡路的天空圆盘就让它的计划移动 0.17 / 0.24 m。0.10 m 的绝对线低于原模型自身的敏感度。main 决定改为相对口径（路口漂移 ≤ 原模型对无信息圆盘的变化，普通帧仍 0.10 m），这是看过数据后改的，附录里写明。

6. **加负样本这一轮**（2026-10-04 下午）：NA（负样本：无信息圆盘、指向不存在出口的箭头、直路上的直行箭头，教师都是原计划）把圆盘的干扰修好了（CARLA 0.36 m，原模型 0.28，SA 3.0），过相对护栏（nav 0.12 / CARLA 0.25 m，线 0.17 / 0.24），CARLA 吸收 0.30 [0.26, 0.33] 正在线上，navtrain 掉到 0.18；但指向不存在出口的箭头仍被执行（CARLA +5.7 m，原模型 −0.2 m），dev 上没过，按预登记停。这个对照可能有缺陷：「不存在」是按本车道的连接道定义的，出口可能从别的车道存在，没有核对。闭环里官方路线指令总是可行的，所以 main 决定把闭环 smoke 当诊断跑（NA、SA 对 drive，27297 / 27043 / 9196 / 24944，2 seed）。

**对方向的含义**：纯感知、非特权的图像指令通道可以训进 openpilot（开环吸收约 0.3–0.4），用户提出的天空箭头在不遮挡场景的前提下可行。负样本去掉了颜色捷径，但箭头被当成必须执行的转向、不管那条路是否存在；第 103 条显示指令在 NAVSIM 两榜上只值约 3 分，这条线的读数改为 B2D 闭环转弯。
