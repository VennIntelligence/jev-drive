# 80. op-adapt L 的数据量曲线与 start gate：每类约 110 个整段（约 110–120 个独立事件）就拿到全量捕获增益的 82–95%，300 段饱和；假起步随 start 增益一起出现；用原模型特征训的起步开关 AUC 0.77，压住了假起步但 start 增益只剩 +0.037，没有超过蒸馏权重扫描的前沿（**待定**，WOD val，curve 每档 2 seed、gate 用 `main` 3 seed，只有 Cinque）

接第 78 条。两个问题：少量专家轨迹能不能教会模型（learning curve，学习曲线：每类取 25 / 110 / 300 / 全部整段的模仿帧，对照帧、其他帧与步数同 `main`）；假起步能不能不靠提高蒸馏权重压下去（start gate：在原模型 stage 4 特征上训一个小头，预测停着的帧 4 s 内人会不会起步，只在静止帧上决定用 `main` 还是原模型的 plan）。

1. **约 10² 个事件 / 类就有训练价值**：110 段三类都过登记的「学到」线，300 段按登记的配对非劣界饱和，110 → 全量只再多 0.014–0.021。第 77 条说的「上千个独立事件」不是必要条件；第 75 条 NAVSIM 打分头要 2 万行才起作用的量级不适用于这种「在冻结大模型上只补几类行为」的适配。**这修正了 main 在 2026-09-30 讨论里的判断「几百条标注对 3.8 亿参数的 policy 差两个量级」**：在同域相机、真实人类轨迹、带完整对照帧与蒸馏的条件下，每类百级事件就够。25 段只教会 stop。
2. 限定这句话的范围：小档位的对照帧、other、nuScenes 池仍是完整的（25 段 / 类时联合训练段 74 个，但对照池不变），步数固定 4 000（小数据重复曝光更多），所以读的是「模仿标签的数量」，不是「总数据量」。手工画的轨迹不在此列，误差量级不同（复核备忘 §3）。
3. **假起步是 start 增益的伴生物，不是数据量问题**：25 段没有假起步也没有 start 增益；110 段起两者一起出现。25 段档的 RFS 还显著变差，少量模仿不是无害的。
4. **gate 没有打破取舍**：静止帧上 AUC 0.774 [0.738, 0.808]（G0 过），说明 1.6 s 前视里有可读的起步信息但远非可分；锁定阈值后 stay 假起步 +0.58 pp（过线），start 增益只剩 +0.037（线 +0.07，不过），对旧前沿的余量 +0.010 [−0.017, +0.027]，CI 跨 0。「假起步只有 dw 能压」（第 78 条已改过措辞）现在多了一个测过的替代，结论是它落在同一条前沿上。
5. 偏离里影响解释的一条：gate 的 dev 段曾被 `main` 训练过（D1），阈值选择可能偏乐观；val 上的结论是失败，方向上不受它影响。

**状态**：**待定**。限定：WOD val 被第 78 条与这里重复用过，不是新的留出；每档只有一份段名单、2 个 seed，CI 不含训练 seed 与名单方差；gate 只试了线性头与 32 维 MLP，AUC 0.77 不是输入的信息上限。
**会推翻或推进本条的证据**：换一份段名单或更多 seed 后 110 段的三类增益掉到全量的 60% 以下；在另一个域（CARLA 或 HUGSIM 场景）用每类约 100–300 个事件做同样的适配，留出读数不涨（那样「百级事件够用」只在 WOD 同域成立）；一个带时序或更大容量的起步头把 AUC 提到 0.9 以上并让 gate 过 G1 与 G6（取舍是头的容量问题，不是信息问题）。
