# 243. 冻结视觉 token 上的「转弯描述」head（HEAD1，stage 1）：以日志路径的 heading 对弧长曲线为标签、navtrain 全量、log 级 fold 训练的 head，在 navtest > 45° 上按 plan 自己的 4 s 弧长读出的 heading 误差 RMS 8.54° [7.47, 9.53]，SH30 自己的 plan 11.24°（−2.70 [−3.57, −1.74]），无视觉的同款头 15.13°，特权地图标签 7.04°；但误差与 policy 相关（对 pilot policy corr 0.53），登记的独立性统计量 R² 0.513 [0.420, 0.586]，线 0.538（按第 204 条换算的 pilot 增益 +0.48 对 +0.5），stage 1 按登记规则在独立性上不过（边缘档），memory 通道 pilot 未跑；对全量 SH30 R² 只有 0.278（换算 +0.26）；日志路径标签优于地图标签；学习曲线到 834 个 log 未饱和（**中**：离线，一种头、一组超参，闸门只读 fold 0 的一个模型，seed 间有差）
2026-10-10。lane HEAD1，接第 240、204 条（第 204 条「会推翻本条的证据」的前半：同一份冻结特征上、log 级 cross-fit 的非特权 heading 预测）；邻居第 207、223、191、192、200、166、165、160、147 条。预登记 [experiments/corridor/plans/2026-10-10-head1-prereg.md](../../experiments/corridor/plans/2026-10-10-head1-prereg.md)（任何 head 读数之前提交并 push），结果 [experiments/corridor/results/head1.md](../../experiments/corridor/results/head1.md)，全表 `results/head1/tables.md`、`reads.json`、`gate.json`，图 `experiments/corridor/figs/h1_*.png`。执行者完成并写本条。地图、日志未来、日志所走车道序列只作训练标签与分析参照；head 推理时只读冻结 Cinque 视觉 token（8 slot × 32 × 512）+ 20 维 ego（含 command）；没有用 WA-JEPA 的权重或特征；没有解冻、没有闭环、没有把任何信号喂给 policy。

设置：标签 = 相对 t0 heading 的 heading 在 22 个弧长点（0–40 m 每 2.5 m，另 45–80 m 五点）上的值。L = 日志后轴 heading 按日志路径自身弧长重参数化（去掉时间轴）；M = 第 240 条匹配出的车道序列 centreline 的切向；C = 两个通道一起学。head = BODY1 S0 的 scene memory + 22 个弧长 query，3.4 M 参数，8 000 步，一组写死的超参。fold = 第 191 条的 log 级 fold：fold 0 的 head 与 fold policy `CF5f0-F-s0` 见过同样的 834 + 89 个 log，245 个 dev log（21 438 token）对两者都 held-out；navtest 不参与拟合与选择。主量与第 240 条 N3 同口径：预测曲线在 plan 自己的 4 s 弧长处的值 − 日志 4 s heading。按 log 的 cluster bootstrap，B 10 000。arm 在 held-out navtrain 上选（> 45° RMS：L 7.93、C 8.11、M 9.26 → L）。

1. **闸门**（navtest，arm L、fold 0、seed 0）。G1 准确：> 45°（1 517 token × 2 seed）head 8.54° [7.47, 9.53] 对 `SH30-F` 的 plan 11.24° [9.87, 12.51]，差 **−2.70 [−3.57, −1.74]**，过。G2 高于 floor：head − blind **−6.59 [−7.66, −5.51]**（blind 15.13°），过。G3 独立：全体 token、对 pilot policy `GH0-F`，R² = corr(e_p, e_p − e_h)² = **0.513 [0.420, 0.586]**，corr(e_h, e_p) 0.53 [0.46, 0.59]，线 0.538（0.93 × R² ≥ +0.5），换算增益 +0.48，**不过，落在登记的「边缘」档**（≥ +0.3、< +0.5）。按登记规则 stage 1 不过，失败的是独立性，不是准确度；stage 2 未跑。seed 1 的同一个头 R² 0.447，没有任何 arm / seed 到 0.538。
2. **各桶**（navtest，head L s0 / policy / R²）：对 `SH30-F` 全体 5.05° / 5.71°（−0.65 [−1.03, −0.25]）R² 0.278 [0.205, 0.344]，> 20° 7.91° / 9.59° R² 0.351，> 45° R² 0.433；对 pilot `GH0-F` 全体 5.27° / 7.38°，> 20° 8.41° / 12.90° R² 0.584，> 45° 9.02° / 15.60°（−6.57 [−8.20, −4.75]）R² 0.666。held-out navtrain（fold policy）：> 45° 7.93° 对 9.90°（−1.97 [−2.63, −1.29]），R² 0.381；全体 4.93° 对 5.31°，R² 0.236。**对全量 policy 的换算增益只有 +0.26**：head 的优势在弱的 pilot policy 上最大，policy 变强就缩小。
3. **误差的构成**。日志曲线本身在 plan 的弧长处读就差 5.26°（> 45°，SH30；这是 policy 的行程误差，按构造共有）；head 在日志自己的 4 s 弧长处（特权弧长）> 45° 是 7.49° [6.37, 8.47]。等弧长比较（> 45°，对 SH30 的 plan 曲线）：5 m 处 3.89° 对 3.73°（不比 plan 好），10 / 15 / 20 / 30 m 处 −0.73 / −1.88 / −2.38 / −1.38°，R² 0.29 / 0.47 / 0.56 / 0.52：head 赢在弯的后半段（弯在哪结束、出弯指向哪）。blind 头的误差与 SH30 的相关 0.66 而 R² 只有 0.013。
4. **入弯点**（heading 曲线沿弧长的平移拟合，晚为正；不是第 240 条的位置拟合）：> 45° 上 head 中位 +0.10 m、均值 +0.12 [+0.03, +0.21]，SH30 +0.40 / +0.46 [+0.36, +0.54]，|δ| 均值 0.78 对 0.90 m（−0.11 [−0.19, −0.03]）；SH30「转不过去」的 75 个 token-seed（26 个 log）上 head 中位 +0.90 m、policy +1.50 m，|δ| −0.36 [−0.67, −0.02]：head 没有系统性的晚，但在 policy 转不过去的 token 上自己也晚，这类失败大半是共有的。
5. **标签来源**：L 胜。navtest > 45°：L 8.54°（seed 1 9.47°）、C 9.03° / 9.70°、M 10.07° / 10.53°；对 `GH0-F` 的 R²（全体）0.513 / 0.447、0.473 / 0.440、0.427 / 0.390。地图标签自身对日志 heading 就有 7.04° 的偏差，在它上面训的头把这部分偏差叠在自己的误差上（对各自标签的拟合 M 并不比 L 好）。第 240 条「centreline 的 heading 比 SH30 的 plan 准」仍成立（7.04° 对 11.24°），但作为训练标签不如日志路径。
6. **学习曲线**（arm C，训练 log 105 / 209 / 417 / 834）：navtest > 45° 14.14 / 13.31 / 10.94 / 9.03°，held-out navtrain 12.11 / 10.56 / 9.21 / 8.11°，对 SH30 的 R²（全体）0.05 / 0.07 / 0.15 / 0.23；没有变平，25% 的 log 时还不如 SH30 自己的 plan。全量 run 的最佳验证 step 在 7 500–8 000（共 8 000）。
7. **G3 的规则**（预登记）：第 204 条独立噪声臂在噪声 / policy 误差比 0.39 / 0.79 / 1.57 处拿到 oracle 的 86 / 62 / 22%，1 / (1 + r²) = 87 / 62 / 29%；同一统计量对第 204 条的 thin head（已存文件）是 0.084，换算 +0.12，QH 实测 +0.09 [−0.11, +0.28]。增益 ≈ oracle 增益 × R²，形状类信号的 oracle 取 QS 的 +0.93。这条换算本线没有用 pilot 检验。

**对方向的含义**：(1) 第 204 条第 5 点「同一份冻结特征再预测一遍没有用」要收窄到那一种头与那一种目标：换成弧长参数化的 heading 曲线、navtrain 全量之后，同一份冻结 token 上的头比 pilot policy 准 2.1°（全体）/ 6.6°（> 45°），能解释掉它一半的 heading 误差；QH 的头当时比 policy 还差。目标形态、标签量、结构三者本线没有拆开。(2) 不过的是独立性，且是程度问题：误差方差约为 pilot policy 的一半、相关 0.53；按同一相关，精度到地图标签的水平（全体 4.78°）R² 约 0.6。学习曲线说加标签 log 还在往这个方向走；这里没有任何读数说信息不在冻结 token 里，所以本条**不构成** LoRA / 解冻臂的证据，先到的杠杆是标签量（更多带日志的 log，不需要地图）与训练时长。(3) 即使 pilot 上过线，对全量 SH30 的换算只有 +0.26：这条支路要值分，head 必须比 policy 进步得更快。(4) 若还要地图，用法不是当标签，而是当上界参照。
**状态**：**成立**（中）。限定：全部离线、开环日志状态，没有任何信号喂进 policy，stage 2（pilot、打乱对照、屏蔽 memory）未跑；闸门读的是 fold 0、seed 0 的一个模型，seed 1 在 navtest > 45° 上差 0.9°、R² 低 0.07（held-out navtrain 上两个 seed 相同）；G3 的点估计离线 0.025，CI 含线，「不过」是按登记的点估计规则判的；G3 的线性换算只有第 204 条的两类校准点；一种头结构、一组超参、训练未收敛；主量在 plan 自己的弧长处读，含 policy 的行程误差；L 把另一条合法车道 / 摆位也算误差；held-out navtrain 上的 policy 是 1 个 fold 模型；入弯读数是 2.5 m 网格上的 heading 平移，转不过去一行只有 75 个 token-seed。成本 1.1 卡时。
**会推翻或推进本条的证据**：同一个头加标签 log（nuPlan 其余 log，只需日志）或训练到收敛后 R² 是否过 0.538、对 SH30 的 R² 是否过 0.32；stage 2 的 pilot 读数本身（换算 +0.48 是否成立：增益 ≥ +0.5 且通道被读推翻 G3 的线，< +0.3 且通道被读坐实）；把 head 的输出作为辅助监督或输入接到全量 SH30 上的读数；拆开目标形态 / 标签量 / 结构（同一结构回归 8 个定时位姿）；LoRA / 解冻臂在同一 stage-1 读数上是否比加标签更快降低误差。
