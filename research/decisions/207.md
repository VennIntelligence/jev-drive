# 207. 转弯 token 的 DAC 差距是路径形状本身，不是路径与 timing 的耦合：把 SH30 的 plan 路径按日志 timing 重定时，> 20° 的 DAC 失败只去掉 12.6% [7.7, 18.0]（net −5.0%），> 20° EPDMS +0.14 [−0.51, +0.84]；把日志路径按 plan 的 timing 走，去掉 94.6% [91.9, 97.1]，> 20° +7.39 [+5.83, +8.91]，超过 WA-JEPA；plan 曲线在等弧长下的偏移等于定时点的偏移，且平均偏外侧不偏内侧；按登记线证伪（**中**，开环，特权 swap，存档 plan，2 seed）

记号：PP = 存档 plan；PL = plan 的曲线按日志的弧长-时间曲线重定时；LP = 日志的曲线按 plan 的弧长-时间曲线走；LL = 日志。navtest 12 146 token，non-reactive，no-EC EPDMS × 100，按 log 的 cluster bootstrap。恒等闸门：8 个成员的 PP 与存档 8 个子分逐 token 相同。

1. **登记判定：证伪。** (a) PL 去掉 SH30 在 > 20° 上 DAC 失败的 12.6% [7.7, 18.0]（gross，线 15% / 40%），net −5.0% [−13.5, +3.7]（230.5 → 242.0）；直线外推口径相同。外推 ≤ 0.5 m 子集是 19.5%，但其中的回收来自重定时后少走一段：重定时后弧长不短于原 plan 的 token 上只去掉 2.0% [0.0, 4.2]，反而多出 30% 失败；走得更短的 token 上 24.5%（第 178 / 186 条的视野效应）。(b) 定时点平均不在内侧：> 20° 上时间对齐偏移 T = −0.070 m [−0.101, −0.039]，等弧长曲线偏移 C = −0.076 m [−0.103, −0.049]，C / T = 1.08 [1.01, 1.26]，曲线偏移等于定时点偏移。
2. **2 × 2**（PP / PL / LP / LL）：SH30 全体 90.07 / 91.01 / 93.13 / 95.05；> 20° 83.74 / 83.88 / 91.13 / 93.85；> 45° 82.07 / 82.22 / 90.47 / 93.92。WA-JEPA（12 027 token）全体 92.37 / 92.77 / 93.92 / 95.04；> 20° 90.26 / 90.18 / 92.30 / 93.85；> 45° 90.16 / 90.10 / 91.63 / 93.92。转弯 token 上到日志的距离全在路径一列，两个模型都是；timing 一列在 < 20° 上约 +1.2，走的是 NC / TTC（第 196 条）。
3. **去掉的失败**（SH30）：DAC，> 20° LP 94.6% [91.9, 97.1]（net 73.8%，外推 ≤ 0.5 m 子集 97.9% / 93.4%），> 45° PL 10.6%、LP 94.2%。NC + TTC，> 20° PL 32.6% [22.1, 42.7]（net 15.1%）、LP 79.1% [70.7, 89.4]：转弯 token 上的碰撞也主要是路径；全体 token 上两者打平（54.0% 对 54.9%）。> 45° 的切内角 / 转不过去：PP 4.28 / 2.47%，PL 4.88 / 2.97%（各 +0.59 [+0.15, +1.07]、+0.49 [+0.07, +0.90]，变差），LP 2.67 / 0.00%（剩下的切内角是日志曲线的外推段）。
4. **对 WA-JEPA 的差**（no-EC 2.34 [1.67, 2.97]，带 EC 2.16）：PL 关掉 40% [24, 62]，全在 < 20° token；> 20° 上关掉 2% [−8, +13]。LP 关掉 131% [111, 165]，> 20° 上 113% [97, 133]。
5. **各臂相同**：> 20° DAC 失败的 PL / LP gross 回收 P2 11.7% / 95.9%，RMH10 12.4% / 94.2%，OT30 12.3% / 93.9%，WA-JEPA 22.9% / 88.5%。强 hinge 改的是路径失败的数量（P2 317 → SH30 230.5），不改分解。
6. **几何**（4 s，内侧为正）：SH30 > 45° T −0.284、C −0.309 [−0.408, −0.214]，左 −0.345、右 −0.254；20–45° C −0.051。WA-JEPA > 45° C −0.188。偏移是双侧的：> 20° 上 SH30 有 26% 的 token 偏内 > 0.3 m、42% 偏外 > 0.3 m。分开两个模型的是偏移的大小（事后）：平均 |C(4 s)| SH30 0.71 m 对 WA-JEPA 0.40 m，> 45° 0.88 对 0.46 m；P2 / RMH10 都是 0.69 m，强 hinge 只把均值往外推了约 0.05 m。失败 token 的曲线偏移约 1 m（事后）：切内角 +0.89 m，转不过去 −1.27 m，通过的 −0.20 m，三者的弧长差相同（+0.17 至 +0.19 m）。
7. **chord 机制的量级**（追加读数 E1 / E2，事前登记）：按观测到的弧长比散布对日志曲线取平均，> 20° 上只偏内 +0.063 m [0.057, 0.068]（4 s），> 45° +0.073 m；C 对 κ × 弧长差² / 2 的斜率 −0.16 [−0.40, +0.03]，Spearman −0.01。时间对齐比较里确实含这个几何项（plan 较短时 (T − C) 对它的斜率 1.13 [0.88, 1.36]），4 s 处约 0.03 m。C 对带符号弧长差的斜率 +0.089 m / m [+0.049, +0.134]。
8. **按方向**（SH30 > 45° DAC 失败率，PP / PL / LP）：左 7.24 / 7.79 / 3.05%，右 11.77 / 11.85 / 2.50%。右转失败更多，同样是路径失败（LP 去掉 95.7%）。

**对方向的含义**（按预登记第 7 节第三种情形）：杠杆是转弯 token 上的路径形状本身（走哪条半径 / 哪个出口，以及走得多准），不是输出参数化。以 timing 不确定性为理由的「路径曲线 + 单独速度剖面」或不取平均的 head，在转弯 DAC 上没有可拿的东西；方向回到路径的监督信号（评价器后果、路径类目标），与第 200 条 JP 臂（泄漏日志路径动的正是转不过去与 NC + TTC）一致。「转弯 token 上的精度」现在有了具体的量：等弧长下 4 s 处的路径偏移，SH30 0.71 m，WA-JEPA 0.40 m，日志路径 + 自己的 timing 就超过 WA-JEPA。timing 是另一根独立的杠杆，约 +0.95 EPDMS，在直行 token 的 NC / TTC 上（第 196 条）。
**状态**：**成立**（中）。限定：开环、non-reactive、no-EC；swap 格用了日志，是上限型读数；日志路径只是可行路径之一，C 把走另一条合法车道也算作误差；每个 swap 格约一半 token-seed 需要外推，LP 的 net 随外推规则变（> 45° 68.6% 对 80.3%）；E1 截断了比值、只含对 timing 的平均，对**路径**备选（哪个出口、哪条车道）取平均会产生的正是双侧的曲线误差，本线不能把它与单纯的不准分开；第 6 点的散布、失败类别与第 8 点为事后读数；WA-JEPA 单 checkpoint、12 027 token，P2 单 seed。
**会推翻或推进本条的证据**：闭环（AlpaSim / HUGSIM）里同一 swap 的读数相反；一个只改输出参数化（路径 / 速度分解）的训练臂在 > 20° DAC 上的增益 CI 高于 0；把转弯 token 的曲线误差拆成「选错出口 / 车道」与「同一出口内的半径误差」的读数（决定下一步是多模态路径还是路径监督）。
