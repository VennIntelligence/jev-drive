1. **设置**：S pilot 的命令（shard s2 + s3，3 000 步，batch 128，seed 0，warp 帧，`--ho ot1:4,yr1:4,bd4:5 --agent-lam 10 --ho-w 3 --ho-excl navsim/body1-val-logs --shape`）加 `--logmargin`，tag `P2H10SM-P-s0`。每行每个新 hinge：m = min(m0, c − 0.05 m)，c = 该行日志路径（日志 t0 位姿 + 8 个日志位姿，与 plan 相同的 0.1 s 稠密化与 hinge 几何）的最小净空，不设下限；agent 的两个 margin（corridor 内 0.3 m、外 0 m）都封顶；hinge-only 行从日志 t0 位姿起算，即源 log 行的世界路径。P2H10 自己的 on-log hinge 与其余不变。对照：存档的 `P2H10S-P-s0`（S pilot）与 `P2H10-P-s0`（base pilot）。
2. **G0 全过**：flag 关闭时 60 步与存档的 S 配方 identity run 逐位相同（42 个标量与全部权重）；新 margin 下日志路径在 agent 39 739 / 39 739 行、road 24 352 / 24 352 行上 hinge 为 0；hinge-only 行的 c 与源 log 行相等（最大差 agent 1.5e-5 m、road 7.6e-6 m）。
3. **G0.c（前提本身）**：日志违反 S 固定 margin 的行很少——road hinge 在 hinge-only 行的 13.3%（> 45° 弯上 10.2%，比别处还少），margin 被压低的行 16.9% / 13.2%，压成负的 3.6%；agent hinge 只有 0.04%（弯上 0），压低 0.4%。所以这个改动按构造只能动 road hinge。
4. **pilot 对三条线**：(i) 外移线不过：W2 142 对 base 110（线 ≤ 110 + 12，12 = base 四个 seed 在 warp 帧上的 spread，第 234 条），S pilot 140（存档读数 141）；出 4 m 管道 26 对 S 27、base 25。(ii) 课保住：hold own-plan agent 接触 −37.9%、出界 −33.8%（S pilot −37.1% / −33.8%；线 ≥ 其一半）。(iii) 代价：dev ADE 0.5902 m（S 0.5882，base 0.5913，上限 0.5932），4 s 弧长比 0.9992。
5. **与 S pilot 直接配对**：navtest 弯 token 上 4 s 横向只差 +0.008 m [−0.000, +0.016]（S 对 base +0.116 m [+0.075, +0.156]），两个 pilot 的 plan 在弯 token 上平均相距 0.043 m（S 对 base 0.166 m）。改动确实进了 loss：hinge-only 行上 road hinge 的质量 0.0017 → 0.0013（−24%），有非零 road hinge 的行 0.228 → 0.194；plan 没有动。
6. **读法**：S 的外移不是 margin 在日志自己路径上起作用造成的。两个没测的候选来源：hinge 在「plan 而不是日志」进到 margin 之内的地方起作用、而 hinge-only 行上没有任何项说出 route（第 234 条的读法）；或者 hinge-only 行上的 agent hinge——单独就给出约一半的外移（第 244 条 noC：+0.059 m 对 +0.123 m），而日志几乎从不违反它。

**对方向的含义**：与到 log 的管道（第 234 条）一样，「与日志一致」也分不开 clearance 课与 route；分开它们需要一个不是「到 log 距离」形式的 route 信号。S 保持原样作为 SELF-CON 的对照基底；S 进比赛 driver 所缺的（第 254 条）仍然没有补上。
**偏离任务书（都在预登记里先改好）**：(ii) 的线取 S pilot 自己的降幅（任务书里的 −40.2% 是 R pilot 的）；hinge-only 行的日志路径从日志 t0 位姿起算（按 design.md 3.1；从扰动位姿起算的变体没跑，它会再压低 8.7% 的 hinge-only 行的 road margin）；G0.a 对存档的 shard s2 identity run 而不是新跑一对；W2 三个 checkpoint 用同一次 reader 调用（S 与 base 的存档值在一个 token 之内复现）。另：`lib/agent_hinge.py` 的 `distances` 多了可选起点 `p0`，默认路径不变（G0.a 证实）；flag 只在 `bd4_train.py`，没进 `joint_train.py`。
