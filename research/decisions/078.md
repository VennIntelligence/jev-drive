# 78. op-adapt L：用真实 log 的人类未来做模仿，轻度适配 WOD train，起步 / 停车 / 起转的留出捕获率都涨，且没有变保守或变急；唯一不过的线是 stay 上的假起步（+2.7 pp，线 +2 pp），在测过的一维蒸馏权重扫描里只有 dw 10 压进了线，代价是增益缩到约三分之一（2026-10-01 复核改：原写「只有提高蒸馏权重能压进线」，gate、按 stay 加权的损失、两阶段都没试过，不能说只有 dw 能压；这条线 stay 只有 144 段，CI 半宽约 1.2 pp，点估计实际要 ≤ 约 +0.8 pp 才过）（**待定**，WOD val 479 段 + nuScenes val + navtest，40 个训练 run，`main` 3 seed，只有 Cinque）

接第 77 条：真实 log 的人类未来在起步、停车、起转上有上千个独立事件，原生 plan 漏 3–7 成。本条做了第一次适配：WOD train 上按这三类切片模仿人类未来，WOD intent 经一个 adapter 进模型，其余帧（stay、control、straight-intent、other）蒸馏到原模型。
用户 2026-10-01 已同意「在 WOD train 上训练」，所以这条线上的模型一律称「在 WOD train 上轻度适配」，不再是零样本；第 77 条的 7.92 提交不受影响，它没有用这些权重。
`main` = stage 4 解冻 + intent adapter + 蒸馏权重 3。选择波没有候选满足全部 dev 线（都只差假起步），按登记的回退规则选出；三个 seed。

1. **按登记读法是「靠代价换的捕获」的边缘形态**：增益稳定（三个 seed 差 < 1 pp）、漂移 / 保守 / 急 / RFS / ADE / navtest 都没坏，唯一的代价是 stay 帧上多约 3 pp 的假起步（原模型本身 4–7%）。没有任何 arm 同时「增益大且过 L2」。
2. **intent 有用，主要买起转**：`main` 对无 intent（`noint`），turn onset +6.8 pp [5.6, 8.1]、start +1.3 pp，假起步无差，RFS 上 `noint` −0.044 对 `main` +0.009。turn onset 原模型没有导航输入时漏 26–39%（第 77 条），这是第一个看得到效果的导航输入接法；第 66 条 turn desire 不动 plan 的结论针对的是原生 desire 通路，这里是学出来的 adapter。
3. **假起步几乎全来自 start 模仿**：只训 start 的 arm 假起步 +11.7 pp，只训 stop / turn 的 +0.1 / +0.8 pp；只训 start 对 stop、turn 几乎没有增益，`main` 里三类互相不帮忙，start 与 stop 增益都比单训一类小（共享容量与蒸馏）。
4. **蒸馏权重是增益与假起步之间的单一旋钮**：dw 0.3 / 1 / 3 / 10 下 start 增益 +0.318 / +0.199 / +0.101 / +0.039，假起步 +25.4 / +8.1 / +2.7 / +0.9 pp，dw ≤ 1 还让漂移超线（0.21 / 0.11 m）。dw 10 是唯一过 L1、L2、L3、L4「无害」、L5 的 arm，但 start 增益只剩 +0.039。stay 占对照帧 3/5 的 `stayheavy`：假起步 +1.7 pp（上界 2.7），仍差 0.7 pp；去掉对照帧假起步 +4.4 pp，所以对照帧的作用主要是压假起步。
5. 可训练部分（stage 4、stage 4 + policy、policy、原生 desire 承载 intent）在同一权重下增益相差 ≤ 0.02，没有哪组明显更好；只训 adapter 增益约一半；8 000 步的长 run 无显著增益。
6. **与 r2 的对照**：r2 stage 1 的失败形状是「整体更保守」（漂移 0.40 m、null 帧 slow 率 +11.7 pp）。这里同样是轻度解冻，漂移 0.06 m、slow / fast 不动，区别在监督信号：真实域里成对的「该动 / 不该动」「该停 / 不该停」人类轨迹，不是 CARLA 配对加对 13 种扰动的规则打分。这支持第 77 条的判断，但 r2 只跑了 2 000 步的 stage 1，两者不是同一设定下的对照，不能写成 r2 的方法被证伪。
7. **增益的量级**：start 捕获率 0.53 → 0.63，仍有约三分之一起步没被复现；RFS 没动（+0.009），所以这条不能说 7.92 会涨，捕获率涨在 WOD 的 rater 帧上没有转化成分数。

**状态**：**待定**。限定：`main` 由回退规则选出，不是有候选过了 dev 线；`stayheavy`、`tr_ad_dw3` 是看过 wave 1 留出读数后加的消融（D4），D3 记了读数管线测试时看过 pilot 模型的 val 数；「假起步来自 start 与 stay 的先验失衡」是由只训单类的 arm 推出的，没有单独量化先验；捕获率的「一半」阈值是任意的；只有 WOD 的 intent，nuScenes 没有，所以 turn onset 的域外迁移未检；单一模型 Cinque，闭环（B2D / HUGSIM）完全没测。
**后续检验（2026-10-01，[预登记与结果](../../experiments/op_adapt_l/plans/2026-10-01-op-adapt-L-followup.md)，只读已有 checkpoint，`main` 三 seed）：原先列的两条推翻条件都没有触发，本条的机制读法因此收紧。**
(1) **intent 置换**（WOD val turn onset 3 825 帧、179 段；本条原写「没有做置换检验」）：as given +0.117 [0.099, 0.136]；层内置换 +0.064、全局置换 +0.016、强制直行 +0.006、左右翻转 +0.011，无 intent 的 `noint` +0.048。按登记读法（置换后增益 ≤ `noint` + 2 pp，且翻转后 sign agreement 比 as given 低 ≥ 5 pp；翻转低 7.5 pp [−9.3, −5.9]）adapter **读的是路线意图，不是场景线索**；错误的 intent 还会把 plan 推偏，增益比无 intent 更低。层内置换的残余增益不能当场景读法的证据（该切片左右比 1 371 : 2 331，置换后约一半帧碰巧拿到对的方向）。假转几乎不涨（上界 ≤ 0.4 pp）。start 增益基本不依赖 intent，stop 在无 intent 下降 5.9 pp。
(2) **WOD stop 按原因拆分**（stop 切片 1 268 帧、181 段；原因标签来自本次新跑的一遍 YOLO26x 前视检测加走廊规则，没有 3D 标注）：前车在走廊内 98 帧 / 24 段，Δ +0.133 [0.050, 0.253]；行人 / 骑车人 9 帧 / 2 段，不可判；严格「无检测到的原因」1 117 帧 / 164 段，Δ **+0.330** [0.271, 0.394]，对应原模型 0.257 → 0.587。所以 stop 增益**主体不是前车跟停**；「学到了停车时机」的读法要收窄（2026-10-01 复核）：「无检测原因」是剩余类，红灯、停止线、让行、漏检都在里面（YOLO 本有 traffic light / stop sign 类别，这次没用），也没有对同速度、人类没停的帧量过假停（control 要求 v0 ≥ 5，stop 切片 v0 中位数 4.6，几乎不重叠）；这一类里是红灯、停止线还是让行没有标注可验证，漏检也会落进这一类使增益偏高（用原模型 lead 头再筛一遍没有变小）。
**仍会推翻或推进本条的证据**：把适配模型放进 B2D 或 HUGSIM 闭环，对同速度配速对照的配对差 CI 下界不 > 0（开环捕获率没转成闭环行为，第 74 条的「开得慢」解释再次成立）；在 dw 3 与 dw 10 之间加一个权重、或提高 stay 的份额，能同时过 L1 与 L2 且 start 增益保持在 +0.07 以上（旋钮不是单调取舍）；stop 的「无检测原因」类里按红灯 / 停止线标注后增益仍在。
