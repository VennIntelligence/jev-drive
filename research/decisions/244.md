1. **问题 1（navhard 增益是谁的）**：按登记线，B「carries」（noB − S 在 stage 2 上 −3.53 [−5.48, −1.64]，剩 −6%），A 与 C 各自「not needed」（留 65% / 54%，对 base 的 CI 不含 0）；但两者各去一样对 S 也都掉一截且 CI 不含 0（−1.16 [−2.18, −0.24]、−1.53 [−2.98, −0.05]）。增益需要离轨行，在行上由两种 hinge 大致对半分；合计分上只有全配方与 base 分得开，两个半臂（32.78、32.84）高于 base 的 4-seed 范围（31.25–32.28）但 CI 含 0。带行的臂 stage 1 都低于 base（noC −1.09 [−2.00, −0.25]）。
2. **问题 2（外移只来自行上的 road hinge 吗）**：登记的说法**不成立**。noA 外移（+9 / +17 token，线 +5）、noB 不外移（0 / +1）与 pilot 一致，但 noC 也外移（+10 / +8）：没有任何 road 项时，行上的 agent hinge 单独就把大弯的 plan 往外推 0.12 m。外移属于 hinge-only 行，road hinge 占大头（留 75%）不是全部；两个半臂的外移之和（0.29 m）大于 S 的（0.22 m），两种 hinge 推的是同一批 plan。
3. **各样料的效应**：(i) on-log 行上的 agent hinge 在全量上几乎无作用（noB 各项都在 base 上，只有 > 45° navtest +0.30 [+0.09, +0.51] 等三个小量 CI 不含 0）；(ii) navtest 的增益、DAC、切内角全部来自行上的 road hinge（noA 保住 100%，noC 剩 18%）；出界率 noA −47%、noC −19%；(iii) 行上的 agent hinge 贡献 agent 接触率的一部分与 navhard 的一半，对 navtest 无贡献；两种 hinge 各自单独去掉约三分之二的 agent 接触，互相重叠；(iv) 弧长线没有臂不过（navtest 0.9969–1.0024）；「转不过去」没有臂动。
4. **与前提不一致处**：任务书里的「`P2H10S` 75 对 base 54」是 pilot 规模的数，全量是 58 / 65 对 45 / 46（第 234 条第 1 点，本次复现）；pilot drop-one 推出的「只来自 road hinge」在全量上被 noC 否定（pilot 没有 noC 这个臂）。

**对方向的含义**：后续在 `P2H10S` 上加 lane-corridor 项的 lane 不能靠去掉某一样料来同时保住 navhard 增益和去掉外移：保住一半 stage-2 增益的两个臂正是外移的两个臂。corridor 项要压的外移有两个来源（road hinge 约 0.17 m、行上的 agent hinge 约 0.12 m），都在 hinge-only 行上，所以该项至少要加在这些行上。若只要 navtest 与出界，noA（不带 agent hinge）与全配方等价；agent hinge 的价值只在 navhard stage 2 与离轨 agent 接触。
