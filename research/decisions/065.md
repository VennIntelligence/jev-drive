# 65. CARLA 就地回退（rewind）不是从头生成的等价替代：最好的 `tree+w40f` 恢复了 hazard 行人（位置 p95 0.04 m，开始走 97%），但 ego 速度、collision 标签、cut-in 车和 openpilot `temporal` 不过线；WL-2 用从头生成 + zygote，地图复用不用（**已定**，11 个分叉点 × 7 个动作，floor 14 + 11 个 run）

2026-09-29。登记（方法、分叉点选择、R1–R5、地图复用 U0–U3 / UR、zygote Z）写于任何数字之前，[fc65452:todos/2026-09-29-carla-rewind.md](https://github.com/VennIntelligence/jev-drive/blob/fc65452/todos/2026-09-29-carla-rewind.md)；小表 [results/carla-rewind/](../../experiments/carla_rewind/results)；对外部提案的更正见 [b2d 闭环与控制](../b2d-closed-loop/index.html)。约 3 卡·h（GPU 6）。
问题：在同一个 Bench2Drive route 里把世界退回分叉 tick，再跑下一个动作的分支（回退，rewind），能否代替 WL 的逐分支从头 run，能省多少。真值是 WL 的从头分支；floor（同配置从头重跑）的 p95 是 0，所以判据取固定下限。

| 方法（回退分支） | 行人位置 p95 | 行人开始走一致 | ego 3 s 位置 / 速度 p95 | unsafe / collision 一致 | cut-in 车 p95 | `temporal` 最小余弦中位 |
|:--|:--|:--|:--|:--|:--|:--|
| 线 | ≤ 0.25 m | ≥ 95% | ≤ 0.3 m / 0.3 m/s | ≥ 98% / 98% | ≤ 0.25 m | ≥ 0.99 |
| `poc`（提案：transform + 速度） | 7.57 | 21% | 3.79 / 4.14 | 78.7 / 77.0 | 12.1 | 0.52 |
| `tree+w20`（行为树 + 20 tick 重放，旧行人处理） | 4.05 | 52% | 0.30 / 0.49 | 97.6 / 95.2 | 0.30 | — |
| `tree+w40f`（+ 重放期间树停住、行人重生） | **0.036** | **97.1%** | 0.295 / 0.305 | 98.5 / 97.0 | 0.39 | 0.87 |
| `tree+w80f` | 0.60 | 82% | 1.89 / 2.73 | 100 / 97.9 | 0.74 | 0.79 |

**结论**：
1. **行人恢复修好了**。旧版的问题有两个：重放期间行为树每个 tick 都从分叉态重来，KeepVelocity 反复给行人施加控制；teleport 不清行人移动组件的速度。改成重放期间树不 tick，并在重放开始时重生行人、用录下的控制驱动以后，行人与真值基本一致。剩下的不一致来自 ego 差让 trigger 翻转。
2. **按登记判：没有方法 R1–R3 全过**。`tree+w40f` 差在 ego 速度 p95（0.305 对 0.3）和 collision 一致率（2/66，都是低速擦碰的临界）上，cut-in 车 0.39 m 也超 R5 线，R4 远不过。传动系、轮胎和 TM 的状态经 API 恢复不了，warm-up 加到 80 tick 反而更差。
3. **WL-2 的生成方式定为从头生成**（登记的三档里的「从头」）。混合方式要求 R1–R3 全过，这里不满足。回退作为默认关的选项留在 `experiments/world_model/archive/wl_fork_agent.py`（`rewind: tree+w40f`），只适合接受约 1.5% unsafe 标签差、不要分支 z 的场合。
4. **zygote（预热 route 进程）与普通 run 等价**：前缀和标签 14/14 一致，分支差与 floor 同量级。每个 run 省约 12 s（setup 85 → 73 s），可以默认开。
5. **地图复用不能用于 WL**：U0 不过，前缀 ego ≤ 0.01 m 的 run 只有 32%，背景交通分叉；U2 亮度差超线，U3（UR）也不过。虽然每个 run 省约 36 s（`load_world` 52 → 9 s），也不用。
6. 实测加速：不带续跑时，每个分叉点 7 个分支，回退 283 s 对从头约 855 s，约 3.0×（对 zygote 从头约 2.7×）。WL-2 的 11 个分支约 3.3×。提案的 6.7× 和「160 s 是前缀」都不成立：前缀约 23 s，装图约 66 s，续跑约 60 s。

**状态**：**已定**（回退不等价、地图复用不用、zygote 可用）。限定：(1) 方法和 warm-up 长度是在这 11 个分叉点上选的，`tree+w40f` 的数有选择偏差；(2) w80f 只有 8 个分叉点跑完，`tree+w40f` 的 R4 只算了 42 个分支；(3) 加速是按同一 tick 时长拆开算的，box 负载在这几个小时里变化大。
**会推翻本条的证据**：若找到能恢复车辆传动系 / 轮胎状态的办法（例如 CARLA recorder 回放，登记里的 `replay` 臂，没做），在同一批分叉点上 R2、R3 过线，就重开「回退 / 混合」。
