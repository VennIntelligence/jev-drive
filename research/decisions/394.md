# 394 REAL-GAP：真实 PAI-AV 画面 vs NuRec 渲染（同 clip、同时刻），相机下载规模

日期 2026-10-20。预登记 [experiments/pai_av/plans/2026-10-20-realgap-prereg.md](../../experiments/pai_av/plans/2026-10-20-realgap-prereg.md)，
结果 [experiments/pai_av/results/realgap.md](../../experiments/pai_av/results/realgap.md)，主题 [experiments/pai_av/README.md](../../experiments/pai_av/README.md)。

**做了什么。** test281 中 50 个 clip（split `physical_ai_av/realgap-exam50`，国家组 x 昼夜分层）沿人类日志渲染（onp_log_driver，NTV0-L18-s0，
每秒存 8 个槽帧），同一时刻从 PAI-AV 视频取真实帧，经驱动同一个 `pai_core.Maps`（PAI-AV 标定 / NuRec CameraSpec 两种）；ego 行、路线记忆、
命令完全相同，只换图像。另 50 个非考试 clip（`realgap-nonexam50`）只取真实 token 训练探针。相机按 zip 成员 range 下载，100 clip 共 1.31 GB。
**纯测量：test281 真实画面不进入任何训练行或缓存。**

**读数（700 个决策，场景聚类 bootstrap）。**
- 转换：时钟完全一致（NuRec 首帧 = PAI-AV 帧时间，0 us）；渲染 -> 真实 road 帧平移中位数 x 0.02 度、y 0.10 度，对齐正确。但 PAI-AV 标定与 NuRec
  CameraSpec 本身不一致：旋转 0.33 度（最大 1.14）、f-theta 半径 40 / 60 度处 -7 / -10 px；同一真实帧两套标定计划距离 0.40 m，NuRec 标定的 ADE 更好（2.78 对 2.95 m）。
- 计划（NTV0）：ADE 渲染 2.53、真实 2.95，配对 **+0.41 [+0.22, +0.62] m（+16 %）**，夜间 +0.58、白天 +0.26；真实 vs 渲染计划距离 **0.90 [0.73, 1.09] m**，
  对照尺（同输入 NTV0 vs RSG）0.35 m；真实帧上更慢（4 s 速度偏差多 -0.26 m/s）。
- token：渲染-真实余弦 0.888（真实 t vs t+1 s 0.819，异 clip 0.311），CKA 0.90（置换 0.03），域分类 0.97。
- 探针（真实非考试训练）：速度 R2 真实 0.977 / 渲染 0.978，3 s 速度变化 0.570 / 0.480，3 s 航向变化 0.749 / 0.755。

**判读（按预登记）。** 差距判据 (a) ADE ±10 %、(b) 计划距离 <= 对照尺均不过；(c) token、(d) 探针过。编码器看到的内容相同，策略对风格差（夜间尤甚）反应明显。

**结论。** 数据不支持直接全量下载约 1 TB（实测约 1 MB/s，约 12 天，且没有证据表明真实行能提升渲染考场）；只支持试点规模：2-4k 非考试 clip、
只下 front-wide（30-55 GB），有重建的 clip 用 NuRec 标定，做一个渲染 + 真实行的联合臂，PAI 281 早停闸过了再谈扩大。

**证据：** 中（1 个模型 + 1 个对照 checkpoint；50 clip；开环；探针为线性读出）。**状态：** 已确认（测量）；下载规模待主会话定。
