# 60. CARLA 渲染故障：黄昏 / 夜里变暗是 `RouteLightsBehavior` 的开关只在新 server 的第一条 route 上生效，`B2D_KEEP_STREET_LIGHTS=1` 修好（6 / 6 → 0 / 3），白天帧不变、夜里帧会变；白天泛光没能复现，没有修复（**待定**，GPU 6，WL 分叉路线 29 条次失败例 + 对照）

2026-09-29。细节、复现步骤与前后对照表在 [WL todo 的「渲染故障的根因」](https://github.com/VennIntelligence/jev-drive/blob/fc65452/todos/2026-09-28-wm-loop.md)，小表在 [results/wl/renderfix/](../../experiments/world_model/results/wl/renderfix)。

- **变暗（WL 里 13 个 run）**：`RouteLightsBehavior`（场景树里每 tick 按 ego 位置开关路灯 / 建筑灯的行为）在夜间模式下关掉半径外的灯。新起的 server 上这一开关让整幅画面在 2–3 tick 内变暗（Town03 sun 0：亮度 57 → 6），
  复用 server 上灯表同样显示被关了、画面却不变（灯表和实际渲染的灯对不上，`load_world` 之后灯表不按新图干净重建）。只跳过路灯开关就不再变暗，只跳过车灯开关照样变暗。
  修复开关 `B2D_KEEP_STREET_LIGHTS=1`（`scripts/b2d_hooks.py`，默认关）：不开关路灯 / 建筑灯，车灯照旧。新 server 黄昏失败例 6 / 6 → 0 / 3；复用 server 上白天帧平均 |Δ亮度| ≤ 0.22（渲染噪声量级），
  **夜里帧会变**：Town03 黄昏 +0.8，Town13 夜 +2.5，Town04 夜 +13（后者前驱地图不同，是上界）。
- **白天泛光（原数据 Town12 / 13 同图前驱时 16 / 1 638）**：本次 41 个复现 run 0 次，按约 1% 的率本来就期望不到 1 次；原因未知，由 WL (c) 的逐 run 渲染判据剔除。
- 状态**待定**：变暗的机制是在 3 条 Town03 路线上确认的，别的图的夜路线只量了修复前后的差，没有「新 server 失败例」；泛光没有复现，谈不上修。
