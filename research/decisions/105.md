# 105. B2D 非特权 bypass（vmerge3）：感知读对了相邻车道和障碍物，但保守的 gap 规则在密集车流里很少放行，障碍路线只剩 +12.9（线 +20.7，否）；碰撞回到 drive 水平（0.158，是）；前向雷达放行检查没有减少 17280 碰撞，反而拖慢灯路线（**待定**，19 路线 × seed 0/1，诊断批）
2026-10-04。预登记 [experiments/vlm_arb/plans/2026-10-04-vmerge3.md](../../experiments/vlm_arb/plans/2026-10-04-vmerge3.md)（D1–D8），结果 [experiments/vlm_arb/results/vmerge3.md](../../experiments/vlm_arb/results/vmerge3.md)，离线放行检查 [vm3_cross_offline.md](../../experiments/vlm_arb/results/vm3_cross_offline.md)。由另两位执行者完成；本条由 main 按其报告写，没有复算。

1. **臂**：`vmerge3` = vmerge2 + 感知 bypass + 放行检查；`vm3priv` = vmerge2 + 放行检查（bypass 仍特权、仍是 vmerge2 的贴车拒绝规则）；`vm3norel` = vmerge2 + 感知 bypass。感知 bypass：障碍起点用 openpilot lead 头，范围用 15 m 先验加前向雷达静止回波，相邻车道侧别与偏移用 openpilot 车道线 / 路沿（CARLA 里车道宽读小，偏移 ×1.2，在 debug 路线上标定），gap 用 4 个雷达（含后角），起步要后车在 3 + 3v m 以外。D1–D6 在 debug 路线上调出，不在 19 条评测路线里。
2. **放行检查**：原定 Qwen 读广角相机判横向来车，离线 test AUC 0.875 但 dev 阈值下 FPR 0.66（线 0.15），分数反映「路口忙」而非「3 s 内入我路径」，判否，改前向雷达 TTC（偏离 brief，已标）。
3. **结果**（每臂 38 run）：DS drive 65.9、vmerge2 76.7、vmerge3 68.3、vm3priv 75.4、vm3norel 70.6；车辆碰撞 / run 0.158、0.289、0.158、0.263、0.237。vmerge3 − drive 全路线 +2.4 [−6.3, +9.9]，障碍路线 **+12.9 [+3.6, +24.3]**（线 +20.7，否）；碰撞 6 / 38 与 drive 持平（线 ≤ 0.158，是）。
4. **瓶颈在 gap 规则，不在感知**：感知的侧别与偏移与地图差约 0.15 m，4 条障碍路线都启动了 bypass；但 3 + 3v m 的起步窗口在 11–14 m/s、headway 约 3 s 的车流里很少打开（19324 两个 seed 28.8 / 97.0，24497 21.7 / 21.7）。vmerge3 − vm3priv 障碍路线 −32.2 [−63.6, −6.4]，这个差是「感知 + 保守 gap」对「特权 + 贴车拒绝」的合计，不能全归于感知。碰撞持平主要因为切出次数少了，不是切出更安全。
5. **放行检查**：vmerge3 − vm3norel −2.3 [−10.1, +4.5]，灯路线 −9.0 [−19.0, 0.0]；17280 seed 1 四个臂都各撞一次（vmerge3 DS 60，其余 17–19）；27297 在 seed 0/1 上都没撞；27043 两次 8 s 满额等待，平均速度 1.62 对 vmerge2 2.17。前向雷达看不到横向来车，这个检查本质上管不到第 95 条说的那类碰撞。
6. **D8**：Qwen 在共享卡上 p95 1.09 s，答案统一按 t_q + 0.35 s 生效，7 139 行全部核过，延迟不进仿真。

**对方向的含义**：非特权 bypass 在感知上可行，B2D 的 bypass 增益主要取决于「愿不愿意在密集车流里挤进去」这个策略参数，而这正是用碰撞换 DS 的那一端（第 95 条第 5 点）。放行检查只用前向雷达没有意义，不保留；要管横向来车得有侧向感知（广角相机的横向检测，或后角雷达朝前的视野），第 95 条那条「缺横向来车检查」的推断仍未被检验。

**状态**：**待定**（2 seed，路线 CI 宽）。
**会推翻或推进本条的证据**：gap 规则在 2–3 s 之间的扫描（DS 对碰撞的前沿）；有侧向感知的放行检查在 17280 上的碰撞；seed 2/3。
