# 99. 指令走图像通道：zero-shot 只有「把其他支路画成不能开」的覆盖物起一点作用（挡板 uptake 0.12），模型在躲不可行驶区域、不读路线语义；轻量微调能学会训练过的两种画法（uptake 0.54–0.64），但留出画法迁移很小、无覆盖时计划漂移 0.29 m 未过护栏（**待定**，navtrain 385 帧 / 247 log + CARLA 696 样本 / 179 路线，Cinque，开环）
2026-10-04。用户的想法（2026-10-04 决定第 2 条）：在 openpilot 输入画面上画出要走的转弯或封死其他支路，代替第 92 条里不管用的 desire。预登记 [experiments/op_img_cmd/plans/2026-10-04-img-cmd-prereg.md](../../experiments/op_img_cmd/plans/2026-10-04-img-cmd-prereg.md)、`2026-10-04-img-cmd-ft-prereg.md`，结果与审阅图在 [experiments/op_img_cmd/README.md](../../experiments/op_img_cmd/README.md)（`figs/overlay_sheet.png` 是模型看到的画面）。由另一位执行者完成；本条由 main 按其报告写，没有复算。

指标：同一帧轮流指定两条支路，计划往指令支路移动的配对差 Δ（4 s，m）；uptake = Δ / 两倍支路间距（1 = 完全换到指令支路）；correct = 计划离指令支路比离其他支路更近的比例（固定评测集，不加覆盖 0.50）。CI 为按 log / route 的 cluster bootstrap。

1. **zero-shot（navtrain）**：覆盖物按各帧自己的位姿画在全部历史帧上。挡板 Δ +0.96 m [0.72, 1.22]、uptake 0.12、correct 0.59；草地 0.11；墙 0.07；锥桶 0.05；涂色路线带、车道线 ≤ 0.01；路面箭头、标志牌、灰色填充 0。挡路类同时让 4 s 计划缩短 1–4 m（读成前方有障碍）。直行帧车道保持不受影响。预登记的 correct 口径会随计划本身变（挡板在原口径下 0.83），改用固定集合后按 partial 判。
2. **zero-shot（CARLA，179 个路口带传感器重录）**：排序相同，combo（事后）uptake 0.18、correct 0.67（不加覆盖 0.43，多为三岔），挡板 0.09，车道线 0.09，标志牌 0。左转吸收最少。
3. **轻量微调**（只训 stage 4 + plan 通路，3 000 步，1 500 个与评测不相交的路口帧，只训路线带和挡板）：路线带 uptake 0.01 → 0.54 [0.46, 0.63]、correct 0.81；挡板 0.12 → 0.64、correct 0.91。留出画法：锥桶 +0.16、车道线 +0.09、墙 +0.05、箭头 +0.04、标志牌 0、草地 −0.05。无覆盖时计划漂移中位 0.29 m（护栏 0.10 m）不过；蒸馏 ×4 降到 0.19 m 仍不过，路线带 uptake 降到 0.34。覆盖物从「挡路」变成「走」的信号（挡板让计划从缩短 2.4 m 变成拉长 2.3 m）。

**对方向的含义**：图像通道能把指令送进模型，但不是 zero-shot：模型只认「能不能开」，不认路线语义。微调学到的是那两种固定画法，不是读路线的能力。要用它，需要先做不漂移的微调（更大更多样的蒸馏池、多 seed），再在 CARLA 和闭环上验证。

**状态**：**待定**。限定：每个模型单 seed；微调只在 navtrain 上评测；闭环 smoke 没跑（需要闭环 server 逐帧画覆盖物、ft 模型导出 ONNX）。
**会推翻或推进本条的证据**：多 seed 下训练画法 uptake 的 CI 下界 < 0.3；不漂移的版本在 CARLA 上复现；闭环在 turn_agree 失败的路口跟上转弯。
