HEAD1b（探索性，第 243 条闸门未过之后经用户授权的第二轮）：把转弯描述 head 训到收敛并用三种方式接到 policy 上，pilot 规模：收敛后的 head 不比 stage 1 好（navtest > 45° 8.83° 对 8.54°，R² 0.524 对线 0.538）；经 memory 通道喂回（HP）EPDMS −0.03 [−0.21, +0.16]，plan 自己的 4 s heading 误差在 > 45° 降 3.19°，「转不过去」−1.09 pp、切内角 +0.66 pp，出界率不动；辅助 loss（HA）+0.04 [−0.04, +0.12]，heading −1.21°，转弯失败不动；同一 memory 放到 `P2H10S` pilot 上（SHP）+0.18 [−0.00, +0.38]，按线记负，外移收回一部分；R² 换算预测 +0.48、实测约 0，不成立；4 s heading 误差降低在任何载体上都没有换来出界率下降（**中偏弱**：探索性，pilot 规模，2 seed，开环）

1. **A（把 head 训到收敛）**：五个候选只在 fold 0 的 89 个验证 log 上选，选中 `rt24`（24 000 步、dropout 0.2、wd 0.1、每步随机留一半视觉 token；val loss 0.002993，stage 1 是 0.003612），两 seed 均值再低 5.7%，最终 head = 每 fold 两 seed 的均值。navtest 读一次：> 45° 8.83° [7.37, 10.35] 对 `SH30-F` 的 plan 11.24°（−2.41 [−3.34, −1.56]），stage 1 是 8.54°，差 +0.30 [−0.46, +1.09]；G3 口径 R² 0.524 [0.439, 0.600] 对线 0.538（stage 1 0.513，差 +0.011 [−0.027, +0.049]）；对 `SH30-F` 的 R² 0.298（0.278）。held-out navtrain 上是好的（全体 4.63° 对 4.93°，−0.30 [−0.44, −0.17]），navtest 上没有。最终 head 的两个成员单独读是 9.27° / 8.98°（> 45°）：stage 1 的那个 seed 0 模型在 navtest > 45° 上是偏有利的一次抽样（它的 seed 1 是 9.47°，第 243 条已记）。**收敛不改变 stage 1 的判定**，R² 仍在线下。
2. **A2（拆目标形态 / 结构 / 标签量）**，navtest > 45° 的 heading RMS，两 seed 均值：L-full 9.00°、L-thin 13.43°、P-full 10.86°、P-thin 14.89°、第 204 条的 QH 原头 16.58°。结构（full − thin）−4.43° / −4.03°，目标形态（L − P）−1.85° / −1.46°，标签量与 fold（P-thin − QH 原头）−1.69°。对 `GH0-F` 的 R²：0.480 / 0.223 / 0.393 / 0.140 / 0.107。第 243 条「三者没有拆开」到此拆开：最大的一项是 head 的结构，三项同向。没有设线。
3. **B（memory 通道，HP）**。分数不动：−0.03 [−0.21, +0.16]，每 seed −0.04 / −0.01；对打乱对照 `HPX` +0.14 [−0.03, +0.31]；> 45° 桶 −0.14 [−0.92, +0.73]。「通道被读」按登记规则**不成立**：dev 错配 ADE / 自己的 = 0.682 / 0.628（1.09）与 0.651 / 0.625（1.04，线 1.05），HP − HPX 的 CI 含 0，所以登记判词是「上限未量到」而不是负。但 plan 明显在用这个通道：heading 误差全体 −1.15°、> 20° −2.33°、> 45° −3.19°，HPX 反而变差 +0.95°；转不过去 4.19% → 3.10%，切内角 4.12% → 4.78%；屏蔽 memory 后 5–20° 桶 −0.47 [−0.86, −0.11]。plan 的朝向跟着喂进去的曲线走了，转不过去的少了、切内角的多了，> 45° 的 DAC 失败率没有变（−0.03 [−0.72, +0.62]）。恒等核对（屏蔽 memory 的模型复现 `GH0`）在登记的 1 mm 线上不过（plan 最大差 3.2 / 5.5 cm），按读数前修订的两处读法（adapter bias 到 fp32 舍入、plan 差不超过等幅扰动参照的 3 倍）成立；`ident.json`。
4. **B2（辅助 loss，HA）**。λ 在留出的 117 个训练 log 上选，三个 λ 单调，选了网格上沿 10（> 20° heading RMS 9.12° → 8.57°，−0.55 [−0.94, −0.17]）。最终臂：EPDMS +0.04 [−0.04, +0.12]（每 seed +0.12 / −0.03），heading 误差 > 45° −1.21°、全体 −0.44°，转不过去 +0.00、切内角 −0.13 [−0.53, +0.18]，守护线都过。剂量小：辅助梯度范数是其余 loss 的 1–5%，辅助 Huber 只从 0.0090 降到 0.0084；λ 没有在更大的值上试，「辅助监督无效」只对这个剂量成立。
5. **C（同一 memory 放到 `P2H10S` pilot，SHP）**。+0.18 [−0.00, +0.38]（每 seed +0.20 / +0.15），< +0.3，通道被读（dev 错配 ADE 0.615 / 0.579、0.624 / 0.572），按线记**负**。增益在中等弯：20–45° +0.90 [+0.06, +1.74]，> 20° +0.58 [+0.05, +1.11]，> 45° +0.23 [−0.31, +0.79]；屏蔽 memory 后 −0.17 [−0.41, +0.09]，回到基线附近。heading 误差 > 45° −1.67°；转不过去 −0.49 [−1.24, +0.19]。外移收回一部分：W2 99 / 120 对基线 141 / 150，4 s 横向 −0.117 m [−0.158, −0.079]（0.342 对 0.458 m）；这些数来自 bench 的 warp plan，与第 244 条当时的 gimm dump 不是同一口径（见第 244 条的更正）。离轨行上喂进去的曲线更差：`bd4` 行 8.30° 对同 token 的 on-log 行 5.47°，head 对位姿偏移的跟随斜率在 0 m 处为 0、在日志 4 s 弧长处 0.34（`ot1` 0.65，`yr1` 0.53）。
6. **R² 换算（第 243 条 G3 的线）第一次被直接检验，不成立**：对喂入的 navtest 曲线重算 R² 0.524，预测 +0.49（stage 1 的预测 +0.48），实测 −0.03 [−0.21, +0.16]，预测值在实测 95% CI 之外，实测 / 预测 = −0.05。换算的两类校准点（第 204 条的独立噪声臂与 QH）都是特权信号加噪或很差的头，外推到「准但与 policy 相关」的头上不成立。

**跨步的读法**：三种载体都把 plan 的 4 s heading 误差降下来了（> 45° −3.19° / −1.21° / −1.67°），没有一种降低 > 45° 的 DAC 失败率（−0.03 / −0.13 / −0.10 pp，CI 都含 0），EPDMS 的变化全在 ±0.2 以内。B 里失败只是换了类型（转不过去 → 切内角）。**4 s heading 误差不应再作为转弯工作的闸门或代理量**：它能被显著移动而出界率不动。第 243 条 G1（head 比 plan 准 2.4–2.7°）仍成立，但「准的 heading 描述喂回去值多少分」的答案在 pilot 上是约 0。
**对方向的含义**：(1) 冻结 token 上的 heading head 这条支路按现有三种接法不值分，不再加变体；C 的 +0.18 落在线下，是否在全量 `P2H10S` 上保留要另做决定，本条不支持。(2) 以后的转弯臂直接读 > 45° 的 DAC 失败率与转弯失败分类（切内角 / 转不过去），不读 heading 误差。(3) R² 换算规则作废，不要再用它设闸门。(4) A2 的结构效应（attention 结构比 thin head 好 4°）是对 head 精度的描述，与分数无关。
**状态**：**成立**（中偏弱）。限定：探索性，闸门未过之后的第二次尝试；pilot 规模（3 000 步），每臂 2 seed，开环；B 的登记判词是「上限未量到」，「plan 在用通道」是登记规则之外的读法；B2 只有一个剂量；A 的候选只在 89 个 log 上选，navtest 的 head 是 fold 0 的模型；navtest 在本 lane 被多次读；转弯失败率行只有 1 517 个 token。
**会推翻本条的证据**：全量规模的同一臂 EPDMS ≥ +0.5 且 > 45° DAC 失败率下降；B2 在更大剂量（λ > 10 或梯度占比 > 10%）下转弯失败率下降；一个 heading 误差降低同时 DAC 失败率下降的载体。
