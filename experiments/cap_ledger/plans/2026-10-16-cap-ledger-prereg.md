## 4. 分类（每格、每阶段，对 P0 配对；CI = log 聚类 bootstrap，B 10 000，seed 0）

- P0 状态：成功率 ≥ 0.60 = 好；< 0.40 = 差；之间 = 部分。
- Δ = 阶段 − P0（同一行配对）。
  - **LOST**：P0 好，Δ ≤ −0.15 且 CI 上界 < 0。
  - **DEGRADED**：P0 不是好，Δ ≤ −0.15 且 CI 上界 < 0（也算丢失）。
  - **GAINED**：Δ ≥ +0.15 且 CI 下界 > 0。
  - **NEVER**：P0 差，该阶段仍 < 0.40，且不是 GAINED。
  - **UNCHANGED**：其余；Δ ≤ −0.05 且 CI 上界 < 0 时加注「eroded」（只报）。
- **丢在哪一段**：LOST / DEGRADED 的格，按谱系顺序第一个「对前驱 Δ ≤ −0.10 且 CI 上界 < 0」的阶段。

## 5. 判词（能力组）

能力组：等（W）、起步（G）、停前车（S_L）、停红灯（S_R）、停车标志（S_SS）、绿灯通过（GO_G）、跟车（F）、巡航（C）、变道（LC_L、LC_R）、转弯（T_L、T_R）、
弯道（K）、让行（Y_P、Y_V）。组内任一可判格 LOST / DEGRADED → 该组丢失。**补丁范围** = 等、起步、停前车、停红灯、停车标志（等待训练方案的 W / G / S 行）。

- 补丁范围之外、在**底座阶段**（P2-F 或 RB0-F）丢失的组 ≥ 2 → **支持重建底座**（不筛选、按行为分层的 trainval 混合）。
- 恰 1 组 → 「补丁 + 一项」：针对那一项补行，不足以支持整体重建。
- 0 组 → **只补等待一族就够**；只在后段（on-policy S 轮等）丢失的组单列，指向那一段的配方而不是底座。
