## 离线测量（已做，见 results/lowspeed_ctrl.md）

c = 每 0.25 s 步实现的朝向变化 / 计划 1 s 方向，按速度分档，合成（恒定偏向计划）与日志回归两种读法。openpilot 真车栈的等效 c 只能按其文档化限值估计（没有
vendored 源码，数值凭上游 drive_helpers 记忆，标为估计）。

## 规则（唯一主臂 `lowspeed`，参数事先定，不按闭环结果调）

代码 `lib/lowspeed_ctrl.py`；HUGSIM 端 `patches/hugsim/optional/lowspeed-ctrl.patch`（tree `lowspeed` = PR #57 + 本 patch，env `LOWSPEED_CTRL`）；
B2D 端 `scripts/b2d_zeroshot_agent.py` 的 `LOWSPEED_CTRL`（仅 HUGSIM 过线或接近才跑）。

1. **默认值取 openpilot 自己的**：曲率变化率上限 |dκ/dt| ≤ MAX_LATERAL_JERK / max(v, 1)²，MAX_LATERAL_JERK = 5 m/s³（`clip_curvature`）。
   离线合成已显示它在 0.5–3 m/s 完全不约束（c 与无规则逐位相同），所以它只是惰性的原则性底线，**不是**有效成分。
2. **有效成分是调出来的（披露）**：对控制器给出的目标转向角做一阶低通，时间常数 τ(v) = 3.0 s（v ≤ 2.5 m/s），线性降到 0（v = 3.5 m/s）；每步
   α = dt / (τ + dt)。τ 的选取依据只有离线 c：把 HUGSIM 日志 c（< 1 / 1–2 / 2–3 m/s：0.066 / 0.146 / 0.307）乘 α 后，步 1 的 c ≤ 0.03（目标
   < 临界 0.03）；没有用闭环结果挑。参数 JSON：`{"jerk": 5.0, "tau0": 3.0, "v0": 2.5, "v1": 3.5}`。
3. 与第 96 / 101 / 107 条的区别：不碰模型输入和计划，不看不确定度，不按榜调参；只改控制器在低速对计划朝向的跟随速率。

- 另报：按起步事件的打转（首次起步与停车后再起步，定义同 spin_attribution：再起步 = v ≥ 1 且前 2 s 内 < 0.4，打转 = 发散起点在事件后 0–12 步），
  RC、碰撞、停在原地（max_steps）数，以及基线打转的 10 个场景各自的结果。如果 ≥ 3 个新场景从不打转变成打转，单独列出。

## 判读

- A 两条都过且 B 两条都过：作为两个闭环榜统一的低速控制规则采用。
- A 过、B 不过：只能作 HUGSIM 单列 trick，报 B2D 的代价来自哪类路线（路口转弯 / 起步）。
