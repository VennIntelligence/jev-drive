## Bottom line

FM cuts navtest off-road failures on turns above 45 deg by 5.0 pp (saved 184 token-seeds, hurt 33) and lifts navhard (combined +7.6, stage 2 +8.6), but it
**buys this by lowering other things**: whole-board EPDMS -1.10, EP -5.57, LK -4.78, EC -3.31, and the < 5 deg bucket -2.33. By the registered
no-regression rule (amendment A.4) FM is **not a candidate**; by the original lines the primary reading is "effective", the guard fails, so "continue" is
false. The branch closes. RG against SH30 (new head + L2 tail) is also slightly worse, not better.

  (< -0.3), < 5 deg bucket -2.33 (< -0.2). **Both fail.**
- **Continue**: "主判定有效 + 护栏过 + 全板 EPDMS FM - RG 点估计 >= +0.3". Point estimate -1.10, guard failed. **Branch closed.**
- **Mechanism (not a verdict line)**: "FM 的 > 45 deg |C(4 s)| 应比 RG 低 >= 0.10 m (CI 上界 < 0)". Observed FM - RG = **+0.195 m [+0.130, +0.252]** (FM 1.068, RG 0.872,
  SH30 0.883; the 0.71 / 0.88 m reference of decision 207 is reproduced by SH30: 0.712 on > 20 deg, 0.883 on > 45 deg). **Not met, the opposite sign.**
  Sample spread on > 45 deg is 4.3 x that on < 5 deg (sd lateral 0.208 m vs 0.048 m) but only 0.18 of the served plan's RMS lateral error (1.18 m);
  neighbouring-sample max gap / range is 0.25, the uniform-draw value, not two clusters. "Both absent -> the two-sided offset is not mode averaging (at least not a
  separable mode in this hidden state)": the second clause holds, the first does not.
- **Amendment A.4 (no-regression rule)**: "FM 成为候选，当且仅当下列每一格的 FM - RG 都不是「CI 整体 < 0」". Five cells are wholly below 0 (below). **Not a candidate.**
  RG - SH30 (the same table): four cells wholly below 0, **not a candidate either** (no cell of it was meant to be adopted; reported for the record).
- **Amendment A.3 (HUGSIM 64)**: condition "FM 对 RG ... 任一项上 CI 整体 > 0" **is met** (FM - RG navhard combined +7.60 [+4.26, +11.03], stage 2 +8.61 [+4.97, +12.32]);
  RG - SH30 is not. The amendment also says the head has no HUGSIM serving path and that it must be built before the run. It was **not built and
  not run** in this lane: it needs a new bench serving option (head behind the tapped `select_4`, an equivalence gate on navtest rows, TRT engines) on a box that has no
  free memory margin, and the A.4 rule needs every cell not-below-0, so a HUGSIM cell can only add a possible regression: it cannot rescue FM. Open for the coordinator:
  build it only if FM's profile (fewer off-road, slower, wider, laterally noisier) is wanted in closed loop for its own sake.

## Caveats

Two seeds per arm; CIs are over logs, the seed spread (FM - RG per seed agree within 0.1 for EPDMS) is smaller than the CIs. RG - SH30 differs by two things (new head, L2 tail). One head structure, one hyperparameter
set, as registered; the loss was a z-score flow with a sigma-normalised L2 on x-hat, so a different loss weighting or sampler is not tested. The 23 significant fine cells and the flip rows are descriptive.
