## 处理

每帧对每个出口类别 c（左 / 直 / 右；同类多个出口取第一个）各跑一次：在全部 31 步历史帧上画同一个世界坐标里的覆盖物，每个源帧用它自己时刻的
ego 位姿投影（关键帧用日志位姿，GIMM 帧用 op_interp 的 EgoTrack），road 和 wide 两路都画。

| 族 | 内容 | 路线与涂色的关系 |
|:--|:--|:--|
| band | 绿色半透明带（1.8 m）沿进口和指令支路 | 路线 = 涂色 |
| lines | 指令支路两侧白实线 | 路线 = 涂色（弱） |
| arrow_road | 指令路径上 ego 前 8–16 m 的白色地面箭头（随路径弯） | 路线 = 涂色 |
| sign | 路口远角右侧蓝底白箭头牌 | 不在路面上 |
| cones / barrier / wall | 其他支路在离指令路径 ≥ 4 m 处横放锥桶 / 红白挡板 / 3 m 灰墙 | 路线 = 没涂色 |
| fill_grey / fill_grass | 其他支路从 ≥ 4 m 处起路面涂灰 / 草地 | 路线 = 没涂色 |
| band_all（对照） | 所有支路都画 band | 有涂色、没有路线信息 |

直行帧：none、band、lines、arrow_road、sign（指令 = 本车道）。

## 指标（计划转到 t0 后轴坐标）

对支路 c 的中心路径 Q_c（进口 + 支路），计划点 x 到 Q_c 的距离 d_c(x)。对一帧的两个指令 a、b，m(x) = d_a(x) − d_b(x)（正 = 更靠近 b）。

- **主指标 Δ4**：同一帧、同一族，Δ = m(P_b(4 s)) − m(P_a(4 s))，单位 m，对帧内所有有序指令对取平均；正 = 计划跟着指令走。
  `none` 下两个指令的计划相同，Δ ≡ 0。同样报 2 s、3 s 和朝向版 Δψ（计划 yaw 差投到两支路切向差的符号上，度）。
- **正确率**：4 s 处计划离指令支路比离其他支路都近的比例；只算「有判别力」的 (帧, 指令)：该点处两支路中心线相距 ≥ 1.5 m。
  `none` 的正确率是基线（两类路口约 50%）。
- **副作用**：族 − none 的 4 s 纵向位置变化（计划变短 = 被读成要停）；直行帧上 3 s 处相对日志未来的横向误差变化。
- CI：95% cluster bootstrap（按 log，2 000 次）。分层：速度 stop < 0.5、low 0.5–3、moving ≥ 3 m/s；路口类型。

## 判读（事先定）

- 某族 **zero-shot 成立**：Δ4 的 CI 下界 > 0 **且** 正确率 ≥ 75%。
- **部分吸收**：Δ4 的 CI 下界 > 0，但正确率 < 75%（或 Δ4 < 0.5 m）。→ Q2 的微调有依据。
- **不吸收**：Δ4 的 CI 含 0。**反向**：CI 上界 < 0。
- 「回避涂色」vs「跟路线」：路线 = 涂色的族（band / lines / arrow_road）与路线 = 没涂色的族（fill / 障碍）的 Δ4 若**同号为正** → 读的是路线；
  涂色族正、障碍 / 填充族负 → 只是被涂色吸引；反之 → 只是回避覆盖物。
- band_all 与直行帧：只看副作用。直行帧横向误差变化 > +0.2 m 或 CI 下界 > +0.1 m 记为「伤车道保持」。
