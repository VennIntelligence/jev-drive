### 烟测与同一性（训练前，`r5.sh smoke R`，3 个 60 步作业）

  训练器记录的 `road_pai_rows` = 索引 ok 行数 322 982、`road_pai_w` = 1；无抹平；抽样份额 = 0.25 / 0.125 / 0.125；快照文件存在。

### 读数与登记线（对 R2C 同场景；R3MV 列作参照）

PAI-FIX 原生（VC + LEAD，`v t` 两组 chunk）；`r5.py gate --stem gate_r5r`：

1. **G-LAUNCH 均分 ≥ 0.815（CTRL 0.865 − 0.05，硬线）**；
2. **T281 路线转零分 ≤ 7（CTRL 12 − 5）**；
3. **TARGET（val160 60 场景）均分 ≥ 0.503（CTRL 0.523 − 0.02）**；
4. **按类护栏（新）**：TARGET + G-LAUNCH + G-LEAD（72 场景，两份读数都计分、无 RPC 的场景）上，每个零分类（overshoot / route-turn / offroad / AF-front / side / zero-other）
   的零分数 ≤ CTRL 同类 + 3。

- 报告：对 R2C 与对 R3MV 各一份 pai_fix 报告（附 NTV0、R2J）；G-LAUNCH 起步数与被追尾数；R5-R − R3MV 按类零分（出路零分是这一臂要看的）。
- **惯性闸（只报告）**：NTV0、R2C、R3MV、R5-R、RSG 一起跑 `inertia.py cf --name round5r`，`lon_anchor.py inertia` 对 R2C 出表。
- **停止规则**：四条都过 → 提交 R5-R 的 **PAI 281 ACC + GAP**（PRIO 30，NTV0 + ACC + GAP 的 chunk 表，g10、FAST=1，同第 2 / 3 轮），对存档 NTV0 + ACC + GAP 与 R2C + ACC + GAP 配对
  （均分 CI、按类零分、起步数 / 37，另列对 R2J）。不过 → 不读 281。**无论 R5-R 过不过，第 2 段照常**（R5-R 是 R5-A 的配对对照）。
- 预期（读之前写）：道路 hinge 只管侧向，第 418 条 G2 显示它在出路零分上触发但很浅（中位 0.005）→ 预计出路零分最多少 1–3 个，TARGET 与 T281 与 R3MV 持平；
  起步不受影响，G-LAUNCH 预计仍在 0.57 附近、不过硬线。若 hinge 反而让起步或转弯变差（例如在路口把计划往回拉），记录为副作用。
- 噪声：G-LAUNCH 只 6 场景，一个起步约 ±0.17；单 seed，TARGET 种子差约 ±0.04（第 406 条）。
