## What this says

- On this subset the pilot's ego status, pose history and command (P2), and the side / rear cameras on top (P3), do not cut the launch
  spin loop that decisions 92 / 111 / 118 suspected of missing ego motion: in the launch spinners the onset step is the shipped model's. What the inputs change
  is the longitudinal behaviour (no standing, faster launch), consistent with the adapter reading speed. [I] The spin onset (steps 12-18,
  ~3-4.5 s) is inside the first seconds after the 5 s static warm-up, i.e. while the history the model sees still contains the repeated
  first state; whether a real pre-start history would change it is not tested.
- WA-JEPA's lead on these 10 is not reached by the input-parity pilot (0.27-0.32 vs 0.59).
- Pilot only: 5 400 navtrain rows, 600 steps, one seed, one run per scenario; per-scenario HD differences below ~0.2 are within the
  rerun-to-rerun spread (the 2026-10-03 rerun of shipped Cinque differs from the stored run by 0.46 on 8440_8640-easy).

## Setup

- Harness: `zs_run.py --preset exam --controller fixed`, opts `{parity: {socket}}` + traffic (the stored `cinque-fixed` configuration plus
  the parity inputs), TensorRT, dilate clock, 5 s static warm-up, desire on, 400-step cap, one run per scenario, scored by
  `hugsim_evaluate`. The 10 = `experiments/hugsim/scripts/derot_spin10.txt`.
- Classes as wajepa_ref.md: spin = heading error >= 60 deg against the recorded route at some step (`spin_analysis.py`), else the runner's
  end reason; launch stall = peak speed over the first 40 steps < 1.6 m/s.
- Arms: P0 = shipped weights, untrained P3 adapter (bias exactly 0) through the full path; P1-s0 fine-tuned plan pathway, no bias;
  P2-s0 + ego / pose / command bias; P3-s0 + side / rear camera tokens. Ego inputs on the model clock (vx x1.25, see hugsim_harness.md).
- Cost: 4 pool jobs (40 GB, 12 cores each), all 40 runs in ~13 min of wall time (most spinner runs end within 20-70 steps), plus a
  2-scenario P0 smoke.

## Caveats

- The P2 / P3 bias rms in closed loop is ~0.50 / 0.52 (T3); its NAVSIM-row distribution was not compared here.
- HUGSIM gives no lateral velocity / acceleration: vy = ay = 0 as in WA-JEPA's client, while the NAVSIM rows carry ay in turns.
- Spin counts use the 60 deg rule only; the 45 deg sensitivity was not recomputed.
