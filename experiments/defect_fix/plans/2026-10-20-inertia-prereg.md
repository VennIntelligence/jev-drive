## 问题

## 窗口类型（逐决策）

- **STOP**：rest ∈ [8, 40] m，停车点前无物（lead = False）。子集 STOP-line（line = True）。
- **NS**（停车对照）：人 8 s 内不停（rest > 8 v0 或无），前方 [-2, 40] m 走廊无物。
- **TURN**：人前方 40 m 航向变化 >= 30°，rest > 40 m，前方 40 m 走廊无物。
- **OPEN**：NS 且人前方 60 m 航向变化 < 10°。

## 反事实臂（帧 / token 与 route memory 固定，除非注明）

  重排到弧长 × f、偏航沿折线插值（第 375 条 s08 / s12 的规则，`warp_loop.respace`）。

## 量

- plan = 8 个后轴位姿（0.5 .. 4 s）。段速 = 相邻位姿距离 / 0.5 s（原点起）。
- **停车站位 S**：第一个段速 < 0.5 m/s 的段的起点弧长；没有则 = 4 s 弧长（删失），并记「plan 含停车」。
- **ΔS_+20**（每 +20 % 输入速度的停车站位移动，米）：R 通道 = [S(R_1.2) − S(R_0.8)] / 2；总响应 = 0.2 × [S(B_1.5) − S(B_0.5)]；帧通道同理
  用 W。停车比例变化同样线性化到每 +20 %。另报 S(F) − rest（相对人的停车点）。
- **运动学参照**：plan 只是带固定减速度外推输入速度 → 停车距离 ∝ v²，+20 % 速度 → +44 % 距离；锁在线索 → 不动；4 s 弧长纯延续 → +20 %。
- **G**（第 375 条的 4 s 弧长增益）：G_X = Σ[A(X_hi) − A(X_lo)] / Σ[4 s × (f_hi − f_lo) × v0]，R 用 0.8 / 1.2，W / B 用 0.5 / 1.5。
- **v24** = plan 2–4 s 平均速度；**Δhead20** = plan 在 20 m 弧长处的航向（度）每 +20 % 的变化。
- **通道份额** = ΔX_R / ΔX_B（同为 0.5 / 1.5 的线性化），X = S（STOP）、A（其余）。
- 95 % CI：场景聚类 bootstrap，B = 2000；每格 < 15 个场景只描述、不判。

## 判读（主：NTV0-L18-s0，总响应 B；B 不可用时用 R 并注明）

- **STOP**：ΔS_+20 < 1 m 且停车比例每 +20 % 降 < 10 个百分点 → **锁在线索（H-CUE）**；ΔS_+20 > 3 m 或停车比例降 >= 25 个百分点
  → **惯性（H-INERTIA）**；其间 → **混合**。辅助：G_STOP / G_NS <= 0.3 锁、>= 0.7 惯性。
- **TURN**：G_TURN / G_OPEN >= 0.7 或 Δhead20 <= −2°（快了转得少）→ 惯性；比值 <= 0.3 且 |Δhead20| < 1° → 锁在线索；其间 → 混合。
- **OPEN**：v24 对输入速度的斜率（B）>= 0.7 → 复制输入；<= 0.3 → 按场景定速度；其间 → 混合。另报 F 下 plan v24 − 人同站位 v24。
- **通道**：份额 > 0.5 → 喂入行为主；< 0.5 且 CI 不含 0.5 → 帧为主。
- **底座**：RB0 与 NTV0 的判读相同且 |ΔS_+20 差| < 1 m → 「底座里已有」。
- 总结论：STOP 与 TURN 都判惯性 → H-INERTIA；都判锁 → H-CUE；否则混合（分别写明）。

## 局限（先写下）

- 状态是 RSG 的、场景是练习池的，不是 NTV0 在 23 / 11 个失败场景上的状态；线索的强弱分布可能不同。
- 帧拉伸同时把其他车辆、信号的表观运动放快 / 放慢（STOP 与 OPEN 无物，影响小；仍是混杂）。
- ax × f 是线性近似（严格的时间缩放是 f²）。开环单决策，不含闭环累积。
