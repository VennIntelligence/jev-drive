# SLOT-RULE 预登记（2026-10-22，写在任何读数之前）

## 问题

nuPlan 赛道上 8 个策略槽（t0 − 1.4 … t0，每 0.2 s）只有 −1.0 / 0 s 是真关键帧（2 Hz），其余 6 个由**最近关键帧**沿自车轨迹
warp 出来（`sh30_core.lattice_gpu`，与 `op_interp.synth_cpu` `warp` 同一规则；训练数据 `pp_prep` protocol W 也是这条规则）。
最近规则下各槽的 warp 偏移（槽时刻 − 源关键帧时刻）是 +0.1 / −0.2 / 键 / +0.2 / −0.1 / +0.1 / −0.2 / 键：相邻槽交替前推 / 后拉，
用户手驾时看到画面「呼吸」（往前拉伸、再弹回）。问：这对模型的 plan 有没有影响？用户的先验：大概没有，因为底座就是用这条规则训的。
诊断，不训练，只开环。

## 做法（复用 WARP-LOOP 的 dump / 重合成）

- 诊断开关 `SH30_SLOT`（`sh30_core`，env，默认 "" = 最近规则，与改前逐位相同；`lattice` / `lattice_gpu` 另有 `rule=` 参数）：
  - `fwd`：每个合成槽由**它之前（含）最新的**关键帧前推（偏移 +0.1 / +0.3 / 键 / +0.2 / +0.4 / +0.1 / +0.3 / 键）；
  - `bwd`：由**它之后最老的**关键帧后拉（−0.4 / −0.2 / 键 / −0.3 / −0.1 / −0.4 / −0.2 / 键），次要、只描述。
  关键帧、喂入行、warp 轨迹（原生自车轨迹）都不动；冷启动（键不足 4 个）时最老键之前的 backwarp 槽也不动。
- 输入：`native_gap` 的 270 个移动窗（6 个分片）原生大考场 held 闭环 dump（每个决策的 8 槽帧、喂入行、served plan）。
  - 主模型：nuPlan 当前候选 B2 `STANDFMXH-L18-s1`（decisions.md 现状，第 391 条）：用同一条命令（`native_gap.sh dump`，
    `jt.sh aread … off` 的原生 serve + `SH30_DUMP`）新 dump。
  - 参照：NTV0-L18-s0（WARP-LOOP 已存 dump；PAI 领先族 R6DAG / R8K 在 nuPlan 上与 NTV0 同级，第 444 条，不另 dump）。
- 每个决策（`warp_loop.py slot`，GPU，serve 默认的 `lattice_gpu`）：关键帧 / 历史按 WARP-LOOP cf 的规则从 dump 重建；
  plan F = dump 帧前向；N / FWD / BWD = 三种规则重建的帧前向（同一喂入行、同一路线记忆）。比较一律 FWD − N、BWD − N
  （同一条重建管线，重建误差相消）。
- **门（不过就停，不读结果）**：N 对 dump 的 served plan 最大位置差 p99 <= 0.06 m、max <= 0.15 m（WARP-LOOP / native_gap 的门）；
  F 对 dump plan 同样。

## 量

- 4 s 弧长比 R = Σ A_FWD / Σ A_N（A = 原点经 8 个位姿的折线长）；
- plan 速度 1 / 2 / 4 s（相邻 0.5 s 位姿间距 / 0.5 s）之差 FWD − N（中位与均值）；
- 规则间位置 ADE（8 个位姿的平均欧氏距离）与横向 ADE（差投影到 N 各位姿朝向的法向）；
- 份额 S = ADE(FWD, N) > 0.3 m 的决策占比；参照噪声：ADE(N, F) > 0.3 m 的占比（重建 vs dump 帧）。
- 决策集：k >= 3（4 个真关键帧，冷启动之后）。类别（按决策，优先级从上到下）：
  - 静止 stopped：当前车速 < 0.5 m/s；
  - 起步 launching：0.5 <= v < 6 m/s 且同一 session 更早某决策 v < 0.5；
  - 转弯 turning：v >= 2 且（N plan 4 s 偏航 >= 15° 或 历史 1.5 s 偏航 >= 10°）；
  - 巡航 cruising：v >= 2 的其余；
  - 其他 other：其余（慢行、无先停）。
- 95 % CI：窗聚类 bootstrap B = 2000。

## 判读线（主：B2；NTV0 同表、同线，只作参照不改判）

- **影响大（matters）**：巡航决策 |R − 1| >= 0.03，**或** 全部 k >= 3 决策中 S >= 10 %。
- **没影响（does not matter）**：巡航 |R − 1| < 0.015 **且** S < 5 %（点估计；同时报 CI）。
- 介于两者之间：记「小影响」，不行动，结论照写。
- 起步 / 转弯 / 静止各类的 R 与 ADE 只描述（静止类弧长近 0，看 ADE 与弧长差米数，不看比值）。

## 各结果之后

- 没影响 / 小影响：关闭；serve 维持最近规则，不改。
- 影响大：说明 plan 对槽规则敏感、训练与 serve 必须同一规则；**只提议**一个训练侧测试（例如前推规则重建训练帧、同配方一条
  1 000 步 pilot，对照原生大考场读数），不启动；serve 侧不换规则（与训练分布不符）。

## 规模与停止

- 每模型约 270 窗、约 2 000 个 k >= 3 决策；B2 6 个 dump 读（各约 45 窗）+ 12 个开环 job + 1 个报告 job，都经 GPU 池串起。
- 门不过就停下查原因，不读结果。
