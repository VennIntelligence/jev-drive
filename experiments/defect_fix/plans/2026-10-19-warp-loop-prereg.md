## 阶段 1：开环（存档输入，`scripts/warp_loop.py cf`）

- 输入：JTN-L18-s1 与 RSG-L18-s0 的 `native_gap/dump`（270 个移动窗，6 个缓存分片）；NTV0-L18-s0 用同一条命令（`native_gap.sh dump`）
  新 dump 同样 270 窗；静止窗：`redline_probe/dump`（JTN-L18-s1，878 个 static 窗 + 105 个 G / N3）。
- 关键帧重建：决策间隔正好 0.5 s，关键帧 = 前几个决策 dump 的槽 7（k = 0..2 冷启动 1..3 个关键帧，同 serve）。历史位姿 = 喂入行
  `ego[8:20]`（已含 fill_history 回推），各关键帧的体速度 = 该时刻决策喂入行的 `ego[4:6]`（回推的键 = 最老真键的速度，同 fill_history）。
  **门**：用原生轨迹重建的 8 槽与 dump 的 `cur` 逐字节比；不全等时 plan 差 max <= 0.05 m（同 dump 帧前向 F 对 dump plan：<= 0.15 m，
  同 native_gap cf 的门）。不过门就停下查，不读结果。
- 替代 warp 轨迹（关键帧不动；只改 6 个合成槽的 warp 源 / 目标位姿；位置沿自车自己的历史折线重新按弧长排布，偏航沿折线插值，
  体速度方向不变、大小换掉）：
  - `hum`：人在每个历史键所在站点的日志车速（native_gap cf H 同一规则：梯形积分弧长）；
  - `const`：恒定 = 当前测得车速，无历史趋势；
  - `stand`：静止（4 个位姿全在 t0，速度 0：合成槽 = 最近关键帧原样）；
  - `s08` / `s12`：自车自己的历史弧长与速度 × 0.8 / × 1.2。
- 每个轨迹三种喂法：**W**（只换 warp，喂入行不动）、**R**（只换喂入行的速度历史 = vx、ax、3 个过去位姿，帧不动；`hum` 的 R 就是
  native_gap 的 H）、**B**（两者都换）。加 F（原样）。共 16 次前向 / 决策。
- 量：plan 4 s 弧长 A（原点经 8 个位姿，同 native_gap）；轨迹的历史平均速度 ū = 1.5 s 弧长 / 1.5 s。
  **增益** G_X = Σ[A_X(s12) − A_X(s08)] / Σ[4 s × (ū_s12 − ū_s08)]（X = W / R / B；1 = 原样延续）。
  人速度交换：同 native_gap A3 的 recovery (X − F) / (1 − F) 与 gain (vp_X − vp_F) / (vh − v)，X = W / R / B（`hum`）。
- 决策集（移动）：k >= 2，当前车速 >= 2 m/s（增益），人速度表另加人 >= 2 m/s（同 A3）。分层（每决策，dec.parquet）：
  前车（lead_gap <= 30 m）/ 停后（同窗之前某决策车速 < 0.5 m/s）/ 自由（其余）；另按窗 stratum（cruise / braking / turn / launch / other）。
- 95 % CI：窗聚类 bootstrap B = 2000，配对差同一组抽样。

## 判读（阶段 1，主：JTN-L18-s1 移动决策）

- **帧是主通道**：G_W >= G_R（点估计）。**帧占大头**：G_W − G_R 的 CI 下界 > 0。**帧不是通道**：G_W < 0.5 × G_R 或 G_W < 0.05。
- **阶段 2 条件**（任务书）：G_W >= G_R（点估计）且 G_W >= 0.10。否则不做阶段 2，只报阶段 1。
- 静止窗（JTN1，P / U / F / N1 / N2 各类，按 JTN1 原生零分 / 成功分）：creep 增长 = 中位 A(k) − A(0)（k = 5..9 的平均）。
  `W_stand` 下增长 <= F 的 25 % 记「蠕行放大消失」，25-75 % 记「部分」，> 75 % 记「不靠 warp」。另报零分窗 k >= 2 的决策里
  `W_stand` plan 弧长 < 2.5 m 的比例（第 372 条的蠕行阈值）。注意：真关键帧本身已带蠕行运动（-1.0 / 0 s 两槽不动），所以开环
  只能读出 warp 的那一份。
- RSG / NTV0 同表报告，不改判读。
