### 2.3 每 batch 的 trainval 行数（理由）

k_tv = round(115 × n_tv / (n_nav + n_tv)) = **52**（底座的 115 个 normal 槽 = 128 − 13 yaw-rate 行；即 si.py pack 的规则用在底座阶段）：
每个 trainval 行与每个 navtrain 行平均被抽的频率相同（「把数据并起来」的中性选择），三档用同一个 k_tv，只差 trainval 内部的类权重，于是第三档就是 SIU 的混合。

navtrain 本身有约 8 300 个从静止起步的行，所以起步信号不只来自这 876 行。

## 3. L18 阶段（RSG 的温和配方：2 500 步、lr × 0.1；池 = on1_L18RB0 + on1_L18RTB1 合并为 `on1_L18NR1`，34 918 行，S 行 self 模式）

### 3.1 历史速度噪声

`--ego-scale-speed 0.5 --ego-scale-max 0.2`（只在模仿行上；池行与 anchor 行不加）。平行的 V2AC-L18-s0 读的是 V2 + 这个噪声单独；它的结果转来后按第 6 节处理。

### 3.2 硬 / 软约束 hinge（`lib/nr1_lat.py`；只加在池行上，只沿各点自身航向的横向移动，无目标位姿、无拉向中心线）

- **硬**：路牙 / 出路 = 现有 road hinge（不变）；车辆接触 = 现有 agent hinge（不变）；
  **旁车预留**（扩展 agent hinge）：在本车横向走廊之外、不在本车后方的被记录物体，`relu(buf − 距离)`（无前伸的本车框），只在有车的一侧起作用；
  **对向车道**（按点）：后轴与车框中心（后轴前 1.461 m）落在对向车道里，按评估器的车道多边形与投影处中心线方向（zeros_mech `Lanes.cls` 规则：
  有一条含该点的车道与**该点自身航向**相差 < 60° 就算同向，否则 > 120° 算对向），航向分 7 档（−90 … +90°，30° 一档，超出夹到 ±90°）逐行逐档预算 SDF
  （`df_lat.py build`），路口格（含该点的两条车道方向差 > 30°）不算；第 281 条的代码移植，改了两处：逐点航向（不再用 t0 航向）与路口格剔除。
- **软**：同向车道中不属于本车自己车道链（t0 后轴所在同向车道、其后继 100 m、前驱 20 m）的部分，路口格不算。
  「只在空、且无路牙处」：有车时由硬的旁车项与 agent hinge 接管（权重大得多），有路牙时由 road hinge 接管；软区不挖掉车的位置，否则梯度会指向车。
- 剂量：对向权重 **0.15 / 0.3**（第 281 条的 0.25 / 0.5 同一刻度：road hinge 的 λ 10 = 1）；软 = 对向 / 5；旁车预留与对向同权（它是 agent 接触项之外的
  缓冲，接触本身仍是现有 agent hinge 的全权重）。
- **标签闸（训练前）**：人的日志路径（池行 meta 的 logfut，从人自己的 t0 位姿起，只取本车离人 ≤ 1 m 的行）上，新硬项的并集激活 ≤ 1 %，软项 ≤ 5 %；
  同时报 V2（RTB1ARO-L18-s0，喂路线记忆）在同一批池行上的 plan、池行自己的 served plan 的激活，以及现有 road / agent hinge 的激活（参照，不进闸）。
  变体按登记的顺序取第一个过的：先 buf 0.4 m 再 0.25 m，每个 buf 下对向允许深度 0 → 0.3 → 0.5 m；软项允许深度 0 → 0.3 → 0.5 m。
  并集都过不了：只留单独能过的那一项（先对向后旁车）；一项都过不了：L18 pilot 只跑对照（无 hinge），并立即报告。（`df_lat.py gate`，结果 `results/lat_gate.md`）

  软区同样用长过的路口格）。
