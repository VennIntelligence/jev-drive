# 第 6 轮 A 线：DAgger + 特权地图老师（只教侧向）（10-21，用户批准；任何滚动 / 闸读数之前写定）

依据：第 427 条（MV 系在提交 serve 下的短板是侧向）、第 429 条（新弄坏 NTV0 满分场景最贵）、第 430 条（MV-LC：变道过滤解释漂移 / 变道零分，
不解释出路；出路对 NTV0 +9 / +12，尺子 −266 / −285）、第 408 条（LON-ANCHOR 教纵向会推快 → 本线不教纵向）、第 418 条（道路 hinge 在 PAI 行上
弱，修不了直路出路）。
代码：[../scripts/dag.sh](../scripts/dag.sh)（链）、[../scripts/dag.py](../scripts/dag.py)（老师 / 闸 / 表）。盒上 `$DATA_DIR/runs/round6/dag/`。
结果：[../results/dagger/](../results/dagger/)。

**问题。** PAI 人类行配方（最好的是 MV-LC，R5LC-L18-s0 / s1）修了路线转弯零分，却在 PAI 281 上比 NTV0 多 9–12 个出路零分，多数落在 NTV0
能过的场景。读法：典型的行为克隆协变量偏移——学生只见过人居中的状态，自己漂出去以后没学过怎么回来。**DAgger**：在学生自己的状态上，
由特权老师（NuRec 矢量地图 + 给模型的同一条路线）给出「回到路线车道」的侧向形状，纵向不动。

## 1. 老师（只侧向）

- **路线**：AlpaSim 运行时的 MAP 路线生成器（`alpasim_runtime.route_generator.RouteGeneratorMap`，`route_start_offset_m 40`，与滚动的配置相同）
  在场景记录的 rig 轨迹上重建 = driver 收到的 route 消息切出来的那条折线。探针（8 个训练场景，s3 A 臂的 drive.jsonl）：记录的 waypoint 到重建
  折线的距离中位 0.05 m（= 比对时的 0.1 m 加密），只有日志之后的延长段在 2 个场景差几米到 22 m（运行时边走边延长）。
- **路口怎么选车道**：生成器自己的规则——对每个记录的位姿取 4 m 内、航向差 < π/8 的车道；上一条车道仍在候选里就保持，否则取它的后继里唯一
  的候选，否则取对后面最多位姿都成立的候选；位姿投影到所选车道中心线。所以穿过路口时路线走的就是人实际开过的那条连接车道（人的路线，含转弯）。
  日志之后由生成器自己的车道跟随延长 80 m（多个后继取航向最近的）。
- **横向换道台阶**：路线换到一条不是后继的车道时（侧向换道），折线有一个台阶（探针里 8 个场景中 1 个有，4.75 m）。在两条车道中心线之间按
  clip(3 s × 人的车速, 15, 60) m 用五次 smoothstep 过渡（台阶前用原路线点 → 新车道投影，台阶后用旧车道投影 → 原路线点）。
- 参考线：每 0.25 m 重采样，σ = 1 m 高斯平滑（去掉车道折线拼接的折角；半径 30 m 的弯只内缩 0.02 m）。
- **老师路径**：学生位姿投到参考线上航向差 < 90° 的最近点 → 站位 s0、带符号横偏 d0（左正）、航向误差 ψ0。Frenet 五次多项式 d(u)：
  从 (d0, tan ψ0 · (1 − κ d0), 0) 到 (0, 0, 0)，长度 **L = clip(2.0 s × v0, 6, 80) m**，之后沿参考线。|d0| > 5 m、|ψ0| > 60° 或没有航向一致的点 → 不出标签。
  合流的峰值横向加速度约 1.44 · d0 m/s²（与车速无关），2 m 横偏约 2.9 m/s²。
- **纵向不教**：标签的 8 个点放在老师路径上、弧长 = 学生**自己 serve 出去的 plan**（drive.jsonl `poses`，ACC / GAP 之后）同一时刻 0.5 … 4 s 的弧长；
  航向 = 老师路径切向；转到决策 anchor 的 rig 系。只改形状，不改快慢（第 408 条 LON-ANCHOR 的教训）。

## 2. 行

- 学生：**R5LC-L18-s0**，提交 serve：`JEV_VCONT=1.0 JEV_LEAD=1 JEV_ACC=1 JEV_GAP=0.7,2.7`，转向权重 10，ALPASIM_FAST=1，CONC 4，`PAI_DUMP=100000`、`KEEP_ASL=1`。
- 场景：与 S3 相同的 719 个非 held curated 训练场景（`experiments/round5/results/s3_scenes.tsv`，已排除 test281 / val160 及其驾驶组）。
- 行管线与 S3 / d402 相同，不改：onp_rows（rows + cold，`--tag R5LC-L18-s0`）→ onp_cache build → rf_pai_pool `--fut poses --prefix paid --src dagger`
  （名字 `on:paid:<scene>:<k>`）→ **池 `on1_PAID`**。token 按普通缓存顺序重编码，ego = driver 喂给模型的 `ego_in`（训练器读的就是它）。
- 行 = 学生 rollout 每个可用（8 槽有效）、第一次计分事件之前、日志结束之前的 10 Hz 决策（现有 PAI 池的规则）。**抽取 = 喂入车速 ≥ 2 m/s 且老师
  有标签**，其余行 fut = served、权重 0。为什么 2 m/s：低速时 served plan 的 4 s 弧长只有几米，标签点挤在原点附近、和 served plan 几乎一样，没有
  侧向信息；合流长度在低速被 6 m 下限撑住，曲率反而大；且 MV（R3MV / MV-LC）的 PAI 人类行也只取 ≥ 2 m/s，同口径。所有类都要（停车 / 急弯 / 起步 /
  其他），不按类加权。
- 清理：每块行建好且数量过线后删本链自己的 rollout.asl 与帧 dump（s3 的 clean 规则）；drive.jsonl 与计分保留。

- 训练与 281 读数由本线在 T1–T4 都过之后手动 `dag.sh launch`（先向主会话报闸）。

  合计约 10 GPU job 时。盘：帧 dump 临时（每块建完即删），行约 40 GB、缓存约 26 GB、池约 35 GB、合并约 32 GB（零拷贝 token）。

## 4. 闸（线在读数之前写定）

- **T1 老师在人的状态上复现人的路径（侧向）**：719 个场景的记录日志，每 0.5 s、车速 ≥ 2 m/s、有完整 4 s 未来的状态；老师从人的位姿出发，标签点
  按人自己的弧长放；误差 = 人在同一时刻的点减老师点、沿老师路径左法向。**线：全部状态 |误差| 中位 2 s ≤ 0.3 m、4 s ≤ 0.5 m**。转弯（人 4 s 内转
  ≥ 30°）与变道形状（D1 规则，老师按定义留在路线车道，预期不一致）单列；转弯中位超过线的 2 倍（0.6 / 1.0 m）就先检查老师的转弯几何再建行。
- **T2 老师在出路事件前留在路面内**：R3MV s0 / s1、MV-LC s0 / s1 在 PAI 281 ACC + GAP 上的每个出路零分，取第一次出路（没有则 left-corridor）事件
  前 2.5 s 的决策（road_pai g2 的规则：anchor = 该决策时刻控制器位姿，计时用该决策的 served plan）；老师标签的 Pacifica 车身（0.1 s 插值）在 road_pai
  栅格（评测器的 PAI 出路规则，anchor 处 −8 … 56 m）上的最小 SDF。**线：在 t0 车身仍在路内的事件里，老师有标签的 ≥ 80 %，且其中 ≥ 90 % 的老师标签
  最小 SDF ≥ 0**。并列报学生 served / model plan 的同一读数，以及 NTV0 不出路的子集。
- **T3 权重 0 逐位相同**：R5LC-L18-s0 记录的命令 60 步（JEV_RM_EAGER=1）两次：on1_JTPH / R5LC 对 on1_JTPHD / R6D0（PAID 行权重 0），df.py bitcmp 必须 identical。
- **T4 标签可行**：抽取行上标签的最大横向加速度（老师路径曲率 × 学生 served plan 在该弧长处的速度²）**p99 ≤ 4 m/s²**；同时报只算路线曲率的部分。
  不过：若超线的行 ≤ 3 % 的抽取行，这些行权重 0 后继续（写入报告）；否则停。
- 另外的确定性检查（不是闸，但不过就停）：输入路径（rf_recov fwd：R5LC 在池 token + ego 上的前向复现行文件里模型自己的 plan，中位 ≤ 0.02 m、超差 ≤ 10 %，
  错 checkpoint RB0-F-s1 超差 ≥ 90 %）；合并前缀与 on1_JTPH 逐项相同（mfix）；烟测（抽到 DAgger 行约 8 / 批、模仿行 32 + 8、批 51 / 13 / 72、各组份额与抽取文件一致、标量有限）。

## 6. 考场与判定

- PAI 281 ACC + GAP（round5 read281 的路径：NTV0 的块清单、g10、FAST=1、CONC 4）→ r2.py r281（对 NTV0、对同 seed MV-LC）→ 本线 verdict：
  均分、零分构成、出路数、「NTV0 满分场景上的新零分 / 部分分」→ 本地 PCS 尺子（d429 / pcs_r5l 的拟合与配池，DAG 在池外打分，与 NTV0 同一组 bootstrap 配对）。
- **adopt-candidate** = 两个 seed 都满足：(a) 均分 − NTV0 的配对点估计 ≥ 0；(b) 出路 + 其他零分 ≤ NTV0 + 3（= 21）；(c) 尺子对 NTV0 差的 95 % CI 上界 ≥ 0。
- **明显好于 MV-LC 但还不是候选** = 两个 seed 都满足：出路 + 其他零分比同 seed MV-LC 少 ≥ 5，且尺子点估计比同 seed MV-LC 高 ≥ 100 PCS。
  此时先问主会话再做第二轮 DAgger（滚新学生、重标、重训）。
- 两条都不满足：本线关闭，报告读数。
