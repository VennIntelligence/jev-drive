# 第 6 轮 B 线：扰动-恢复行（ChauffeurNet 式增广）预登记（2026-10-21，用户 10-21 批准，与 A 线 DAgger 并行）

## 问题

MV-LC（R5LC-L18-s0 / s1，d430）学会了转弯，但在 PAI 281（ACC + GAP）上出路零分比 NTV0 多 +9 / +12。PAI 人类行（on1_PAIH）的状态全在人开的车道中线上，
学生一旦偏离就没见过「怎么回来」。本线用增广补这块：把自车从人的轨迹上侧向推开（带航向偏差），在推开的位姿上用 NuRec 重新渲染输入帧，标签 = 从推开的位姿
平滑回到人的未来轨迹、速度按人的速度。

测的能力：策略在「偏离人类中线的状态」上的侧向恢复（闭环里出路零分的直接成因之一）。不是 serve 修补，增益只能来自模型。

## 行怎么造（代码 `scripts/rec.py`、`scripts/rec.sh`、`lib/rec_geom.py`、`lib/rec_driver.py`）

渲染路径 = on1_PAIH 的原样：pai_rows H 读（NTV0-L18-s0 在环、A0 serve、`onp_log_driver.py` 让自车跟日志、g10、`send_recording_ground_truth`、
KEEP_ASL、CONC 4、ALPASIM_FAST 默认）→ onp_rows rows / cold → onp_cache build → rf_pai_pool。唯一的改动：驱动器 `rec_driver.py` 返回给 MPC 的参考 =
日志 + 侧向偏移 E（沿日志航向的左法向），于是每个决策的渲染帧、自车历史（P / V / acc）都来自一辆真的沿扰动路径开过的车（ChauffeurNet：历史与画面一致）。

偏移几何（`rec_geom.py`，按日志弧长参数化，航向偏差 = atan(dE/ds) 与速度无关）：

- 一个事件（episode）在决策时刻 t0：目标侧偏 e0、航向偏 ψ0。
- 驶入段：t0 − 2 s … t0，三次 Hermite 从 (0, 0) 到 (e0, tan ψ0)（2 s 的历史 = 从日志上慢慢偏出去）。
- 驶回段（只是让车回到日志，好接下一个事件）：t0 … t0 + 2 s，Hermite 回到 (0, 0)。
- **标签**（每一行，含驶入段里的行）：从该行时刻驾驶参考的状态 (E(t), E'(t)) 出发，Hermite 在 2 s（人的弧长）内并回人的路径；第 j 个标签点 = 人在
  t + 0.5 (j + 1) s 的位姿沿其左法向平移 E_lab、航向 + atan(E_lab')，所以每个标签时刻的弧长就是人的（速度 = 人的）。坐标系 = 该行的锚点（和 log_fut 同一套
  rig_n + 2π 支路规则）。E ≡ 0 时标签与 on1_PAIH 的 log_fut 逐位相同（x + 0.0 = x）。

扰动取值：类型 lat / head / both 等概率；|e0| ∈ {0.5, 1.0, 1.5} m，|ψ0| ∈ {3, 6, 10}°，符号随机（both 两个符号独立）。拒绝（重抽，最多 30 次，再不行该事件作废）：

1. 附加侧向加速度 v² |E''|（日志速度，驶入 + 驶回，0.1 s 网格）> 3 m/s²（高速时只剩小扰动，是设计，按速度分段报告）；
2. t0 时扰动后的自车脚印（Pacifica 角点，同 road_pai）出 road_pai 可行驶栅格（对应 on1_PAIH 行的栅格，min SDF < 0）；
3. t0 … t0 + 2 s（0.5 s 步）扰动后的自车框与任一他车框重叠（他车是日志回放，不反应）。

## 采样（状态从哪来）

- 场景：on1_PAIH 的 851 个训练场景去掉训练器留出的（crc32 % 100 < 15），约 723 个；只用 pai-rows（train），不碰 test281 / val160 / 第二批。
- 候选 t0：k0 ≥ 37（驶入段从 k 17 开始，避开运行时 1.7 s 的强制日志窗口），k0 − 4 … k0 + 4 都在 on1_PAIH 里，日志速度在 t0 − 2 … t0 + 2 s 全程 ≥ 2 m/s，
  对应行的道路栅格 ok_primary。
- 分层：按人 4 s 标签的航向变化分 turn（≥ 30°）/ curve（8–30°）/ straight；候选按「1 / 该类在 PAIH 在动行中的份额」加权随机排序，贪心选，同一 rollout
  内事件间隔 ≥ 43 个决策（驶入 2 s + 驶回 2 s + 0.3 s）。
- 两遍 rollout：A、B，各一个完整的 723 场景读；B 的 t0 离 A 的 ≥ 10 个决策（不同状态）。
- 每个事件取 k0 − 4 … k0 + 4 共 9 行（t0 前 0.4 s 到后 0.4 s；驶入末段的行标签同样是「从当前偏离状态并回」）。在 t0 之后若出现自车 at-fault 碰撞事件，
  该行之后的行丢弃；出路 / 走廊事件不丢（是扰动本身造成的）。
- 预计：每遍约 2–3 个事件 / 场景 → 两遍约 3–4 千个事件、3–3.5 万行（实际数见补记 1，在任何 rollout 之前写入）。

## 闸（先于全量；探针 = A 的前 11 个场景）

- **G1（零扰动 = on1_PAIH，逐位）**：Z 遍 = 探针 11 个场景、A 的事件但 e0 = ψ0 = 0（走同一段偏移代码）。行文件（frames、slot、ego_in、P / V / acc、cmd、anchor、
  poses_model、log_fut、日志）与 on1_PAIH 的 H 行文件逐位相同；池行（ego、标签、8 个 front token、teacher）与 on1_PAIH 同名行逐位相同。任何一项不等 → 停。
- **G2（标签在路上、加速度合理）**：A 探针行。(a) 在孪生行（同场景同 k 的 on1_PAIH 行）有栅格且人自己的标签脚印在栅格内的行里，恢复标签沿 [自车, 8 个标签点]
  0.1 s 插值的脚印 min SDF ≥ 0 的份额 ≥ 99 %；(b) 恢复标签路径（起点 = 意图位姿 + 8 点，三点曲率 × 人的速度）的最大侧向加速度 ≤ max(4 m/s², 孪生行人标签自己的值)
  的份额 ≥ 99 %。同时报告不加条件的份额和孪生行的同口径数。
  回退（登记）：(a) 不过 → 离线丢掉 d = 0 那行恢复标签出栅格的事件（不重 roll），在保留的行上重算，线不变，报告丢掉的份额。
- **G3（渲染没坏）**：(a) R1：训练器前向（池行的 token + ego）= 驱动器记录的 NTV0 计划（pp.py r1，中位 ≤ 0.02 m、超差 ≤ 10 %、错模型 ≥ 90 %，同 PAIH）；
  (b) NTV0 在扰动行上的计划对它在孪生行上的计划不退化：4 s 路程比中位 ∈ [0.8, 1.25]、世界系 4 s 终点距离中位 ≤ 3 m。描述：自车系最大差中位、
  「计划终点比自车离日志更近」的份额（NTV0 自己会不会回）。
- **G4（权重 0 恒等，逐位）**：MV-LC s0 的原命令 60 步 eager：on1_JTPH / R5LC 对 on1_JTPHREC / R6REC0（恢复行权重 0），df.py bitcmp 全等。
- 训练前冒烟：60 步，批 51 / 13 / 72，模仿行 32 + 8，组份额等于抽样文件。

G1–G3 在探针上全过才放全量（`rec.sh` 的 probe 作业写 PROBE_OK，否则 STOP，后面的 rest 作业不动）。全量池上再报一遍 G2 / G3（只报告）。

## 考试与采用规则

PAI 281 ACC + GAP（round 5 read281 路径：NTV0 的 chunk 列表、g10、FAST 1、CONC 4）→ r2.py r281（REC s0 / s1 对 R5LC 同种子、对 NTV0）+ 「NTV0 满分场景上的新零分 /
