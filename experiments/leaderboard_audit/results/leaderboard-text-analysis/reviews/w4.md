## 范围与抽样

按任务 README 的 W4 要求，复核七个榜单的官方计分代码、攻击面与第一轮 `out/findings.jsonl` 的对应关系；只静态阅读代码。`out2/w4_attack_surface.csv` 有 24 条记录（不计表头）。固定 `seed=20260924`，用 `random.Random(seed).sample(range(24), max(10, ceil(0.1*24)))` 抽得记录下标 `[0,21,17,20,4,22,1,13,8,5]`，对应 CSV 物理行 `[2,23,19,22,6,24,3,15,10,7]`。表中 `AS-xx` 是本次复核用的记录序号，CSV 本身没有 ID 字段。
