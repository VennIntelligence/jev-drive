# P1 ReCogDrive 投影伪影对照 预登记（2026-10-23，变体 sweep 之前写）

决定行：PD6（research/paper/decisions.md）。原读数：[results/p0_subjects/p1_recogdrive/p1_readout.md](../results/p0_subjects/p1_recogdrive/p1_readout.md)，
k95 = 512、k99 = 1024（共 1536 维）。

## 要排除的假设

「k95 = 512 是投影伪影，不是真用量」：LM 隐状态各向异性（巨激活维、尺度极不均），丢掉的方向一变，向量的范数 / 分布就离开规划头的
输入分布，计划坏掉，即使丢掉的信息无关。

## 先查清的事实（代码，不是结果）

- 原实现 `usage_probe._Basis.project` = `mu + (x - mu) U_k U_k^T`：**丢掉的方向已经停在拟合均值上（均值填充），不是置零**。所以任务里的
  V1「均值填充」原样就是原协议；按任务的备选，V1 改成「均值填充 + 恢复范数」。为与 V2 区分，V1 恢复的是中心化部分的范数
  （`||x' - mu|| = ||x - mu||`），V2 恢复的是原始范数（`||x'|| = ||x||`）。
- 规划头读 LM 隐状态只经过一层线性 `action_head.feature_encoder = nn.Linear(1536, 384)`（DiT small，`get_action` 第一行；序列均值
  与交叉注意力都用它的输出）。所以规划头能读到的子空间秩 ≤ 384：「1536 维里要 512 维」这个说法本身受 PCA 排序与 W 行空间不对齐的影响。
  因此加 V5（规划头对齐的 PCA），任务未列，便宜。

## 臂（同 token、同两折 log 交叉拟合的 PCA、同 k 网格 8 … 1536）

每个 token 的 LM 只跑一次（缓存的隐状态），每个变体 × k 在缓存上跑 DiT；采样噪声每次按 token 重置（与原 sweep 配对）。
`x` 为一行（一个位置）的 1536 维向量，`c = x - mu`，`mu` / 协方差来自另一折。

| 臂 | 定义 |
|---|---|
| pca（原协议，复用原 sweep 的计划） | `mu + c U_k U_k^T` |
| V1 cnorm | 同上，再把 `c U_k U_k^T` 缩放到 `||c||`（逐行） |
| V2 norm | 同 pca，再把整个 `x'` 缩放到 `||x||`（逐行） |
| V3 rand | `mu + c Q_k Q_k^T`，Q = 1536 × 1536 高斯矩阵 QR（seed 0，嵌套） |
| V4 std | 按拟合的逐维标准差标准化，相关矩阵 PCA，投影，再反标准化 |
| V5 wpca | `V_k` = `W Cov W^T` 的前 k 个特征向量（W = 读入层 384 × 1536）；`x'` = 由 k 个坐标 `V_k^T W c` 对 x 的最小二乘（高斯条件均值）重建，`W x' = W mu + V_k V_k^T W c`；k ≤ rank = 384 |

另记（不跑规划头）：每个变体每个 k 的留出解释方差（输入空间、读入空间 `W(x - x')`）与平均范数比 `||x'|| / ||x||`，原 pca 臂也算。

## 恒等闸（不过就停）

24 个 token：G1 钩子关 == 无钩子，G4 两次无钩子相同，G3 / G5 sweep 的 off 臂 == 无钩子且可重复（都逐位），
P0 `Projector('pca')` 与原 `_Basis.project` 逐位相同；R 各变体满秩臂（V1–V4 k = 1536，V5 k = 384）对无钩子的计划平均 |xy| ≤ 0.01 m。
全量：变体 run 的 off 臂必须与原 sweep 的 off 计划逐位相同（vmerge 检查），否则不读。

## 读数与判定线（现在定死）

- 每个变体每个 k：EPDMS（v2）与 v1.1 PDMS，对 off 的配对差，按 log 聚类 bootstrap（B 10 000，seed 0）；k95 / k99 定义同原预登记
  （点估计：retained ≥ q；CI 版：差的 CI 下界 ≥ -(1 - q) × off，CI 版为标题）。
- **主判定（V1、V2）**：min(V1, V2) 的 CI 版 EPDMS k95 ≤ 64 → 原读数是投影伪影；两者都 ≥ 256 → 不是伪影，ReCogDrive 的规划头确实读一个大子空间；
  其间（128）→ 部分是伪影，照实写。
- V4：k95 ≤ 64 → 是各向异性（尺度）造成的排序伪影。
- V3：随机子空间 k95 与 pca 相差 ≤ 一档 → PCA 排序不重要（信息在各方向上铺开）；明显更大 → 排序有用。
- V5：规划头对齐后的 k95，即「规划头在它看得见的 384 维里读多少维」；若 ≤ 64，论文改用这个数（相对 384）而不是 512 / 1536。
- 描述：原 pca 臂在 k512 的范数比；若接近 1，范数漂移本就不大。

## 成本

闸（10-23 07:27，通过，`variants/gate.json`）：无钩子 0.55 s / token，缓存臂 0.06 s / 臂（每 token 的输入读取与 InternVL 切图只做一次，只是 harness 级缓存，闸逐位复查）；44 个变体臂 + off ≈ 3.2 s / token 加装载开销，全 navtest 约 10–25 卡时（6 片，约 2–4 h 墙钟）；读出 CPU（46 + 9 个臂的 v2 打分与 v1.1 PDMS）。LM 隐状态原 sweep 没存（只存了汇聚特征），所以每个 token 重跑 LM 一次；不存隐状态（全量约 75 GB）。
池作业：sweep 每卡一片（VRAM 申报 45 GB，避免两片同卡），与 WA-JEPA、DriveVLA-W0 探针共用卡；只存分数。

(i) 投影后范数离开 RMSNorm 后的分布，或 (ii) 32 层同时投影的误差逐层叠加，而不是动作专家真读满维。

  min(类大小, 200))，其余类按比例缩放到总数 3 000，rng 0；`scripts/p1_w0ctl_split.py`）。每类：直行 1240、左转 409、弯道 359、
  起步 347、右转 238、变道 200、停车 200、静止 7。子集上的 EPDMS 不是 navtest 均值（分层加权），只读配对差。
- 臂（同 2 折 log 交叉拟合 PCA，复用原 PCA 文件，同每 token 种子噪声，与原 sweep 配对）：
  `ctl-off`（本次 sweep 的 off，查与原 off 逐位相同）；`norm-k64 / k512 / k2048`：32 层全投影 + V2 式范数恢复（逐行 `||x'|| = ||x||`）；
  `L16-k64 / k512`、`L31-k64 / k512`：只投影第 16 层或最后一层（31），原投影，其余层不动。对照的原臂 `k64 / k512 / k2048`（32 层，
  原投影）复用原 sweep 的计划，在同一子集上重新打分。
- 恒等闸（子集前 24 个样本，原闸同规则）：G4 两次无钩子逐位相同；G5 sweep off 两次逐位相同；G3 sweep off 对无钩子平均 |xy| ≤ 0.01 m；
  R 满秩臂（norm-k4096、L16-k4096、L31-k4096）对 sweep off 平均 |xy| ≤ 0.01 m。不过就停。
- 读数：每臂 EPDMS（v2）与 v1.1 PDMS 对原 `off` 的配对差（log 聚类 bootstrap，B 10 000，seed 0）；对照臂与同 k 原臂的配对差
  也报（同脚本另跑一次 ref = 原臂）。

  ReCogDrive 判定线不变（上文）。
