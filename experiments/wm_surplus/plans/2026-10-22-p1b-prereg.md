# P1 level (b) pre-registration: drop deep encoder blocks / prune context tokens (WA-JEPA, 2026-10-22, before any (b) GPU job)

Runs only if level (a) finishes cleanly (identity gate passed, arm `off` within 0.3 of 91.71). Same subject, inference path,
scoring and statistics as level (a) ([2026-10-22-p1-usage-prereg.md](2026-10-22-p1-usage-prereg.md)); reference = level (a)'s
`off` plans (`PROBE-wajepa-ctx-off`); level (b)'s own `off` arm must be bit-identical to it (checked at merge, else stop).
Code: `scripts/p1_wajepa_b.py`.

## Arms

- `drop2`, `drop6`, `drop12`: skip the last 2 / 6 / 12 of the 24 V-JEPA 2.1 ViT-L encoder blocks (the block returns its input).
  The planner's projector reads the concatenation of the normalised outputs of blocks 5 / 11 / 17 / 23 (4 x 1024 = 4096-d per
  token), so a dropped deep block's slot carries the stream of the last kept block through that slot's norm. drop12 leaves
  only blocks 0-11 (half the encoder compute).
- `keep2`, `keep4`, `keep8`: keep 1/2, 1/4, 1/8 of the 16 x 32 patch positions of every view and tubelet (2-D strides
  (1, 2), (2, 2), (2, 4)); the context tokens and their position indices are pruned together, so the planner attends over
  2048 / 1024 / 512 instead of 4096 context tokens with correct positions.

## Read-out lines (fixed now)

- Per arm: EPDMS and sub-scores, paired difference vs `off` [95 % CI, cluster bootstrap over logs].
- "Not needed" for a component = CI lower bound of the difference >= -0.05 x EPDMS(off) (keeps 95 %); "needed" = CI upper bound
  < -0.05 x EPDMS(off). Otherwise "unclear".
- C2 reading: if drop12 keeps 95 %, half the grafted encoder's depth is not needed by the driving head at inference; if keep8
  keeps 95 %, seven eighths of the spatial tokens are not needed. Neither result says the components were not needed in
  training (Fast-WAM objection; paper section 3.2).

## Caveats fixed in advance

- Dropping blocks shifts the input distribution of the projector (the deep slots see shallow features through deep norms):
  a large drop says "the planner depends on what these blocks compute", not "the information is absent in shallow layers".
- Strided pruning keeps a uniform grid; it measures spatial redundancy, not which tokens matter (that is level (c)).
