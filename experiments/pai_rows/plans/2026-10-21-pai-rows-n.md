# PAI-ROWS-N 预登记：第二批 64 个 NuRec 场景的人类状态行（2026-10-21，写于任何输出之前；无训练）

## 做什么

`results/download_queue_v2.csv` 的 64 个场景（2026-10-21 02:51 下完，盒上 `all-usdzs`，大小逐个与清单一致；stop_nolead 29、turn_sharp 29、launch 6，共 111.15 GB）
按 PAIH 的建法原样建人类状态行与两个拉伸变体，建成**新池**，再零拷贝合并到旧池后面。不改旧池、不改 `scenes.tsv`（`pai-rows@v1` 的 853 个不动）。

- 场景表 `results/scenes_n.tsv`（`pr.py scenes-n`；列同 scenes.tsv，`half` = N，另有 t281 / t281_gap_s / t281_why）。64 个都在 curated-train，与 curated-val、test281、
  pai-rows@v1、pai_fix 的 exam_scenes / train_exclude / drives_val160 不相交。登记 `physical_ai_av/pai-rows-n@v1`（64）和 `physical_ai_av/pai-rows-x@v1`（853 + 64）。
- **t281 标签**：这 64 个全部与一个 PAI test281 场景同驾驶（pav.py 的规则：pose_record 纪元或日志会话时钟 600 s 内，且起点距离在该时间内可达）。
  `pr.py partner`（盒上 CPU 作业）重算每个场景的 test281 伙伴与时钟差（下载清单只有到「某个考题」的 exam_gap_s，没有场景号）：64 / 64 有伙伴，差 144–591 s，
  中位 391 s，与清单的 exam_gap_s 逐个一致，且没有 val160 伙伴。结果 `results/n_t281_partner.tsv`。
- 每行字段 `t281`（U8，伙伴 test281 场景 id 去掉 `clipgt-` 后的前 8 位）写进新池的 tab.npz（`pr.py tag`，在 rf_pai_pool 之后；拉伸池从明文池继承）；合并池里旧行为 ""。
  场景级旁表 = `scenes_n.tsv` / `n_t281_partner.tsv`（含完整伙伴 id 与时钟差）。**用途**：这些行不是考题泄漏，但与考题同驾驶；训练臂可按 t281 把它们单列或剔除。

## 建法（`pr.sh chain N`，pass N = H 的配方）

- 与 H 逐项相同：渲染（NTV0-L18-s0 照 A0 serve 喂入并记录，`onp_log_driver.py`，send_recording_ground_truth，CONC 4，ALPASIM_FAST=1）→ `onp_rows` → `onp_cache build`
  （冻结 Cinque 编码；按场景编码，批组合只取决于该场景的行文件，所以与 853 个的建法同序）→ `rf_pai_pool --fut log_fut --prefix paihn --src human` → 池 `on1_PAIHN`；
  `pr.py stretch` f = 0.5 / 1.5（补记 2 的膨胀标签）→ `on1_PAIHN05` / `on1_PAIHN15`。
- 分阶段同 H：1 个场景 → 检查 → 10 个 → 检查 → probe（这 11 个场景整条尾巴，池 `on1_PAIHNT*`，R1 与 f = 1 位等）→ 其余（32 一个 chunk）。池优先级 6（第 5 轮 20 不被延迟）。
- 闸：同 H。R1（训练器前向）：中位 ≤ 0.02 m、超出的行 ≤ 10 %、错模型 ≥ 90 %、无缺行；f = 1 位等（ego、fut、8 个 token、teacher 逐位）。H 只在 probe 上判 f = 1；这里
  **另外在全量新池上判一次**（`on1_PAIHN10` = f 1.0 的拉伸，留作证据）。
- 合并（`pr.sh merge`，`rf_pait.py merge` 零拷贝，不复制 token）：`on1_PAIHX` = PAIH + PAIHN，`PAIHX05` = PAIH05 + PAIHN05，`PAIHX15` = PAIH15 + PAIHN15（前缀 ph / phn 等）；
  `on1_JTPHX` = JTPH 的各部分（同 r2.sh）+ PAIH* + PAIHN*，`--nan-keys fut_reg`。检查：合并池的前缀行与被接的池逐文件逐键相等（tab、agent / road / route、feat、teacher、4000 行 token 抽样）；
  JTPHX 的 agent ok 前缀照 JTPH、新人类行（phn*）为 False（与 r2.py fix 对 ph* 的处理一致）。不覆盖已存在的池。
