## 3. D0 闭环读（步骤 4）

**臂**：RSG-L18-s0，PAI 提交配置（`controller.gains.rel_front_steering_angle_weight=10`，`JEV_VCONT=1.0 JEV_LEAD=1 JEV_ACC=1`，v8 gate，决策 327 / 328），加
`JEV_DESIRE=1 JEV_DESIRE_VMIN=<第 2 节的闸>`：每个推理决策 `RouteDesire.step(t0, v, 喂入的路线记忆)`，desire 队列写入 `_to_copy`（`PModel.forward(desire=)`）；
`drive.jsonl` 每决策记 `desire`（state / side / t_on / why / y_t / y_0 / intent）。`JEV_DESIRE` 不设 = 今天的路径逐位不变（第 4 节闸）。

**场景与参照**：
- **PAI 281 全集**（`CHUNKS_FROM=$DATA_DIR/runs/route_follow/pai_g10/acc/chunks`，与参照同 8 个 chunk 表），配对已存参照 `pai_g10/acc`（RSG-L18-s0 同配置）。
  同代码、不开 desire 重跑 chunk c000（`acc_re`）作恒等检查：分数与已存参照逐场景相同（ACC-GAP 的同表重跑是 37 / 37）；不同 → 所有 chunk 都重跑参照，用重跑的配对。
  主读子集：`dd.py scenes` 的 pai281 表（155 个场景：地图变道点 31 ∪ 规则在参照日志里起过 149）。其余场景只进安全线。
- **PAI train160 规则场景**（`d0/lists/pai160.txt`，46 个：on1_PAIonp 里规则起过的场景，含 d332 P_lca 的 15 个），没有已存 ACC 参照：同表跑 D0 与参照（不开 desire）两臂。
- **nuPlan held @18**（`d0/lists/held.txt`，116 个：held 地图变道点 26 ∪ 已存 held 日志规则起过 98），同代码跑参照与 D0 两臂（nuPlan 读数不逐位可重放，第 329 条补记 1），只报 + 描述性线。

**读数**（`dd.py d0report`，每个场景两边都有分才进）：
- **M1 地图变道点完成**（第 299 条补记 3 的 lc_map 规则：路线在 s 处离开所在车道进相邻车道，gap ≤ 6 m）：到达 / 横移 ≥ 2 m / 之后在路线车道（s + 30…60 内 |lat| ≤ 1.75）/
  stayed；**完成 = 横移 ≥ 2 m 且之后在路线车道**。PAI 281 与 train160 合并计数，左右分开；validated（人的日志自己移 2–6 m）另报。
- **M2 规则层完成**：D0 臂每次起变道（`desire` 日志的上升沿）的结局：done（剩余偏移 < 0.5 m）/ 超时 / 中止；参照臂同一规则离线跑在它自己记录的路线记忆上（同 v_min，不喂）得同样的结局。
  done 份额差 [场景 bootstrap CI]；按 |y_0| < 1 m 且非缺口（**路线前方变道**，主）与其余（回到路线车道 / 缺口）分开，左右分开。
- **M3 安全**：侧面接触（metrics `collision_lateral` 为真的场景数）、at-fault 碰撞零分、零分、corridor 零分、offroad 零分、被追尾；均分差 [场景配对 bootstrap，B 10 000，seed 0]；
  新增 / 修好的零分逐个列出。

**线**（PAI；held 只描述）：
1. **能带出变道**：M1 完成数 D0 − 参照 ≥ +3（PAI 两集合并、gap ≤ 6 的点）**且** M2 路线前方变道 done 份额差 CI 下界 > 0 → 「能带」；两条只成立一条 → 「部分」；都不成立 → 「不能带」。
2. **安全**（PAI 281 全集）：侧面接触 ≤ 参照 + 2、at-fault 碰撞零分 ≤ 参照 + 1、零分 ≤ 参照 + 2、corridor 零分 ≤ 参照 + 1、均分差 CI 下界 > −0.02；任一不成立 →「有代价」。
3. **停**：「不能带」，或「有代价」且不是「能带」→ 这条线停（不做 D0 变体），报负结果。
4. 左右：M1 / M2 左右分开报；若右边「能带」而左边完成数 0 → 「左边要 D2」。

**对 D1 / D2 的含义**（结论里一句话）：训练行用的速度闸 = 第 2 节的闸；左边是否必须靠 D2。
