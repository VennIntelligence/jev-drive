# op_wide_ft 预登记：wide 槽加宽到 116° 后微调，openpilot 会不会用宽视野在急弯 / 直角弯上转够（2026-10-05，写于任何训练与读数之前）

## 问题
从 shipped Cinque 出发，按 op_route_ft 的配方（rc-bear + 第 130 条更正的 action 目标）微调，wide 槽在同一 512×256 张量里改用更小的焦距
（wide f 455 → 160，HFOV 58.7° → 116°，地平线行 151.8 不动；road 相机不变，第 135 条：改 road 焦距破坏尺度）。
训练后，模型会不会**用**宽视野在 B2D 急弯 / 90° 弯上转够（shipped 只给所需曲率的 0.3 倍，第 127 条）？

已知：第 135 条 zero-shot W116 无害但不被使用（冻结 wide 画面几乎不改转向）；第 136 条 Alpamayo 一路 120° 前视 + nav 就够转，cross 相机不加分。
所以唯一没测的是「训过之后用不用」。

## 设计：只差 wide 视场的成对两臂

| 臂 | CARLA 行的 wide 帧 | 其余 |
|:--|:--|:--|
| **W58** | f 455（58.7°，出货） | rc-bear-fix 配方：行构成、目标、损失、超参、4000 步、seed 0、bear 路线 adapter |
| **W116** | f 160（116.0°） | 与 W58 完全相同：同一批次抽样（同 seed → 同行）、同一目标（教师输出取 58.7° 输入下的原模型，两臂共用） |
| W116-ctl（可选） | f 160 | 无路线（zero_cmd），闸门过且卡空闲时才训，只报告 |

- **数据**：CARLA 出口配对（op_route_cmd 的 8 607 个位姿 / 21 151 行，1 310 个路口，不含 B2D 的 172 个）在对齐视角（1.59 m 前、1.86 m 高，
  B2D `spec`）**重渲一次**：同一个 1928×1208、f 567（118.9°）的 wide 传感器同时切出 f 455 与 f 160 两份 wide 帧，road 帧共用。两臂的 CARLA
  图像来自同一次渲染、同一帧，像素上只差 wide 的裁法。116° 而不是 120°：f 160 时 model 帧四角仍在 CARLA wide 传感器内（u ≤ 907 < 964、
  v ≤ 538 < 604，不钳边），也是 comma 广角传感器的全宽（第 135 条 W116）；120°（f 148）会钳边。
- **真实行**（navtrain / WOD，P / N / D 行）与 layer-3 CARLA H 池（Dhc）两臂都保持 58.7°：这些相机竖直只有 ±17–20°，116° 的 wide 帧上方约 30%
  是黑的（第 135 条）。所以 W116 是**混合视场训练**（CARLA 位姿行 116°，其余 58.7°），视场不告诉模型（由画面本身可辨）。
  这同时回答板级问题：没有宽覆盖的榜（NAVSIM、WOD）照常喂 58.7°，W116 在训练里见过 58.7°，相当于对 wide 槽做了视场 dropout；
  护栏里测它在 58.7° 输入上是否掉。
- 教师：两臂 CARLA 行的 distill / 一致性 / 负样本 / 计时目标都取原模型在 **58.7°** 输入上的输出（`bank/w58`），W116 臂只换 trunk（输入像素）。
  于是「同行、同目标、同 seed」，单变量是 CARLA 行的 wide 视场。
- 不加：近距离 / 低速入弯样本（第 134 条）、desire（第 92、121 条，闭环关 desire）、comma1M / PhysicalAI 训练行（v1 不加，只做读数；记为限定）。
- 执行层：action 曲率 + op-path（第 133 条）。

## 小步与闸门

0. **代码 pilot**（W116 400 步）：损失比第 100 步低；CARLA dev 出口走对 ≥ shipped + 0.10；无指令漂移中位 ≤ 0.15 m。任一不过先查原因。
1. **全量训练**两臂（4000 步，每臂约 11 min，不是长任务），开环 2×2（模型 × 输入视场）CARLA dev 读数。
2. **闭环小集**（op_route_ft 的 9 个转弯 / 8 条路线，`near_lane.SMALL`）：W58@58、W116@116。
3. **闸门**（判定在读数前写死）。过（放 25 转弯 + 次读数 + 护栏）当且仅当下列任一成立：
   (a) 小集走对 W116 ≥ W58 + 2；
   (b) 进入的转弯里入弯位置（`rft_split` tin_m，到 0.5 / R_min 时车相对转弯起点的弧长）中位 W116 比 W58 早 ≥ 2 m，或 s_peak / need 中位高 ≥ 0.3；
   (c) 开环：CARLA dev 出口走对 W116@116 − W58@58 ≥ +0.05 且 CI 下界 > 0，并且 W116@116 − W116@58 ≥ +0.03（模型确实读宽画面）。
   **明确负（停）**：(a)(b)(c) 都不成立。停时只报告小集与开环，不跑 25 转弯，结论写「训练后仍不用 / 用了也不转」。
4. 过闸门后：B2D 25 转弯 × {W58@58, W116@116, W116@58}；comma1M、PhysicalAI 读数；护栏；GIF（一个 B2D 急弯，第三人称 + 两臂真实的
   road / wide 输入帧）。

## 判定（25 转弯，事先写死）
- **宽视野帮转弯**：took 差 ≥ +0.12（25 个里 ≥ 3 个）且 CI 下界 > 0；或 forced 曲率比差 ≥ +0.2 且 CI 下界 > 0；同时 W116@116 − W116@58 同号
  （效应来自测试时的宽画面），护栏全过。
- **训练帮、视野不帮**：W116@58 与 W116@116 相当（差的 CI 含 0），且都高于 W58。
- **无效应**：took 差 CI 含 0 且曲率比差 < +0.1。
- 护栏线：直路车道宽比 ∈ [0.93, 1.07]、plan 速度比 ∈ [0.95, 1.05]、ADE 比 ≤ 1.20（对 shipped，同第 135 条）；负样本偏移不比 W58 差 0.05 m 以上；
  早转子集 ≥ W58 − 0.3；CARLA dev 无指令漂移中位 ≤ 0.10 m。
