## 3. 标签（`lib/lc.py`，每行 = 状态 × query；1 正、0 负、-1 无标签）

共用的几何（`scripts/lc_ctx.py`）：token 的**后见路线** = 日志 ego 之后 30 s（60 帧）实际开过的路径 + 沿最后航向直行 30 m，1 m 网格到 130 m，
在 token 的日志后轴坐标系里；`vlog` / `tlog` = 日志 ego 第一次到达该弧长时的速度 / 时间。停止线 = 地图 `STOP_LINE` 层被路线穿过的 type 1（stop sign）
与 type 2（红绿灯停止线）多边形，`d` = 路线第一次进入多边形的后轴弧长，只留前保险杠之前（d > 4.05 − 0.5 m）且 ≤ 130 m 的最近 4 条；红绿灯线的
connector 与灯态取法照搬 `lowboard_diag/scripts/stoplbl_label.py`（第 238 条），灯态 = 日志 `traffic_lights` 在 t0 + 0.5 k（k = 0..8）的
(connector, is_red)。转弯 = 路线航向的曲率段（|κ| > 0.025 /m，间隔 ≤ 5 m 合并，stoplbl 的规则，边缘填充平滑），取第一个转角 ≥ 45° 且峰值在前方的段，
峰值 = 段内 |κ| 最大处。扫掠用 body1 的 `sweep.py`（ego 框 0.1 s 一步，日志框在对应时刻，含运动）。

**A：开到本车道前方的车上。**
- 合格对象（按 token，与 query 无关）：车辆（class 0），t0 有效，中心到后见路线的横向距离 ≤ 1.5 m 且在路线已知部分，最近点在 ego 车头之前，
  航向与该处路线航向差 < 45° 或速度 < 0.5 m/s。
- 正：该行自己的扫掠在 t > 0 接触某个合格对象，**并且**把同一条弧长-时间曲线放到后见路线上走（反事实「这条速度剖面沿车道开」）也接触同一个对象。
  子类：被撞对象在接触时速度 < 0.5 m/s 为 A1（静止），否则 A2（行驶）。
- 负：该行没有任何计数的 agent 接触（S0 的 `a_hit` 为假；只被后方更快的对象追尾的行按 S0 读数的惯例算负，在 A 的损失里照常加权）。
- 无标签：其余有 agent 接触的行（横向 / 绕行 / 漂移 / 切入 / 横穿 / 行人等，以及只有路径造成的与合格对象的接触）、t = 0 已接触、query 无效、
  token 没有路线。

**B：在必须停的时候越过停止点。**
- 合格停止线：stop sign 线——日志司机在 t0 之后、越线之前停下（后轴在 [d − 15, d − 4.05 + 1.5] m、速度 < 1 m/s，时间 > 0.5 s，
  即还没停过）；红绿灯线——connector 匹配上（< 3 m）、窗口内至少一个灯态已知、日志司机**不是**在红灯时越线，并且日志司机在线前停下、
  或在已知非红时越线、或 30 s 内没到线（在等）。
- 越线：该行前保险杠中心投影到路线上的弧长 ≥ d 且横向距离 ≤ 3.5 m 的第一个 0.1 s 步 t_c。
- 正：越过某条合格线且此时必须停——红绿灯：t_c 最近的关键帧灯态为红；stop sign：越线前该行的速度没有降到 0.5 m/s 以下。子类：红灯 / stop sign。
- 负：4 s 内没有越过任何合格线（包括没有合格线的状态），或越线时不需要停（绿灯、停过之后过 stop sign）。
- 无标签：越过红绿灯线时灯态未知（且没有别的违规）；4 s 时前保险杠已超出路线已知长度而又没有违规（负不成立）；query 无效。

**C：以高于日志司机的速度进入 > 45° 的弯。**
- 合格弯：存在 ≥ 45° 的路线弯，日志司机过峰值的速度 v_log ≥ 1.0 m/s（不是弯里停车让行）。
- 到达峰值：该行后轴投影到路线上的弧长 ≥ 峰值弧长、横向 ≤ 3.5 m 的第一个 0.1 s 步，且此时该行航向与路线在峰值处的航向差 ≤ 30°
  （在这个弯里，不是走了另一个出口）。
- 正：4 s 内到达合格弯的峰值，速度 v ≥ v_log + 1.5 m/s 且 v ≥ 1.25 v_log。
- 负：4 s 内没到峰值（包括没有弯），或到达时 v ≤ v_log + 0.5 m/s。
- 无标签：到达时速度差在 (0.5, 1.5) m/s 之间（带宽，同 S0 出界标签的 [−0.20, 0) 带），到达不合格弯（日志司机在弯里停）或到达时航向差 > 30°，query 无效。

**看图后的两处修改**（第一张图，标签计数与定义都在任何模型输出之前）：(1) 红绿灯线原来只要求「日志司机不在红灯越线」，图里一条线日志越线时灯态未知、
司机没停，可能是另一个方向的红灯或日志司机自己闯了，加上「在线前停下 / 已知非红越线 / 没到线」；(2) C 原来不看航向，图里一条 plan 从弯的峰值附近
开向另一个出口，加上 30° 航向条件。第二张图（另一组随机正例）没有再发现问题。

## 4. 输入阶梯（`lib/lc_head.py`，累加）

1. **blind**：ego 向量（20 维，含 command）+ query 位姿。S0 的 `blind` 结构（下限）。
2. **vis**：+ 8 个 policy slot 的冻结 Cinque `view_39` token（8 × 32 × 512，fp16，warp 帧）。S0 的 `step` 结构，即 S0 的输入。
3. **nat**：+ openpilot 原生输出，来自**生成这个 query 的那个学生**的同一次前向（`scripts/lc_native.py`，P2H10-F-s0 / -s1）：
   `lead`（144：3 个假设 × 6 个时刻 × (x, y, v, a) 的均值与 log std）、`lead_prob`（3）、`meta`（55）、`action`（4），以及 policy 的时序摘要
   `select_4`（512）与 `mean`（512）（第 203 条的 H，缓存便宜所以保留）。经两个 MLP 嵌入后加到该 query 的 9 个 step token 上；
   own0 与建在 own0 上的扰动用 s0 的输出，own1 同理；ship / log 两个 query 用一个学到的 null 向量。这些都是 driver 本来就算出来的，非特权。
4. **priv**（oracle，只作上限）：+ 特权 memory token：32 个日志 agent 框在 0..4 s 的轨迹（含类别、A 合格标记、t0 速度）、后见路线（每 4 m 到 120 m，
   带日志速度 / 到达时间）、4 条停止线（类型、弧长、合格标记、9 个关键帧灯态、日志司机停车 / 越线时间与越线灯态）、第一个 ≥ 45° 弯（起止与峰值弧长、
   曲率、角度、日志峰值 / 入弯速度）。全部换到状态自己的坐标系。等于把标签的原料直接给头。
5. **blind_nat**（描述性，不进判词）：blind + rung 3 的原生输出，不带视觉 token。回答「原生输出单独够不够」。

## 5. 训练（`scripts/lc_train.py`，S0 的配方，只多三项）

- 每个 rung 一个头同时出 S0 的 7 个输出与 A、B、C 三个 logit；S0 的全部损失项不变（agent / 出界 BCE、`w4` 权重、净空 / 余量 / 首次接触回归、
  逐步目标），加 λ_long = 1 × (A + B + C 的 BCE)。
- 纵向标签的权重按 S0 的 `w4` 风格：4 个用户类 × {正, 负} 的格子在有标签的 fit 行上等质量；格子行数少于 100 的按 100 计（防止个位数正例的格子
  拿到极端权重，S0 没有这么稀的格子）。状态按 (四套权重在该状态 24 个 query 上之和)^0.5 抽样，其余权重进损失（S0 的做法）。
- 12 000 步，batch 256 个状态 × 24 query，AdamW 3e-4，bf16，30% 行做 slot dropout（只留最新 k 个 slot）；每 500 步在验证 log 上读一次。
- 模型选择（只用验证 log）：`lat` 组按 S0 的规则（own plan agent 与出界 AUC 的均值）；A、B、C 各自取 own + arc 行（槽 0、1、16–19）上该标签 AUC
  最高的步（验证集 own plan 的 B / C 正例只在 5–10 个 log，单用 own 选步太吵）。checkpoint 存四组权重，每个标签用自己那组读。
- 每个 rung 两个 seed（0、1），共 5 × 2 = 10 个全量训练。

## 6. 登记读数与判线（每类、hold logs、最好的非特权 rung）

- **判词人群 P1** = hold 状态上 own plan 与它的 arc 重定时行（槽 0、1、16–19），三族状态合并。理由（读任何 AUC 之前决定）：own plan 单独在 hold 上的
  正例只在 6–9 个 log（A 的 85 个里 74 个在 3 个 log），按 log 聚类的区间会由两三个 log 决定；arc 行就是 own plan 的路径换速度，正是纵向的反事实，
  正例 361–1 820 个、24–73 个 log。S0 的 G1 报过同一族 arc query 的 agent AUC（0.918），所以横向的对照在同一人群上也有（第 7 节重算）。
- **人群 P0** = 只有 own plan（槽 0、1），与 S0 G1 完全同人群，用同一条判线**照样判一次并报出**，标注正例 log 数；两者不一致时两个都写，
  登记判词按 P1。
- 分数 = 两个 seed 的 logit 平均（S0 闸门的惯例）；每个 seed 单独也报。AUC 平局算一半；区间 = 按 log 的百分位 cluster bootstrap，10 000 次，seed 0
  （`contact_head.auc_boot` 的抽样）；增益 = 同一组抽样上两个分数的 AUC 差（配对）。
- 「最好的非特权 rung」= blind / vis / nat 中 P1 上两 seed 平均 AUC 最高者（blind_nat 是描述性的，不参与）；增益 = 它减 blind。
- **READABLE**：AUC ≥ 0.80 且下界 > 0.70，**并且**增益 ≥ +0.05 且配对 CI 不含 0。含义：纵向这一课是标签问题，可以放进联合 policy 训练。
- **NOT READABLE**：AUC < 0.70，或增益 < +0.02。含义：感知不够，这一后果是 capability 阶段的目标。
- **PARTIAL**：其余。报出是哪一级在起作用（vis 对 blind、nat 对 vis 的配对差）、哪个速度段、哪个子类。
- 边界情形照字面判：最好的就是 blind 时增益为 0，按「增益 < +0.02」记 NOT READABLE，另注明 blind 自己的 AUC（若 ≥ 0.80，说明这一后果从 ego + plan
  就读得出，不需要感知）。

## 7. 正对照（同一代码路径、同一划分）

1. S0 的三个 checkpoint（step seed 0 / 1、blind seed 0）用本线的读数代码重读 own plan agent / 出界：必须**逐位复现** `s0_gate.md` 的 0.905 [0.868, 0.934]
   与 0.978 [0.969, 0.985]（以及 blind 0.770 / 0.779）。不复现 = 读数管线有错，停下修。
2. 阶梯头自己的 `lat` 输出在 P0、P1 上的 agent 与出界 AUC（四个 rung + blind_nat，两 seed 平均与逐 seed）：多任务训练后横向读数还在 S0 附近，
   说明这条管线能读出已知可读的后果。
3. **横向按类拆开**：S0 两 seed 平均的 agent logit，正例按接触类型分成「A 类（本车道前方的车）」「其他车辆接触（横向 / 绕行 / 漂移 / 切入 / 横穿）」
   「其他对象（行人、自行车、一般物体）」，负例都是无接触行，在 P0 和 P1 上各读一次（2 000 次 bootstrap）；vis / nat 阶梯头的 `lat` 输出同样拆。
   这样 A 有一个「同一组负例上的横向兄弟」可比。

## 9. Pilot（任何 hold 读数之前）

rung vis 与 rung priv，seed 0，只用 shards s2–s4，6 000 步，读**验证 log**（`lc_read.py pilot`，不碰 hold）。清单：
(1) 两个都跑完、损失有限；(2) vis 的 own plan 横向验证 AUC agent ≥ 0.80、出界 ≥ 0.90（S0 同规模 pilot 0.857 / 0.936）；
(3) priv 的 A、B、C 验证 AUC（own + arc）都 ≥ 0.90（标签能从它自己的原料学出来，标签与输入一致）；(4) 每类验证正例 > 0。
(1)(2)(4) 不过 = 管线错，修了再跑。(3) 某类不过 = 那一类的标签或原料有问题：查、修，修法作为补记写进本文件后再全量；1 小时内找不到原因，该类记为
「标签不能从它自己的原料学出来」，hold 读数照报但不下判词。vis 上纵向 AUC 低（例如 0.6）**不是**停止条件：明确为负的 pilot 照样跑全量。
