## 1. 问题

第 456 条（NTV0NS）把 S 行整个拿掉，PAI 281 掉 0.12。但 S 行在 NTV0 配方里同时带两样东西（research/method-search/notes.md 第 6 条的漏洞）：
(a) 在模型自己的 plan 上的 agent / road / 侧向 hinge（后果项）；(b) `distill_ho`：非 plan 头蒸馏到出厂教师（lam_d 30）。哪一样带来增益？
这决定论文的「身体图式 = 后果 hinge」站不站得住，也决定干净 NTV1 配方要保留什么。

## 2. 代码核对（P0 = PCL0-L18-s0 的存档 argv，盒上 `runs/route_mem/train-PCL0-L18-s0/20261023-210845/meta.json`）

P0 = NTV0-L18-s0 的 argv 只换 `--on-wfile runs/round9/pool_pilot/w/JT00S-rb0.npz`：`--on on1_JT --on-k 32 --on-mode mixed`、无 `--ho`、
`--agent-lam 10 --agent-on-only --shape --ho-w 3`、road_lam 默认 10、`--lat-onc 0.5 --lat-soft 0.1 --lat-side 0.5`（nr1_lat 作 --on-lon 模块）、
`--on-arc 0`、`--on-lon-all`。JT00S-rb0 的非零行全是 `self` 行，所以每批 32 个池行都是 `self` 行。

- 没有 `--ho`，所以 Losses43 的 hinge-only 行恰好就是这 32 个池 `self` 行（on_train.losses：`ho = is_ho | sfr`，is_ho 全假）。
- 这些行在 Losses43 的 hinge-only 路径上得到：`agent_ho` x ho_w x agent_lam（`--agent-on-only`：agent 标签只在池行上，普通行的 agent 项 A 为空）、
  `road_ho` x ho_w x road_lam、`distill_ho` x lam_d（**不乘 ho_w**）；再经 LossesOn 的 `--on-lon-all` 路径得到 nr1_lat 的 `on/lat_{onc,soft,side}_ho`
  x ho_w x on_lon_lam（1；10 W 在 nr1_lat 里），`lon_arc` 权重 0。`self` 行没有模仿项，P2H10 的 drivable hinge 只在模仿行上。
  rm_train 另外可加的 kd / awr / d2 / lane / lc 项在 P0 里全关。
- 所以 **`--ho-w` 恰好只乘 S 行的全部 hinge**（agent、road、三个侧向项），不碰 distill_ho：这是现成开关。`--ho-w 0` 下 --diag 的 grad/pool 为 0、
  cos 为 0（有限），日志里各 hinge 值照记。
- distill_ho 没有单独开关：lam_d 同时管普通行的 `distill`。新增 `on_train.py --ho-distill W`（默认 1 = 关，不加任何操作；rm_train 经
  `recipe_args` 继承，rm_train.py 不改）：在 LossesOn 里加 `(W − 1) x lam_d x distill_ho`。W = 0 时 distill_ho 收到的梯度是 30g 与 −30g 之和，
  逐位为 0（本地 torch 检查：含 65536 的 loss scale，梯度与不含该项逐位相同）；值照记。损失在 eager 下算（只有模型前向编译）。

## 6. 判读线（新评分器为主，旧评分器同线并报）

两端：P0（全 S 行，0.806 新 / 0.737 旧）与 NTV0NS（无 S 行，0.698 新），在共同场景上重算两端的均值。对每一臂（其「去掉的部分」见第 3 节）：

| 结果 | 结论 |
|:--|:--|
| 臂 ≥ P0 − 0.02 | 「去掉的那部分不需要」 |
| 臂 ≤ NTV0NS + 0.03 | 「去掉的那部分承载增益」 |
| 之间 | 部分（报保留的份额 (臂 − NTV0NS) / (P0 − NTV0NS)） |

合起来：NH 承载 + ND 不需要 → hinge 承载 S 增益，论文主张成立；NH 不需要 + ND 承载 → 增益来自 distill_ho，「后果 hinge」不成立于这份增益；
两者都不需要 → 二者各自都够（冗余）；两者都承载 → 二者都要；其余 → 混合，照实报。

同时报：配对差与 95 % CI（NH、ND 对 P0、NTV0NS、NTV0-s0、RB0-F，NH 对 ND，新旧两个评分器）；零分 / 部分分按类（AF-front、出路、漂移
（zero-other）+ 侧向、路线转、过冲、追尾 / 慢 / 撞）对 P0 与 NTV0NS 的计数差和 CI；dev ADE；训练日志末 1 000 步的 distill_ho、各 hinge 值、
grad/pool；卡时。一个 seed 的结论按 seed 噪声（NTV0 s1 − s0 = −0.006）读，不加 seed。
