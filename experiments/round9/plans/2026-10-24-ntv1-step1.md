## 1. 底与三臂

底 R = P1L = PCL1L-F-s0（第 461 条）：RB0L 的 argv（出厂权重 19 500 步、eager）+ NTV0 的 S 开关、池 on1_JT 只抽 rb0（wfile JT00S-rb0）、
`--on-start 10000` + `--lr2-at 10000`（NTV0-L18 的调度）。argv 由 `pcl.py argv P1L` 生成，不手抄。

| 臂 | tag | 与 R 的差 | 第 10 000 步前每批 | 第 10 000 步起每批 |
|:--|:--|:--|:--|:--|
| N1 | NT1N1-F-s0 | `--cmd-rule heading-all`（第 459 条）+ `--on-mix-log`（只记录） | 115 navtrain + 13 yaw | 83 + 13 + 32 S（rb0） |
| N2a | NT1N2A-F-s0 | N1 + 池换成 on1_JTPH、`--on-k 64`、wfile NTV1M（S 0.5 / PAI 人 0.5）+ `--on-pre-k 58 --on-pre-wfile RB0P.npz` | 57 + 13 + 58 PAI 人（= HP50） | 51 + 13 + 64 池（期望 32 S + 32 PAI 人） |
| N2b | NT1N2B-F-s0 | N1 + 池换成 on1_JTPH、`--on-k 64`、wfile NTV1M | 115 + 13（= N1） | 51 + 13 + 64 池（期望 32 S + 32 PAI 人） |

决定与理由（每一处与先例的差都记在这里）：

1. **PAI 人类行 = RB0P.npz 的抽样**（HP50 / RB0-P50 用的那份：R6FIX 式，MV-LC 的 D1 过滤 + F1 / F2，ph : ph05 : ph15 = 0.5 : 0.25 : 0.25，
   held 部分权重 0，19.4 万可抽行）。N2a、N2b 用同一份。R5LC 的 R5LC.npz 只有 MV-LC 没有 F1 / F2，这里不用它（简报要「清洗过的」同一批行）。
2. **合并池 = on1_JTPH**（R5LC 用的池）：前 169 606 行与 on1_JT 逐名相同（rb0 S 行 17 429 行、可抽 13 793 行在其中），后面是 PAI 人类行
   ph / ph05 / ph15（tab mode `both`）。不新建池。NTV1M.npz：rb0 行按 JT00S-rb0 的权重、PAI 人类行按 RB0P 的权重，两部分各归一到 0.5；
   grp 用 RB0P 的 grp（其 on1_JT 部分与 JT00S-rb0 的 grp 逐行相同，所以 wait / launch 监视探针行与 N1 相同）。
3. **PAI 人类行在池里怎么算损失**：`--on-mode mixed` 下非 `self` 行是 `both` 行；on1_JTPH 的 agent / road 标签只在 87 012 个 S 行上，
   nr1_lat 的侧向栅格只覆盖池的前 169 606 行，所以 PAI 人类行实际只有模仿项 + distill（与 R5LC / R6DAG 一样），并且照 `--on-normal`
   参与 25 % 路线记忆置空。这与 HP50 的 imit 模式（`--agent-lam 0`，无任何 hinge）等价，只是走 mixed 的路径。
4. **N2a 的 T 前**：HP50 的构成（115 个普通行里 58 个换成 PAI 人类行）。训练器没有「T 前另一份抽样」，新加开关
   `rm_train --on-pre-k K --on-pre-wfile F`（默认关，关时不加任何操作）：T 前每批 K 个池行按 F 的权重、用自己的随机流 [seed, 0, 191] 抽，
   普通行少 K；T 起照常（池流 [seed, 0, 53] 在 T 前不动，与不带开关时一样）。
5. **两臂 T 后构成相同**：51 navtrain + 13 yaw + 64 池（期望 32 S + 32 PAI 人），即 R5LC 的构成（简报举的例子）。这样 N2a 与 N2b 只差 T 前那一段，
   比较的就是「放法」。N2a 在 T 处 PAI 人类行从 58 降到期望 32，navtrain 从 57 降到 51；记为与「T 后照留」的字面差：留着，但份额与 N2b 对齐。
   与 N1 比，T 后 navtrain 83 → 51：PAI 人类行替掉的是 navtrain 行，S 行数不变。
6. 其余全部与 N1 相同（seed 0、eager、lr 调度、S 开关、hold-out 15 %、`--diag`、`--save-at 10000`）。

## 2. 闸（全部在队列里；任何一个不过，训练不开 / 不读）

- G0 开关关（提交时的 HEAD）：RB0-F 的 argv 跑到第 100 步，≤ 75 步全部标量与存档 RB0-F-s0 逐位相同、无多无少；P1L 的 argv 跑到第 125 步，
  ≤ 100 步全部标量与存档 PCL1L-F-s0 逐位相同、无多无少。
- G-W 合并池抽样文件（ntv.py wfile）：名字与 on1_JTPH 逐行相同；非零行 = 13 793 rb0（全是 mode self）+ 193 850 PAI 人（全是 ph / ph05 / ph15、
  mode both）；份额 S 0.5、ph 0.25、ph05 0.125、ph15 0.125（± 1e-9）；rb0 行权重相等；PAI 行权重与 RB0P 成比例。
- 冒烟（每臂 60 步、T = 30、`--save-at 30`）：DONE、全有限、到第 60 步、终点与快照 checkpoint；日志的批构成（N1 83 / 13 / 32，N2 51 / 13 / 64，mixed）；
  每个记录窗的池行数与计划一致（N2a T 前 58）；T 前 S 行 0，T 后 S 行份额 N1 = 1、N2 在 0.42–0.58；训练器记录的抽样份额与 G-W 一致（N2a 另有 T 前
  ph 0.5 / ph05 0.25 / ph15 0.25、mode both 1.0）；S 项 T 前无质量、T 后有限非零；lr 与公式一致（p1l.py lrcheck）。
- 指令一致（cpl.py smoke，每臂冒烟上）：2 万抽样行喂入的指令与 cmdd.py 独立重算一致 ≥ 99.9 %（按来源分组都报，含 navtrain、yaw、PAI 人
  ph / ph05 / ph15、S rb0），各部分改动份额与 cmdd.py rows 差 ≤ 0.5 个点。
- 照报（不是闸）：N2b 冒烟 ≤ 25 步的标量对 N1 冒烟（T 前两臂同一批流，只差池的装载）。
- 训练中：T 后 500 步 S / 模仿梯度比在登记带 0.21–1.04（pcl.py ratio；出带 → 取消该臂训练、不读）。
- 训练后：DONE、末步 navtrain dev ADE ≤ 0.566；整段 lr 对公式（闸）；N2b 整段 T 前标量对 N1（照报）。
- 读数：serve 指令与规则一致 ≥ 99.9 %（dl.py cmdagree，每臂）。

## 3. 读数

PAI 281 ACC + GAP（g10、FAST、CONC 4、NTV0-L18-s0 的 8 块表、Harmonizer 关），serve = P1L 的 serve 加 `JEV_CMD=heading`；`pai_fix.sh tax` → facts；
scorer_v2 新评分器重评。主读新评分器，旧评分器同报。共同场景 = N1、N2a、N2b、P1L、NTV0-L18-s0、R8K-L18-s2 六个读数都打了分（新旧两个评分器）且都
没有 driver RPC 错误的场景，新旧同一集合。配对差 = 场景 bootstrap 95 % CI（jevdrive.stats.paired）。

## 4. 判读线（新评分器为主；旧评分器同线并报）

| 比较 | 线 | 结论 |
|:--|:--|:--|
| N1 − P1L | ≥ −0.015 | 「航向指令在 S 配方里不花代价」，采用 |
| | < −0.015 | 报告（航向指令在 S 配方里有代价） |
| N2a / N2b − N1 | 路线转零分比 N1 少 且 均分 ≥ N1 + 0.01 | PAI 人类行在这种放法下有帮助 |
| | 均分 ≤ N1 − 0.01 | 有害 |
| | 其余 | 中性 |

路线转零分 = 旧评分器 facts 的 fclass route-turn 零分数。同时报：侧向零分（fclass ∈ {offroad, zero-other, side}）每臂；NTV0-L18-s0 满分场景
（旧分 ≥ 0.98）上的新零分每臂；零分按类对 N1 / P1L / NTV0-s0 / R8K-s2 并列；配对差（每臂对 P1L、NTV0-s0、R8K-s2，N2a / N2b 对 N1，N2a 对 N2b）；
dev ADE（10 000 / 19 500 步）；T 后梯度比；卡时。R8K-L18-s2（新 0.874）是之后要超过的目标，这一步不设对它的线。

## 5. 代价估计

训练 3 × 约 1.1 卡时（eager，P1L 实测约 65 min；N2 每批 64 个池行，可能稍慢）；闸约 0.4；读数 3 × 约 0.8 卡时；合计约 6.5 卡时。三个训练同时提交、并行。
盒上此时有 P1 seed 1、S-SPLIT、INTERP 读数、body-schema 前向在跑，墙钟取决于空卡。
