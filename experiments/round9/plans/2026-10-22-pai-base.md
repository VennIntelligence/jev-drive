## 2. 底座臂 RB0-P（定的选择）

- **命令** = RB0-F-s0 的 meta.json argv 原样（步数、lr、warm-up、yaw 行、路线记忆定义与 drop 0.25 都不变），只加：
  `--on on1_JTPH --on-k K --on-mode imit --on-normal --on-wfile runs/round9/pai_base/w/RB0P.npz`，并把 `--agent-lam 10 --agent-on-only` 写成
  `--agent-lam 0`。后者不是改配方：rm_train 对没有池的 RB0-F 本来就把 `--agent-on-only` 变成 agent-lam 0（任何行都没有 agent hinge）；imit 模式下
  on_train.setup 不接受 `--agent-on-only`，写成 0 得到同一个状态。**不改任何代码**。
- **imit 模式**：PAI 行是普通模仿行（模仿池里的人类未来 + 非规划头蒸馏到出厂老师），不带 hinge，与 navtrain 行同一损失；`--on-normal`：路线记忆按
  同样 25 % 置空。PAI 行从不作 anchor 行。
- **份额**：PAI 行占 115 个模仿（normal）行的 30 / 50 / 70 % → K = 35 / 58 / 80（30.4 / 50.4 / 69.6 %），yaw 13 行不动，批仍 128。
- **清洗**：抽样文件 = R6FIX.npz（`runs/round6/fix/w/`：MV-LC 第 430 条的变道过滤 + MV 的输入 ≥ 2 m/s + F1 / F2 第 433 条）把 S 组置 0，PAI 三部分保持
  相对权重（ph 0.5 / ph05 0.25 / ph15 0.25，可抽 81 801 / 73 413 / 38 636 行）。不用 PAIHN / PAIHX（第 424 条：64 个场景全与 test281 同驾驶）。
- **数据检查（闸）**：可抽行全在 ph / ph05 / ph15；场景 ⊂ `physical_ai_av/pai-rows@v1`，与 test281、curated-val、drives_val160、train_exclude、
  exam_scenes、N 批同驾驶表都不相交，且不在训练器 held（crc32 % 100 < 15）里；训练后在 CPU 上重放训练器的抽样流（[seed, 0, 53]），
  on_hash_60 / _1000 / 末步必须与 DONE 相同，抽到的行无一权重 0 或 held。没有 test281 的真实帧。
- **恒等闸**：份额 0 = RB0-F 的 argv 原样；在 HEAD 上 eager 重训 RB0-FR-s0（10 000 步）与存档 RB0-F-s0 `df.py bitcmp --extra-ok`（每个标量、每个权重、
  dev ADE）必须逐位相同。不过 = 停线报告（底座闸不判）。
- **冒烟**：50 % 臂 300 步（eager）：DONE、标量有限、日志批构成 57 / 13 / 58 imit、dev ADE 低于第 0 步。
- 只跑 seed 0；三个底座并行（`cl fanout`），eager（与 RB0-F 相同）。

## 4. 底座闸（读数之前写定）

一个份额过闸 = (a) 281 关读数对 RB0-F 的配对均值差 95 % CI 下界 > 0；(b) 起步数（LAUNCH-37 的 launched）≥ RB0-F 的 − 2（第 416 / 428 条：PAI 人起步
只有 navtrain 一半远，慢起步被追尾）；(c) 抽样重放过；且恒等闸过。多个过：取配对均值最大者（相同取份额小者）。**没有一个过：停线、报告**（闸作业
exit 3，后面的作业随之失败）。
