## 1. S 课：干净池 + 自适应压力（用户 10-22 点名「非常有新意」，记入计划）

现状（research/s-rows-and-paper.md）：每批 S 32 行，能学且激活的只有约 3.9 行；63.5 % 的 hinge 量在学不动的行上；

第 311 / 347 / 348 条），但剂量与「垃圾行」从没分开过。时间安排（爬升 / 周期 / 自适应）从没试过。

**自适应压力（主提议）**：每步按训练里已记录的梯度范数（`--diag`）调 S 行数，使「S hinge 对主干的梯度 / 模仿梯度」
稳在目标比例附近（现测 0.3–0.45）。模型学会一部分后激活行变少、S 拉力掉，k 自动加上去；不再用固定 70 / 30。

```python
def k_adaptive(g_s, g_imit, k, target=0.4, lo=4, hi=64):
    # g_s, g_imit: EMA of per-step backbone grad norms of the S hinge and of imitation
    return int(np.clip(k * (target / max(g_s / g_imit, 1e-6)) ** 0.5, lo, hi))
```

配套：池层面的 PER 式刷新，每 N 步用当前模型重算激活 / 可学性、重定权（审计「没测过」第 1 条）。

对照臂（1 000 步 pilot 上比，作同一联合臂的剂量维）：固定 2.4×（= R6DAG）、固定 5×、爬升（前 1 000 步以模仿为主，
之后 S 线性加到上限）、自适应。周期式（高低交替、末段落低 S）放后面。先读转弯切内侧 / 出路小考场，过线的一个跑全长，
读 281 Harmonizer 开 / 关。

## 2. 路线支路：按速度自适应的前视窗口（用户 10-22）

现状：路线记忆固定为后轴坐标 −6 … +72 m、每 2 m 一点、40 点（第 282 条），前后范围从没扫过。高速时 +72 m 只够
2.4 s（30 m/s），而 plan 4 s 约 120 m，后半段没有路线可对照（假设，与高速漂移可能有关）。

**提议**：窗口长度随车速定，点数固定（token 数不变），间距随之伸缩：

```python
def route_window(v, T=5.0, L_min=40.0, L_max=160.0, back=6.0, n=40):
    L = np.clip(v * T + 20.0, L_min, L_max)          # look-ahead grows with speed
    s = np.linspace(-back, L, n)                     # fixed n points: spacing (L + back) / (n - 1)
    return s                                         # variant: denser near, sparser far (e.g. s ~ L * u**1.5)
```

需要重训底座（输入定义改变），与锚定记忆（`--rm-anchor`，第 342 条）和航向指令（第 432 条）一起作为一次输入定义
重训；是否值得，等 CPU 检查（10-22 已派）：漂移 / 直路出路场景里指令是否翻转、plan 是否超出路线覆盖、偏向哪侧；
以及现模型按距离带对路线的依赖。
